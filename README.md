# 数学解説の庭

数論・幾何・物理・確率・圏論の解説集。著者: Hiromasa Hagino。

公開サイト: GitHub Pages（リポジトリの `docs/` を配信）。

## このリポジトリの安全設計

このリポジトリには **公開してよいファイルしか入っていない**。
親フォルダ（研究ノート/）の `career-strategy.md`・`自前事業/`・`論考/`・
未公開の第一論文草稿などは **物理的にここに存在しない**。

`build.ps1` の許可リスト（`$public`）に明記したファイルだけが
`記事/` にコピーされ、レンダリングされる。許可リストに無いものは
墓場/ に存在しても絶対に公開されない。

## ビルド

```powershell
pwsh ./build.ps1   # 許可リストのファイルをコピー → quarto render → docs/
```
