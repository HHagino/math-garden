# 数学解説の庭

数論・幾何・物理・確率・圏論の解説集。著者: Hiromasa Hagino。

公開サイト: GitHub Pages（リポジトリの `docs/` を配信）。
2026-11-22 から、**パスワード付き**で配信している（StaticCrypt でページを暗号化し、ブラウザでパスワードを入れると開く）。

## このリポジトリに入っているもの

- `docs/` … 暗号化したページ（中身はパスワードが無いと読めない）。
- 組み立ての道具（`build.ps1`・`暗号化して組む.ps1`・`_quarto.yml`・`_暗号化の入口.html` など）。

記事と教科書のソースは、このリポジトリには入れない（`.gitignore`）。
ソースを置くと、パスワードなしで GitHub から読めてしまうため。
2026-10-29 までに公開していた分は、前から公開していたものなので履歴に残っている。

## 組み方（作者の手元だけ）

```powershell
pwsh ./暗号化して組む.ps1   # 許可リストの記事を組む → 暗号化の前に関所 → 暗号化 → 平文が残っていないか確かめる → docs/
```

`build.ps1` の許可リスト（`$public`・`$publicByHead`）に書いた記事だけが組まれる。
Quarto の出力は `_plain/`（git の外）に出て、暗号化してから `docs/` に置く。
