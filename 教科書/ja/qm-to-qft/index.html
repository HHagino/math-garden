単位 第1部は \(\hbar\) を明示（第4章 §4.6 の水素原子だけ原子単位 \(\hbar=m_e=e^2/(4\pi\varepsilon_0)=1\) と宣言）。第2部・第3部は \(\hbar=1\)。第3部は \(c=1\) も。 第2部で \(\hbar\) が要る所（§7.6）は戻して書く。第3部の例外は第14章 §14.5（ループ展開を \(\hbar\) の展開として読むために戻す。\(C_\hbar(J)=\hbar\log Z_\hbar[J]\)、\(\hbar=1\) で表の \(\mathcal C[J]\)）。
内積 \(\langle\phi,\psi\rangle\) は第1引数について反線形・第2引数について線形。Dirac 記法 \(\langle\phi\vert\psi\rangle\) も同じ。\(\vert\psi\rangle\langle\phi\vert\) は \(\chi\mapsto\langle\phi,\chi\rangle\psi\)。 第1引数で線形の文献を引くときは換算を一言書く。
随伴 作用素の随伴は \(A^{\dagger}\)（非有界でも）。複素共役は \(\bar z\)。 例外：余微分は MW に合わせて \(\d^{*}\)。
作用素の用語 対称作用素（\(A\subset A^{\dagger}\)、稠密な定義域）・自己共役（\(A=A^{\dagger}\)）・本質的自己共役。 MW の「自己随伴」は同じ意味。この本では「自己共役」に統一。
定義域・スペクトル 定義域 \(\operatorname{dom}A\)、スペクトル \(\operatorname{spec}A\)、スペクトル測度 \(\mathsf E_A(\cdot)\)。 \(\mathcal D\) は経路積分の測度記号に、\(\sigma\) は Pauli 行列に、\(E\) はエネルギーに使うので避けた。
交換子 \([A,B]=AB-BA\)、\(\{A,B\}=AB+BA\)。古典の Poisson 括弧は \(\{f,g\}_{\mathrm{PB}}\)。
位置・運動量 作用素は \(X,P\)（\(\mathbb R^n\) では \(X_j,P_j\)）、変数・固有値は \(x,p\)。\(P=-i\hbar\,\partial_x\)、\([X,P]=i\hbar\)。
Fourier 変換（第1・2部） \(\hat\psi(p)=(\mathcal F\psi)(p)=(2\pi\hbar)^{-n/2}\int_{\mathbb R^n}e^{-ip\cdot x/\hbar}\psi(x)\,d^nx\)（ユニタリ）。 \(\hbar=1\) で \((2\pi)^{-n/2}\)。
Fourier 変換（第3部） \(\tilde f(k)=\int d^Dx\,e^{-ik\cdot x}f(x)\)、\(f(x)=\int\frac{d^Dk}{(2\pi)^D}e^{ik\cdot x}\tilde f(k)\)。\((2\pi)\) は運動量の測度の側に置く。 第11章の場の展開もこの形。
時間発展 \(U(t)=e^{-itH/\hbar}\)、Heisenberg 描像 \(A(t)=U(t)^{\dagger}AU(t)\)。
Wick 回転 \(t=-i\tau\)。\(e^{-itH/\hbar}\mapsto e^{-\tau H/\hbar}\)、\(e^{iS/\hbar}\mapsto e^{-S_{\mathrm E}/\hbar}\)。 第3部は \(\hbar=1\)。
時間の刻み 経路積分の時間刻みは \(\epsilon=t/N\)（または \(\beta/N\)）。 Feynman の処方は \(\epsilon\) を使わず \(-i0\) と書く（§2）。
Gauss 積分 \(\int_{\mathbb R^n}e^{-\frac12x^{\top}Ax}\,d^nx=(2\pi)^{n/2}(\det A)^{-1/2}\)（\(A\) は正定値対称）。
Pauli 行列 \(\sigma_1=\begin{pmatrix}0&1\\1&0\end{pmatrix}\)、\(\sigma_2=\begin{pmatrix}0&-i\\i&0\end{pmatrix}\)、\(\sigma_3=\begin{pmatrix}1&0\\0&-1\end{pmatrix}\)。\(\sigma_j\sigma_k=\delta_{jk}+i\varepsilon_{jkl}\sigma_l\)。 Levi-Civita は \(\varepsilon_{jkl}\)（添字三つのときだけ）。
角運動量 \([J_j,J_k]=i\hbar\,\varepsilon_{jkl}J_l\)、\(J_{\pm}=J_1\pm iJ_2\)、\(J^2\vert j,m\rangle=\hbar^2j(j+1)\vert j,m\rangle\)、スピンは \(S_j=\frac{\hbar}{2}\sigma_j\)。 数学の \(\mathfrak{su}(2)\) の基底は \(X_j=-\frac{i}{2}\sigma_j\)（\([X_j,X_k]=\varepsilon_{jkl}X_l\)）。\(J_j=i\hbar X_j\) の対応を第4章で一度書く。
ボソンの生成消滅 \(a=\sqrt{\frac{m\omega}{2\hbar}}\bigl(X+\frac{i}{m\omega}P\bigr)\)、\([a,a^{\dagger}]=1\)、\(N=a^{\dagger}a\)、\(H=\hbar\omega(N+\frac12)\)。基底 \(\vert n\rangle\)、Hermite 関数 \(h_n\)。Hermite 多項式は \(H_n(\xi)=(-1)^ne^{\xi^2}\frac{d^n}{d\xi^n}e^{-\xi^2}\)。 Hamiltonian の \(H\) と Hermite 多項式の \(H_n\) は添字の有無で区別。

ガンマ行列 \(\{\gamma^{\mu},\gamma^{\nu}\}=2\eta^{\mu\nu}\)、Dirac 方程式 \((\gamma^{\mu}\partial_{\mu}+m)\psi=0\)。\(1+1\) 次元で \(\gamma^0=i\sigma_2\)、\(\gamma^1=\sigma_1\)、カイラリティ \(\gamma_*=\gamma^0\gamma^1=\sigma_3\)。Dirac 共役 \(\bar\psi=\psi^{\dagger}\beta_{\mathrm D}=i\psi^{\dagger}\gamma^0\)、\(\mathcal L=-\bar\psi(\gamma^{\mu}\partial_{\mu}+m)\psi=i\psi^{\dagger}\partial_t\psi-\psi^{\dagger}H_{\mathrm D}\psi\)、\(H_{\mathrm D}=\alpha_{\mathrm D}P+\beta_{\mathrm D}m\)（\(\alpha_{\mathrm D}=-\gamma^0\gamma^1=-\sigma_3\)、\(\beta_{\mathrm D}=i\gamma^0=-\sigma_2\)）、カレント \(J^{\mu}=i\bar\psi\gamma^{\mu}\psi\)（\(J^0=\psi^{\dagger}\psi\)）。Euclid：\(\gamma_{\mathrm E}^0=i\gamma^0=-\sigma_2\)、\(\gamma_{\mathrm E}^1=\sigma_1\)、\(S_{\mathrm E}=\int\bar\psi(\gamma_{\mathrm E}^{\mu}\partial_{\mu}+m)\psi\)（第12章 §12.0 の表・命題 12.2・命題 12.23）。 \((\gamma^0)^2=-1\)。符号は第12章で \(\{\psi,\psi^{\dagger}\}=+\delta\)（内積が正）から決めた（「エネルギーが下に有界」だけでは決まらない：全体の符号を替えても \(\psi\leftrightarrow\psi^{\dagger}\) で有界。注意 12.8）。カイラリティを \(\gamma_*\)、Hamilton 形の行列を \(\alpha_{\mathrm D},\beta_{\mathrm D}\) と書くのは、有効作用 \(\Gamma[\varphi]\)・逆温度 \(\beta\) と区別するため。
生成汎関数 \(Z[J]\)、連結の生成汎関数 \(\mathcal C[J]=\log Z[J]\)、有効作用 \(\Gamma[\varphi]\)（Legendre 変換）。 \(W\) は第2部の超ポテンシャル専用なので \(\log Z\) に使わない。
結合定数 場：\(\frac{\lambda}{4!}\phi^4\)。量子力学の非調和振動子：\(gX^4\)。対応は \(\lambda=24g\)。
臨界値の差 \(f(q)-f(p)\) と書き下す。 MW の「\(\Delta f\)」は使わない（ラプラシアンと衝突）。
\(\kappa\) 裸の \(\kappa\) は正則化のパラメータ（最後に \(0\) へ送る数）に予約する：第11章 §11.5 の \(-i\kappa\)（\(-i0\) の実現、\(\kappa\downarrow0\)）と第15章の次元正則化 \(D=4-\kappa\)（\(\kappa\to0\)。文献の \(\varepsilon\) 展開）。添字つきの累積量 \(\kappa_n\)（第2・13章）は標準の記号なので別に許す。 いくつかの章では、章の中で宣言した局所の \(\kappa\) も使う（例：第4章の \(\kappa=\sqrt{-2E}\)（水素原子）、第7章 演習 7.3 の \(\log\cosh(\kappa x)\)）。量子力学の部の中だけの使い方で、場の部の \(\kappa\) と同じ式には出てこない。
\(\nu\) 第3部では Lorentz の添字 \(\mu,\nu\) だけ（「時空」の行）。第2部では第8章の占有数 \(\nu_i\in\{0,1\}\) に使う（占有の符号は \(2\nu_i-1\)）。 第13章の格子の有効な振動数は \(\omega_\epsilon\)、第9章の Fredholm 指数は \(\ind(D)\) と書き、\(\nu\) は使わない（下の行）。
\(\omega_\epsilon\)（第13章） \(2\cosh\omega_\epsilon=2+\epsilon^2\omega^2\)（時間刻み \(\epsilon\) の格子の有効な振動数。\(\omega_\epsilon=2\operatorname{arcsinh}(\epsilon\omega/2)=\epsilon\omega+O(\epsilon^3)\)）。同じ章のフェルミオンの振動数 \(\omega_{\mathrm F}\) と同じ型。 第3部の \(\nu\) は Lorentz の添字だけに予約。第13章は \(\omega_\epsilon\) を添字には使わない。
\(Q_{0\pm}\)（第9章） 近似的真空の行列要素 \(Q_{0\pm}=\langle\Phi_0,Q\Phi_{\pm}\rangle\)（3状態の模型では \(Q\Phi_{\pm}=Q_{0\pm}\Phi_0\)）。添字は「\(\Phi_0\) 行・\(\Phi_{\pm}\) 列」。 MW の臨界点 \(p,q\) や、正則化のパラメータ \(\kappa\) と区別するための名前。
\(\ind(D)\)（第9章） 第9章の Fredholm 指数 \(\ind(D)=\dim\ker D-\dim\ker D^{\dagger}\)（命題 9.17）。第7章の Witten 指数 \(\ind(H)\) と同じ記号で、引数が作用素 \(D\) か \(H\) かで区別する。 第3部の \(\nu\) の予約と、第8章の占有数 \(\nu_i\) のどちらにも触れない。

§2 記号の衝突の避け方

  • \(\Omega\)：MW の微分形式だけ。真空は \(\vert0\rangle\)。
  • \(\Delta\)：ラプラシアン（と MW の \(\Delta_t\)）だけ。差は書き下す。伝播関数は \(G\)。
  • \(\sigma_j\)：Pauli 行列だけ。スペクトルは \(\operatorname{spec}\)。
  • \(\epsilon\)：時間刻みだけ。Feynman の処方は \(-i0\)。Levi-Civita は \(\varepsilon_{jkl}\)。
  • \(W\)：超ポテンシャルだけ。\(\log Z\) は \(\mathcal C\)。
  • \(\psi\)：第1部では波動関数、第2部以降はフェルミオン。章の冒頭で宣言する。
  • \(\Gamma\)：有効作用 \(\Gamma[\varphi]\)（第14章）。第11章の対称 Fock 空間 \(\Gamma_s(\mathfrak h)\) と第15章の Gamma 関数 \(\Gamma(n-\frac D2)\) は添字・引数で区別。カイラリティは \(\gamma_*\)（第12章）。
  • \(\alpha,\beta\)：Dirac の Hamilton 形の行列は \(\alpha_{\mathrm D},\beta_{\mathrm D}\)（第12章）。\(\beta\) は逆温度（第5・13章）。
  • \(\kappa\)：裸の \(\kappa\) は正則化のパラメータだけ（第11章 §11.5 の \(-i\kappa\)・第15章の \(D=4-\kappa\)。§1 の表の行）。累積量は添字つきの \(\kappa_n\)。第9章の近似的真空の行列要素は \(Q_{0\pm}\)。章の中で宣言した検算・演習の局所の \(\kappa\) は、その章の中だけで使う。\(\epsilon\) は時間刻み専用なので、どの章もこれらに \(\epsilon\) を使わない。
  • \(\nu\)：第3部では添字だけ。第13章の格子の振動数は \(\omega_\epsilon\)、第9章の Fredholm 指数は \(\ind(D)\)。第8章の \(\nu_i\)（占有数）は第2部の中だけの使い方。
  • \(\Sigma\)：第12章 \(\Sigma^{\mu\nu}\)（スピン生成子）・第13章 \(\Sigma_s\)（符号つき巡回シフト）・第14章 \(\Sigma(p)\)（自己エネルギー）は章ごとに局所。第15章の質量のずれ \(\delta=\frac\lambda2G_a(0)\) は \(-\Sigma\)。
  • \(\omega\)：第15章の表面的発散次数 \(\omega\) は振動数 \(\omega_{\mathbf k}\) と添字で区別。第13章 §13.5 のフェルミオンの振動数は \(\omega_{\mathrm F}\)（\(\Omega\) を避けた）。
  • 2点関数：Wightman は \(G_+\)、Feynman は \(G_F\)、Euclid は \(G\)（§1 の表）。\(W\) は使わない。第11章の Gauss の幅は \(\ell\)（\(\sigma\) を避けた）。

§3 第1部と第2部の換算

\(\hbar=m=1\) の第1部の Hamiltonian \(H_{\mathrm I}=\frac12P^2+\frac12W'(X)^2\) に対し、第2部の \(H\) の \(F=0\) の部分は \(2H_{\mathrm I}-W''\) である。とくに \(W=\frac{\omega}{2}x^2\) なら第1部の零点エネルギー \(\frac{\omega}{2}\) が第2部では \(\omega\) になる（MW 付録 A.4 の「零点エネルギーは \(t\vert\lambda\vert\)」と同じ）。\(\hbar\) を戻すと

\[H_\hbar=-\hbar^2\partial_x^2+f'(x)^2+\hbar f''(x)[\psi^{\dagger},\psi]=\hbar^2\,\Delta_{t}\big\vert_{t=1/\hbar}\]

（第7章 §7.6 で証明する）。Euclid 作用の値（インスタントンの作用 \(t\,(f(q)-f(p))\)）は、この全体の定数倍の規約に依らない（時間の尺度に吸収される）。
