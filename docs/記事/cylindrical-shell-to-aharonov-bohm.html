円筒シェルから Aharonov–Bohm へ ── 境界条件がスペクトルを決め、磁束がそれを動かす

タイトル案

  1. 円筒シェルから Aharonov–Bohm へ ── 境界条件がスペクトルを決め、磁束がそれを動かす
  2. ベッセル関数の零点と整数量子数 m ── そしてそれが磁束でずれるという話
  3. ホワイトボードの円筒シェル ── 量子力学ゼミから Aharonov–Bohm 効果へ
  4. J_m(ka)N_m(kb)=J_m(kb)N_m(ka) から先を覗く ── 円筒シェルと磁束

冒頭 ── ホワイトボードの式は何をしていたのか

jj_sakurai ゼミのホワイトボードに、L_z = -i\hbar\,\partial_\varphi、円筒座標、ベッセル関数 J_m、N_m、そして見慣れない行列式条件 J_m(ka)\,N_m(kb) - J_m(kb)\,N_m(ka) = 0 が並んでいた。最後に「次回は磁束を入れる ── Aharonov–Bohm 効果」とだけ書かれている。

これは要するに、円筒シェル領域 a<r<b に閉じ込められた自由粒子のエネルギー固有値を求める計算と、それを磁束のあるバージョンに拡張するための準備、をやっていた。

一気に式を追うとややこしいが、構造としては実にきれいだ:

  1. 円筒座標で Schrödinger 方程式を変数分離する。
  2. 角度方向の周期性から、角運動量量子数 m \in \mathbb{Z} が落ちる。
  3. 半径方向はベッセル方程式になる。
  4. シェル境界 r=a, b で波動関数がゼロ ── これが行列式条件を生み、エネルギー固有値が決まる。
  5. 中心を磁束が貫くと、量子数 m が m - q\Phi_B/h にずれる。

順に追う。

第1節 ── 円筒座標と L_z = -i\hbar\,\partial_\varphi

3 次元の角運動量演算子のうち、z 成分は直交座標で L_z = -i\hbar\left(x\frac{\partial}{\partial y} - y\frac{\partial}{\partial x}\right) と書かれる。円筒座標 x = r\cos\varphi, y = r\sin\varphi を入れて連鎖律で書き直すと、 x\frac{\partial}{\partial y} - y\frac{\partial}{\partial x} = \frac{\partial}{\partial\varphi} となる(これは直接の計算で確認できる)。したがって L_z = -i\hbar\,\frac{\partial}{\partial\varphi}, \qquad (\hbar=1\text{ の単位系で } L_z = -i\partial_\varphi).

円筒対称な系では、L_z は Hamiltonian と可換になり、エネルギー固有関数は L_z の固有関数でもあるように選べる ── これが「角度方向に e^{im\varphi} という形が出てくる」物理的な理由だ。

第2節 ── 角度方向の周期性と m \in \mathbb{Z}

円筒座標で Schrödinger 方程式を変数分離する。2 次元なら \psi(r,\varphi) = R(r)\,\Phi(\varphi), 3 次元なら z 方向も独立して \psi(r,\varphi,z) = R(r)\,\Phi(\varphi)\,Z(z) と書く。角度方向の方程式は \frac{d^2\Phi}{d\varphi^2} = -\alpha^2 \Phi となり、形式解は \Phi(\varphi) = A\,e^{i\alpha\varphi} + B\,e^{-i\alpha\varphi}.

ここで重要なのは、\varphi は周方向の角度なので、\varphi と \varphi + 2\pi は同じ物理的な点を表す。よって波動関数の一価性から \Phi(\varphi + 2\pi) = \Phi(\varphi) を要求する。これは e^{2\pi i\alpha} = 1、つまり \alpha = m, \qquad m \in \mathbb{Z} を意味する。これが整数の角運動量量子数 m の出どころだ。角度方向に「巻きつきの自由度」がある以上、固有値は整数に量子化される。

これは後の Aharonov–Bohm 効果で核心的な役割を演じる ── 磁束を入れると一価性の要求が変質し、m が整数からずれる。

第3節 ── 半径方向とベッセル方程式

角度部分が落ちると、半径方向の方程式が残る。自由粒子(円筒シェル領域では Hamiltonian は単に運動エネルギー)の場合、 \frac{d^2R}{dr^2} + \frac{1}{r}\frac{dR}{dr} + \left(k^2 - \frac{m^2}{r^2}\right) R = 0 の形になる。ここで k はエネルギーから来る波数で、E = \hbar^2 k^2 / (2M) の関係がある。

これは次数 m のベッセル方程式で、線形独立な解として第 1 種 J_m(kr) と第 2 種 N_m(kr)(Neumann 関数、Y_m とも書く)を取る: R(r) = A\,J_m(kr) + B\,N_m(kr).

通常の円形ディスク(0 \le r < b)では、N_m は原点で発散するので捨て、J_m だけを残す。しかしいまは円筒シェル領域 a < r < b を考えており、原点を含まない。したがって N_m を捨てる物理的理由はなく、両方を保持する。

第4節 ── 境界条件 R(a)=R(b)=0 から行列式条件へ

シェル境界 r=a, b で波動関数がゼロ(無限ポテンシャル壁)とすると、 A\,J_m(ka) + B\,N_m(ka) = 0, A\,J_m(kb) + B\,N_m(kb) = 0.

(A,B) についての斉次連立 1 次方程式だ。非自明解 (A,B)\ne(0,0) が存在するには、係数行列の行列式が消える必要がある: \begin{vmatrix} J_m(ka) & N_m(ka) \\ J_m(kb) & N_m(kb) \end{vmatrix} = 0 すなわち \boxed{\;J_m(ka)\,N_m(kb) - J_m(kb)\,N_m(ka) = 0.\;}

これが固有値条件だ。k について離散的に解が並び、m 固定ごとに n=1,2,3,\ldots と数えて k_{m,n} と書く。

ベッセル関数の零点を計算するときの「単一ベッセル関数の零点」ではなく、J_m N_m - J_m N_m というクロス組み合わせの零点であることに注意。シェル境界が二つあるから、両方を同時に満たす条件として出てくる。

第5節 ── 固有値 k_{m,n} とエネルギー E_{m,n}

固有値条件を解いて得られる根を k_{m,n} と書くと、2 次元の円筒シェルでは E_{m,n} = \frac{\hbar^2 k_{m,n}^2}{2M}.

3 次元で z 方向にも自由に動ける場合は、z 方向は平面波 Z(z) = e^{ik_z z} で E_{m,n,k_z} = \frac{\hbar^2}{2M}\left(k_{m,n}^2 + k_z^2\right).

ここまでが、ホワイトボードの主部分が言っていたことだ。要するに、円筒座標で自由粒子を解くと、角度方向の周期性から整数 m が出て、半径方向の境界条件からベッセル関数の零点条件が出る。エネルギーは (m, n)、3 次元なら k_z も含めた 3 つのラベルでパラメトライズされる。

第6節 ── 次回への接続:磁束で m がずれる

ここから先が Aharonov–Bohm 効果につながる本題だ。

磁場を入れると、運動量演算子が最小結合によって -i\hbar\nabla \;\longrightarrow\; -i\hbar\nabla - q\mathbf{A} に置き換わる(q は粒子の電荷、\mathbf{A} はベクトルポテンシャル)。

円筒の中心軸を貫く磁束 \Phi_B を考える。粒子のいる領域 a<r<b には磁場がゼロ(磁束は中心の細い領域、たとえば r<a にだけ詰まっている)としても、ベクトルポテンシャルは消えない。ストークスの定理から、r > 0 では A_\varphi = \frac{\Phi_B}{2\pi r} が残る(A_r = A_z = 0 で良い)。

このベクトルポテンシャルを Schrödinger 方程式に入れると、角度方向の演算子が -i\partial_\varphi \;\longrightarrow\; -i\partial_\varphi - \frac{qA_\varphi r}{\hbar} = -i\partial_\varphi - \frac{q\Phi_B}{2\pi\hbar} = -i\partial_\varphi - \frac{q\Phi_B}{h} のように変化する。

結果として、角度方向の固有値が \boxed{\;m \;\longrightarrow\; m - \frac{q\Phi_B}{h}\;} のようにずれる。整数のままだった m に、磁束による連続的な「ずれ」が乗る。

単純なリング模型

中心半径 R の細いリングに閉じ込められた粒子なら、計算はずっと簡単だ。エネルギーは E_m(\Phi_B) = \frac{\hbar^2}{2MR^2}\left(m - \frac{q\Phi_B}{h}\right)^2 となり、整数 m ごとに放物線が並び、その頂点が磁束で連続的に動く。磁束を変化させると、エネルギー準位が周期 h/q で振動する ── これが Aharonov–Bohm 振動の最も素朴な姿だ。

円筒シェルの場合

シェル領域 a<r<b では、磁束がある場合、ベッセル関数の次数 m が概念的には \nu = \left|\,m - \frac{q\Phi_B}{h}\,\right| へ置き換わる。固有値条件も J_\nu(ka)\,N_\nu(kb) - J_\nu(kb)\,N_\nu(ka) = 0 のような形に変わる。\nu は一般には整数でなくなるので、ベッセル関数の次数が連続的にずれた状態でゼロ点を取ることになる。

大事な注意:一様磁場と Aharonov–Bohm 型の区別

ここは混乱しやすいので明示しておく。

  • 粒子のいる領域に一様な磁場 B がかかっている場合:Schrödinger 方程式そのものに磁場の効果がフルに乗り、Landau 準位的な物理が出る。エネルギー準位の構造は本質的に変わる。
  • 粒子のいる領域では磁場がゼロだが、穴を磁束が貫いている Aharonov–Bohm 型:局所的には磁場がゼロなので、古典的には粒子は何も感じないはず。それでも量子論では波動関数の位相にベクトルポテンシャルが効き、エネルギー準位が磁束依存性を持つ。

Aharonov–Bohm 効果の本質は、局所的な磁場ではなく、ベクトルポテンシャルおよび磁束のトポロジカルな効果がスペクトルや位相に現れる点にある。粒子は通過しない領域の磁束を「感じる」── ゲージ場の物理が古典直観を超える、量子力学の根幹に関わる現象だ。

結論

今回のホワイトボードの中身を一段抽象化すると、こうなる。

円筒座標で Schrödinger 方程式を解くという作業は、表面的には「ベッセル関数の零点を探す」計算に見える。しかし構造としては、角度方向の周期性が整数量子数 m を生み、半径方向の境界条件がエネルギーを離散化する、という「境界条件がスペクトルを決める」話だ。

そして次回への伏線:

その上で、円筒の中心を磁束が貫くと、ベクトルポテンシャルが角度方向の演算子に乗り、量子数 m が連続的にずれる。これは「トポロジー(磁束)がスペクトルを動かす」話 ── すなわち Aharonov–Bohm 効果である。

「境界条件がスペクトルを決める」から「トポロジーがスペクトルを動かす」への橋渡し。今日の円筒シェル計算は、次回のために、その渡り板を整えていたのだった。
