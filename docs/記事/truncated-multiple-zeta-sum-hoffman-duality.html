有限切断多重ゼータ和 ζ_{<N} ── N=∞ と N=p、二つの双対性の母体

1. 導入:二つの「双対性」を、ひとつの母体から見る

多重ゼータ値(multiple zeta values, MZV)には、双対性と呼ばれる不思議な対称性がある。指数列 \mathbf{k} に対して双対指数 \mathbf{k}^{\dagger} が定まり、

\zeta(\mathbf{k}) = \zeta(\mathbf{k}^{\dagger})

が成り立つ。一見まったく違う二つの無限和が、同じ値を持つ。

一方、有限多重ゼータ値(finite multiple zeta values)の世界にも、Hoffman 双対性と呼ばれる対応がある。こちらは無限和ではなく、素数 p を法とした有限和の合同関係として現れる。

この二つの双対性は、ふつう別々の文脈で語られる。MZV の双対性は解析と幾何の話、Hoffman 双対性は有限体と組合せ論の話。住む世界が違う。

しかし本記事では、両者をひとつの共通の母体から派生する二つの特殊化として眺めてみたい。その母体が、有限切断多重ゼータ和 \zeta_{<N} である。N を \infty に飛ばせば MZV が、N を素数 p に固定すれば有限多重ゼータ値が現れる。そして、それぞれの先で、姿の異なる双対性が立ち現れる。

これは厳密な定理の体系ではなく、ひとつの見取り図である。その前提で読んでいただきたい。

2. 有限切断多重ゼータ和 ζ_{<N}

主役を定義する。正整数列(指数列)\mathbf{k} = (k_1, \dots, k_r) に対して、

\zeta_{<N}(k_1, \dots, k_r) = \sum_{0 < n_1 < n_2 < \cdots < n_r < N} \frac{1}{n_1^{k_1}\, n_2^{k_2}\cdots n_r^{k_r}}

これが有限切断多重ゼータ和である。和の範囲は、0 より大きく N より小さい整数を、狭義単調増加に並べた組 (n_1, \dots, n_r) すべてにわたる。N という上限で和を「切断」しているのがポイントで、\zeta_{<N} は有限和である。だから収束を心配する必要がない。

N を有限のまま見れば、これは「切断された多重調和和」(truncated multiple harmonic sum)にすぎない。素朴な有限和だ。

ところが、この N をどう選ぶかで、\zeta_{<N} はまったく異なる数学的世界に接続される。本記事で見るのは、次の二つの選び方である。

  • N \to \infty:和を無限に伸ばす。解析的・幾何的な世界へ。
  • N = p(素数):上限を素数に固定し、\bmod\ p で見る。有限体的・合同式的・組合せ的な世界へ。

同じ \zeta_{<N} が、二つの扉を持っている。

3. N=∞:通常の MZV と、反復積分の双対性

まず N \to \infty の扉を開く。

切断を取り払った極限

\zeta(\mathbf{k}) = \lim_{N \to \infty} \zeta_{<N}(\mathbf{k}) = \sum_{0 < n_1 < \cdots < n_r} \frac{1}{n_1^{k_1}\cdots n_r^{k_r}}

が、通常の多重ゼータ値である。ただし、この無限和が収束するには条件が要る。いちばん深いところ(最大の n_r)が担う指数について、k_r \geq 2 が必要になる。1

MZV には、冒頭で触れた双対性がある。

\zeta(\mathbf{k}) = \zeta(\mathbf{k}^{\dagger})

この双対性は、反復積分表示から自然に説明できる。MZV は、0 と 1 のあいだの反復積分として書ける。鍵となる二つの微分形式は

\omega_0 = \frac{dt}{t}, \qquad \omega_1 = \frac{dt}{1-t}

である。指数列 \mathbf{k} は、\omega_0 と \omega_1 を並べた語(word)に翻訳される。各 k_i が、\omega_0 を k_i - 1 個並べてから \omega_1 を一つ置いたブロックに対応する。語の長さは重さ n = k_1 + \cdots + k_r に等しく、そのうち \omega_1 の個数が深さ r に等しい。

ここで変数変換 t \mapsto 1 - t を施す。すると、

  • \omega_0 = dt/t と \omega_1 = dt/(1-t) が入れ替わる(0 と 1 の入れ替え)。
  • 積分区間の向きが反転し、語が逆順になる。

しかも積分の値そのものは変わらない。したがって、「もとの語」と「0/1 を入れ替えて逆順にした語」は、同じ MZV を与える。この「逆順 + 0/1 入れ替え」で得られる指数列が、双対指数 \mathbf{k}^{\dagger} である。

代表例を挙げよう。Euler が見つけた有名な等式

\zeta(2,1) = \zeta(3)

がこれである。\zeta(3) の語は \omega_0\,\omega_0\,\omega_1、\zeta(2,1) の語は \omega_0\,\omega_1\,\omega_1。前者を逆順にすると \omega_1\,\omega_0\,\omega_0、0/1 を入れ替えると \omega_0\,\omega_1\,\omega_1 ── ちょうど \zeta(2,1) の語になる。だから両者は等しい。

要点は、MZV の双対性は幾何的だということだ。それは、0 と 1 という二点を入れ替える t \mapsto 1-t という変換、反復積分の図形的な対称性として見える。

4. N=p:有限多重ゼータ値と、Hoffman 双対性

次に、もう一つの扉 ── N = p(素数)── を開く。

N = p とすると、和の範囲は 1 \leq n_1 < \cdots < n_r \leq p-1 になる。

\zeta_{<p}(k_1, \dots, k_r) = \sum_{0 < n_1 < \cdots < n_r < p} \frac{1}{n_1^{k_1}\cdots n_r^{k_r}}

ここで、各 n_i は 1 から p-1 のあいだの整数だから、\bmod\ p ではすべて可逆である。だから 1/n_i^{k_i} は \bmod\ p で意味を持つ。\zeta_{<p}(\mathbf{k}) を \bmod\ p で見たものは、\mathbb{Z}/p\mathbb{Z} の元として well-defined である。

これらをすべての素数 p にわたって束ねたものが、有限多重ゼータ値である。形式的には、各 \mathbb{Z}/p\mathbb{Z} の直積を、有限個の成分しか非零でないものの直和で割った環 ── Zagier が「貧者のアデール(poor man’s adeles)」と呼んだ環 ── のなかで考える。これは Kaneko–Zagier によって体系化された対象である。

この有限体的な世界では、Fermat の小定理 a^{p-1} \equiv 1 \pmod p が効いてくる。指数を p-1 ずらしても値が変わらない、という「折り返し」が生じ、指数や重さの扱いが無限和のときとは構造的に違ってくる。連続的な解析の世界ではなく、合同式と組合せ論の世界である。

そして、この世界にも双対性がある。Hoffman 双対性である。

大雑把に言えば、指数列 \mathbf{k} に対して Hoffman 双対 \mathbf{k}^{\vee} と呼ばれる別の指数列が、組合せ的な変換によって定まり、\zeta_{<p}(\mathbf{k}) と \zeta_{<p}(\mathbf{k}^{\vee}) のあいだに、\bmod\ p の合同関係が成り立つ。典型的には符号付きの関係である。

ここで注意を入れておきたい。Hoffman 双対性の正確な定式化には複数の流儀がある。符号、添字の規約、star 版(等号 \leq を許す和)か non-star 版(< の和)か ── こうした選択によって、正確な式は変わる。本記事は見取り図を重視する立場なので、正確な符号付き合同式は断定しない。ここで述べたいのは、構造の質である。

その質とは:Hoffman 双対性は、反復積分の幾何から来るのではない、ということだ。それは、有限和そのものの組合せ的な変換、あるいは \bmod\ p の合同式の操作として現れる。MZV の双対性に「似ているが、しかし別物」── これが Hoffman 自身による特徴づけである。同じ「双対性」という名前を持ちながら、出どころが違う。

5. 二つの双対性を並べる

同じ母体 \zeta_{<N} から、二つの扉の先に、姿の異なる双対性が現れた。並べてみよう。

N \to \infty N = p(素数)
得られる対象 通常の多重ゼータ値 \zeta(\mathbf{k}) 有限多重ゼータ値(\bmod\ p)
住む世界 解析的・幾何的 有限体的・合同式的・組合せ的
双対性の名前 MZV の双対性 Hoffman 双対性
双対性の源 反復積分、変数変換 t \mapsto 1-t 有限和の組合せ変換、\bmod\ p 合同
双対指数 \mathbf{k}^{\dagger}(反復積分的・0/1 入れ替え) \mathbf{k}^{\vee}(Hoffman 双対、組合せ的)
双対性の式 \zeta(\mathbf{k}) = \zeta(\mathbf{k}^{\dagger}) \zeta_{<p}(\mathbf{k}) \equiv \pm\,\zeta_{<p}(\mathbf{k}^{\vee}) \pmod p(典型的に)

注目したいのは、双対指数の作り方からして違うことだ。\mathbf{k}^{\dagger} は反復積分の語を逆順にして 0/1 を入れ替える、幾何由来の操作で得られる。\mathbf{k}^{\vee} は有限和の構造に根ざした、組合せ由来の操作で得られる。両者は一般に一致しない。同じ指数列から出発しても、\infty の扉と p の扉では、別の相手と対になる。

それでも ── 出発点はひとつの \zeta_{<N} だった。同じ有限切断和が、N の選び方ひとつで、解析的双対性と有限的双対性という二つの対称性を生み分ける。この構造そのものが面白い。

6. まとめ:無限と有限のあいだの橋

有限切断多重ゼータ和 \zeta_{<N} は、単なる MZV の近似ではなかった。それは、通常の多重ゼータ値と有限多重ゼータ値を結ぶ、発想の足場である。

  • N \to \infty は「解析的な無限極限」── そこでは反復積分の幾何が支配し、双対性は t \mapsto 1-t という 0/1 入れ替えとして見える。
  • N = p は「有限体的な特殊化」── そこでは合同式と組合せ論が支配し、双対性は Hoffman 双対性という有限的な変換として見える。

多重ゼータ値の「双対性」は、ひとつの言葉でありながら、無限の側では反復積分の幾何という顔を、有限の側では Hoffman 双対性という組合せ・合同式の顔を持つ。

そしてこの二つの顔は、\zeta_{<N} という共通の母体を通して、ゆるやかにつながっている。\zeta_{<N} は、多重ゼータ値の世界における「無限」と「有限」のあいだに架かる橋として理解できる ── これが、本記事で描きたかった見取り図である。
