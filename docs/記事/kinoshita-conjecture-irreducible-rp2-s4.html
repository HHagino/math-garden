樹下予想が破れたかもしれない：S⁴ 内の既約な実射影平面と、基本群で斬る4次元トポロジー

注意（2026-05-16 JST 時点）. 本記事は 2026-05-16 JST 時点で確認できる arXiv v1（プレプリント初版）に基づく整理であり、査読済みの確定版ではない。したがって以下はすべて「論文の主張が正しければ」という留保のもとで読んでほしい。検証は今後の専門家の精査を待つ必要がある。

1. 導入：基本群で予想を斬る

曲面結び目理論には、「樹下予想（Kinoshita conjecture）」という有名な未解決問題がある。その予想に、否定的な反例が出たらしい ―― 2026 年 5 月の arXiv プレプリントが、S^4 の中に予想に反する曲面を具体的に構成した、と主張している。

驚いたのは、解決の道具立てだ。4次元トポロジーで「難問が解けた」と聞けば、ふつう身構えるのはゲージ理論である。Donaldson 理論、Seiberg–Witten 理論、各種の Floer 理論 ―― 4次元の深い問題は、たいていこうした重い解析的不変量で攻略されてきた。ところが今回の論文は、それらをこの問題には使っていない。使っているのは、補空間の基本群、とりわけ peripheral subgroup（周辺部分群） という、見かけはかなり古典的な群論的データである。

びっくりした、というのが正直な第一印象だった。本記事では、その驚きを「すごい」で終わらせず、「では、どの不変量が実際に効いて予想を斬ったのか」まで降りて整理してみたい。

2. 樹下予想とは何だったのか

まず舞台を説明する。曲面結び目理論とは、4次元空間 S^4 の中に2次元の曲面が埋め込まれている状況 ―― 曲面結び目（knotted surface） ―― を扱う分野である。1次元の結び目（S^3 内の円周）の、次元を一つずつ上げた版だと思えばよい。

今回の主役は、曲面のうち実射影平面 \mathbb{RP}^2 である。\mathbb{RP}^2 は向きづけ不可能な閉曲面で、これが S^4 になめらかに埋め込まれる。いちばん素直な埋め込み方を標準的な非結び目 \mathbb{RP}^2 と呼ぶ（結ばれていない、基準となる埋め込み）。

曲面結び目には「足し算」がある。連結和だ。二つの曲面結び目から、それぞれに小さな穴を開けて筒でつなぎ、一つの曲面結び目を作る。とくに、ある \mathbb{RP}^2 と、2次元球面の結び目 ―― 2-結び目 S^2\subset S^4 ―― を連結和すると、また \mathbb{RP}^2 ができる。

樹下予想は、おおまかに言えばこうだ：

S^4 内のすべての（結び目付き）\mathbb{RP}^2 は、標準的な非結び目 \mathbb{RP}^2 と、ある 2-結び目 S^2 との連結和として表せるはずだ。

この形 ―― 非結び目 \mathbb{RP}^2 ＋ 2-結び目 ―― で書ける曲面を Kinoshita type と呼ぶ。予想は「\mathbb{RP}^2 の結ばれ方の複雑さは、すべて『おまけの 2-結び目』に押し込められる」と言っている。逆に言えば、そう分解できる \mathbb{RP}^2 を 可約（reducible）、分解できないものを 既約（irreducible） と呼ぶことにすると、予想は「S^4 内の \mathbb{RP}^2 はすべて可約だ」という主張になる。

樹下予想への反例とは、すなわち既約な \mathbb{RP}^2\subset S^4 を一つ作ってみせることである。

3. 新しい論文の主張

その既約な例を構成した、と主張するのが次の論文だ。

  • Mark Hughes, Seungwon Kim, Maggie Miller, Gheehyun Nahm, An irreducible real projective plane in the 4-sphere, arXiv:2605.12921（2026-05-13 投稿）。

タイトルがそのまま結論を言っている ―― 「4次元球面内の既約な実射影平面」。論文の中心となる Theorem 1.1 は、要するに次を主張する：

なめらかに埋め込まれた \mathbb{RP}^2\subset S^4 で、「結び目付き 2-球面と非結び目 \mathbb{RP}^2 の連結和」としては分解できない（＝既約な）ものが存在する。

しかも、この分解不能性はなめらかな（smooth）範囲だけの話ではない。論文によれば、局所平坦な位相的分解（topologically locally flat な連結和分解）に対しても分解不能だとされる。なめらかな圏でだめなだけでなく、より緩い位相的な圏でもだめ ―― つまり予想の破れ方が、なめらかさの微妙な差では言い訳できない、頑健なものだということだ。

主張が正しければ、これは樹下予想への明確な反例である。

4. 反例 R の構成

論文は反例となる \mathbb{RP}^2 を R と名づけ、いくつかの古典的な構成を組み合わせて作る。専門外の読者のために、流れだけ追えるように説明する。

出発点は half-spin、mapping torus、そして generalized knot surgery（一般化結び目手術） といった操作だ。

  • mapping torus（写像トーラス） とは、空間 X と自己同相写像 f\colon X\to X から、X\times[0,1] の両端を f で貼り合わせて作る空間のこと。「ひとひねり加えて筒を閉じる」操作だと思えばよい。
  • spinning（スピン構成） は、低次元の結び目やタングルを「回して」高次元の曲面結び目を作る古典的レシピである。half-spin はその変種。
  • knot surgery は、ある部分を切り取って別の結び目に由来するピースを貼り直す操作。

これらを組み合わせると、R は deform-spun projective plane（変形スピン射影平面） として記述できる。deform-spinning とは、ふつうのスピン構成に「変形（diffeomorphism の族＝動き）」を一枚かませた構成で、得られる曲面に余分なひねりを仕込める。

そして R の具体的な素材として現れるのが、トーラス結び目 T_{3,4} の4つの連結和

T_{3,4}\,\#\,T_{3,4}\,\#\,T_{3,4}\,\#\,T_{3,4}

に由来する古典結び目である（T_{3,4} はトーラス面上に (3,4) 型に巻きついた結び目）。

ここに、構成のうまさがある。論文の文脈によれば、既知の deform-spinning では、できあがる \mathbb{RP}^2 が可約になってしまうケースが多かった。せっかくひねっても、結局は Kinoshita type に分解されてしまう。ところが今回は、素（prime）でない ―― すなわち連結和に分かれる ―― satellite 的な古典結び目（T_{3,4} の4連結和）と、braid（組みひも）の選び方を工夫することで、その「可約に落ちる」罠をすり抜けている。可約性をすり抜ける素材選びそのものが、この構成の勘どころなのだ。

5. なぜ反例だとわかるのか：peripheral subgroup の像

構成しただけでは足りない。R が本当に既約 ―― Kinoshita type に分解できない ―― ことを証明しなければならない。ここが論文の芯であり、いちばん面白いところだ。

決定打になるのは、補空間の基本群そのもの……というより、その中の peripheral subgroup（周辺部分群）の像である。

peripheral subgroup とは何か。 曲面結び目 R のまわりに、薄い管状近傍（チューブ状の近傍）を取る。その近傍の境界は3次元多様体になる。この境界の基本群が、補空間 S^4\setminus R の基本群へと写る ―― その像が peripheral subgroup である。直観的には、「R のすぐそば」の構造、つまり曲面結び目の周辺の絡まり具合を記録した部分群だと思えばよい。1次元の結び目理論で、メリディアンとロンジチュードが張る peripheral subgroup が結び目の周辺情報を持っていたのと、ちょうど同じ役回りである。

ここから論証は、驚くほどクリーンな二段構えになる。

ステップ A（可約なら、像は小さい）. 論文の Lemma 3.1 によれば、R がもし可約な射影平面 ―― Kinoshita type に分解できる ―― なら、peripheral map の像は位数 2 になる。これは標準的な非結び目 \mathbb{RP}^2 の周辺構造を反映していて、\pi_1(\mathbb{RP}^2)=C_2（位数2の巡回群）が効いているからだ。要するに「可約なら、周辺の像は C_2 ぶんしかない」。

ステップ B（構成した R では、像が大きい）. ところが、実際に構成した R については、論文の Theorem 3.3 が、C_2\times C_2（位数4の群、いわゆるクラインの四元群）が補空間の基本群の側に単射的に入ることを示す。これにより、R の peripheral subgroup の像は少なくとも位数4、より精密にはちょうど位数4になる。

結論. 可約なら像は位数2のはず。しかし構成した R では像が位数4。位数2と位数4は一致しえない。したがって R は可約ではない ―― 既約である。これが樹下予想への反例性の核心だ。

論証の形に注目してほしい。重い解析的不変量は出てこない。出てくるのは「ある部分群の像の位数」という、有限群論のいちばん素朴な量である。それでも、2\neq4 というただ一行の不等式が、長らく未解決だった予想を斬っている。「どの不変量が効いたのか」と問えば、答えははっきりしている ―― peripheral subgroup の像の位数だ。

6. Klein bottle 版の帰結

論文はさらに一歩進み、R 自身の連結和 R\,\#\,R も調べる。\mathbb{RP}^2 二枚の連結和はクラインの壺（Klein bottle）になるので、これは Klein bottle の曲面結び目の話になる。

向きづけ不可能な曲面が4次元多様体に埋め込まれるとき、正規 Euler 数（normal Euler number） という整数不変量が定まる。これは法束のねじれを測る量で、曲面の種類ごとに取りうる値の範囲が決まっている。論文によれば、R\#R は正規 Euler 数が極値（取りうる端の値）をとる、既約な Klein bottle の例を与える。

ここでも武器は peripheral subgroup だが、効き方が少し違う。R\#R については、peripheral subgroup が無限群になることが示される。一方、論文の Lemma 3.7 は「可約な Klein bottle なら peripheral subgroup は有限」だと言う。無限と有限は両立しない ―― よって R\#R も既約。第5節の「位数2 対 位数4」が、ここでは「有限 対 無限」に置き換わった、同じ論法である。

この帰結により、論文は Kirby の問題リスト（低次元トポロジーの有名な問題集）の Problem 4.37 に関連する問いにも答える位置づけになる、とされている。一つの構成が、予想への反例と、問題リストへの応答とを同時に提供している、という収穫の多さも、この論文の見どころだ。

7. 使われている道具：何が「重くない」のか

「高度な理論を使っていない」とだけ書くと雑になるので、実際に何が使われているのかを挙げておく。論文の道具立ては、おおむね次のものである。

  • Seifert–van Kampen の定理 ―― 空間を貼り合わせたとき、基本群がどう合成されるかを与える基本定理。補空間の基本群を計算する屋台骨。
  • mapping torus ―― 第4節で触れた、構成側の道具。
  • pushout ―― 図式の貼り合わせ。van Kampen を圏論的に運用するための言語。
  • Serre 流の群論的議論（融合積や群の樹への作用）―― 基本群の構造を、部分群の貼り合わせとして制御する。
  • 有限群の商の計算 ―― 第5節の「位数4の群が単射的に入る」を実際に確かめる部分。
  • GAP による群計算 ―― 有限群の計算機代数システム。具体的な群の位数や元の位数を計算で確認する。

とくに Lemma 3.4 では、トーラス結び目 T_{3,4} の meridian（メリディアン）/ longitude（ロンジチュード） に関する単射性を GAP で確認している。そこでは、位数 48 の有限群や、meridian・longitude にあたる元の位数が 2 であること、といった具体的な数値計算が現れる。

ここで誤解を避けたい。GAP の計算は「魔法の箱」ではない。論証の骨格 ―― 可約性と peripheral subgroup の像を結ぶ補題群 ―― はあくまで人間の手による幾何学・群論の議論であり、GAP は「ある有限群の中で、特定の元が確かに望みの位数を持つ／単射的にふるまう」という補助的な確認を担っているにすぎない。とはいえ、こうした具体的な有限群計算が証明の一部に組み込まれているのも、この論文の率直で手触りのある味わいだと思う。

そして、ここで「重くない」の意味も正確にしておきたい。本記事は「ゲージ理論は不要だった」と一般化するつもりはない。4次元トポロジーの多くの問題で、ゲージ理論はいまも本質的だ。言えるのは限定的なこと ―― この樹下予想という特定の問題に対しては、ゲージ理論や Floer 理論を使わずに、補空間の基本群と peripheral subgroup の情報だけで反例性が示せた、ということである。それ自体が十分に驚くべき事実だ。

8. 何がそんなに面白いのか

改めて、面白さの構図を言葉にしておく。

4次元トポロジーには、「深い問題には深い（＝解析的に重い）不変量が要る」という、経験則というか雰囲気がある。実際、4次元多様体の分類や、エキゾチック構造の検出では、ゲージ理論的不変量が決定的な役割を果たしてきた。

ところが今回の樹下予想は ―― 主張が正しければ ―― その雰囲気の外側で斬られた。決め手は、補空間の基本群という古典的な代数的データ、さらに言えばその中の peripheral subgroup の像という、周辺構造の群論的指標だった。「可約なら像は小さい（位数2／有限）」「構成した例では像が大きい（位数4／無限）」―― この対比一発で、曲面の既約性が確定する。

これは、不変量の選び方についての教訓でもある。問題に対して「正しい不変量」を当てられれば、論証は驚くほど短く、透明になる。今回 peripheral subgroup が「正しい不変量」だったのは、それが可約性そのものを直接に制約する量だったからだ。可約な曲面の周辺構造には、\pi_1(\mathbb{RP}^2)=C_2 という強い縛りがある。だから「周辺の像が C_2 より大きい」と示せれば、それはそのまま「可約でない」になる。重い不変量で殴るのではなく、可約性の定義に最短距離で噛み合う量を見つけてきた ―― そこにこの論文の鮮やかさがある。

横断メモ(位相クラスタ). ここで効いている \pi_1(\mathbb{RP}^2)=C_2 という縛りそのもの、そして「どの不変量が空間の何を見て何を見落とすか」という選び方の問題は、別記事「弧状連結・単連結・可縮 ── 不変量は何を見て何を見落とすか」で、\pi_1・ホモロジー・ホモトピー群の解像度の差として基礎から扱っている(\mathbb{RP}^2 の \pi_1\cong H_1\cong\mathbb{Z}/2 も、その「H_1=可換化」の節に出る)。本記事の周辺部分群論法は、その「正しい不変量を当てる」威力の4次元版だと見てよい。

9. 結び

繰り返しになるが、これは arXiv v1 の段階の主張である。今後、専門家による検証 ―― peripheral subgroup の像の計算、Theorem 3.3 の単射性、GAP 計算の再現性などの精査 ―― を経る必要がある。だから本記事も「樹下予想は解決された！」とは書かない。書けるのは、こうだ ―― arXiv v1 の主張が正しければ、樹下予想は否定的に解決されたことになり、それは曲面結び目理論における非常に鮮やかな反例構成である。

S^4 内に既約な \mathbb{RP}^2 を一つ作り、その既約性を「周辺部分群の像の位数」というたった一つの古典的データで確定させる。重い機械を持ち出さず、補空間の基本群の周辺構造で4次元トポロジーの長年の予想を斬ってみせる ―― もし主張どおりなら、これは「正しい不変量を当てる」ことの威力を、これ以上なく明快に見せてくれる仕事である。続報を待ちたい。
