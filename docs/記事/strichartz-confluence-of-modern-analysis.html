Strichartz 評価という合流点 ── 微分方程式の授業が突然「現代解析」になるとき

微分方程式の授業のはずだったのに

「解析の話題にもついていけるようにと履修した微分方程式の授業が Strichartz 評価に突入し、予備知識の不足を痛感……」

このつぶやきは、たぶん多くの学習者が一度は通る局面を、ほとんど痛いくらい正確に切り取っている。微分方程式の授業として履修したはずだったのに、いつの間にか黒板にはこんな式が書かれている。

\|u\|_{L^q_t L^r_x} \le C \|u_0\|_{L^2_x}.

ここで u(t,x) は Schrödinger 方程式や波動方程式といった「分散型 PDE」の解、u_0 はその初期データである。左辺には時間と空間の二重のノルムが並び、右辺はただの初期データの L^2 ノルム。一見シンプルなのに、何が書かれているのか直観的に掴めない。

先に種明かしをしておきたい。授業についていけないと感じたのは、能力の問題ではない。Strichartz 評価という地点は、そもそも「微分方程式」一科目の話ではないからだ。

Strichartz 評価が立っている場所

Strichartz 評価が住んでいる地点を地図上に置くと、こうなる。

  • PDE(偏微分方程式)── Schrödinger・波動・KdV など分散型方程式の解の挙動
  • フーリエ解析 ── 周波数空間でのプロパゲータの記述
  • 関数解析 ── 線形作用素のノルム評価、双対性、TT^\ast
  • 調和解析 ── L^p 上の振動積分、補間理論
  • 分散型方程式の理論 ── 非線形項を扱うための時空間ノルム

Strichartz 評価は、これら五つが合流する地点にある。微分方程式の授業で初めて出会うとき、つまずいているのは「ここまでの授業の続き」ではない。「ここから先は今までと別の世界です」という壁のほうだ。

だから、予備知識不足を感じるのはむしろ正しいセンサーが働いている証拠である。Strichartz 評価とは、計算中心の常微分方程式や初等的な PDE の延長ではなく、関数空間上の力学系としての現代解析 PDE への入口の標識なのだ。

エネルギー保存と Strichartz 評価 ── 二つの世界観の違い

まず、自由 Schrödinger 方程式 i\partial_t u = -\Delta u の解は、よく知られたエネルギー保存則

\|u(t)\|_{L^2_x} = \|u_0\|_{L^2_x}

を満たす。これは「各時刻ごとに、解の総量(2乗積分)は変わらない」というステートメントだ。時間 t を固定して、その瞬間の空間プロファイルだけを見ている。

これに対して Strichartz 評価

\|u\|_{L^q_t L^r_x} \le C \|u_0\|_{L^2_x}

は、時間と空間をまとめて測る。左辺は、まず各時刻 t に対して空間 L^r ノルム \|u(t,\cdot)\|_{L^r_x} を取り、それを時間方向に L^q で積分したもの ── いわゆる混合ノルム L^q_t L^r_x である。

エネルギー保存が「各時刻のスナップショットの大きさ」を述べているのに対して、Strichartz 評価は「解が時間と空間にどれくらい散らばっているか」を述べている。この「散らばる」という挙動こそ、分散性(dispersion)と呼ばれるものだ。

Schrödinger 方程式や波動方程式の解は、初期データが空間的に局在していても、時間が経つにつれて広がっていく。直観的には、波数 \xi ごとに伝播速度が異なるから、初期に集中していた波束が時間発展でほぐれていく。Strichartz 評価は、この「ほぐれていく速度」を時空間ノルムで定量化したものだ。

ここで授業の難しさが正体を見せる。エネルギー評価は微分方程式の中だけで完結するが、Strichartz 評価は「分散性を測る」ために、PDE の外にある道具を呼び出さざるを得ない。

なぜ予備知識が一気に厚くなるのか

Strichartz 評価に必要になりやすい予備知識を、関係順に並べてみよう。これは目次ではなく、「なぜ授業が急に難しく感じたのか」の構造そのものでもある。

L^p 空間と Hölder 不等式。混合ノルム L^q_t L^r_x の意味を読むためには、まず L^p 空間が身体になじんでいる必要がある。Hölder 不等式 \|fg\|_{L^1} \le \|f\|_{L^p}\|g\|_{L^{p'}} は、後で出てくる admissible 条件 \tfrac{2}{q}+\tfrac{n}{r}=\tfrac{n}{2} のような「指数のバランス」を読むための文法に当たる。

混合ノルム L^q_t L^r_x。時間と空間で別々の指数を使うこと自体が新鮮なはずだ。これは「時間方向の挙動」と「空間方向の挙動」を独立に評価するための装置である。

Fourier 変換。Schrödinger プロパゲータ e^{it\Delta} は、Fourier 側では掛け算作用素

\widehat{e^{it\Delta} u_0}(\xi) = e^{-it|\xi|^2}\, \widehat{u_0}(\xi)

として書ける。つまり、周波数 \xi ごとに位相が e^{-it|\xi|^2} で回る、という非常にクリーンな描像になる。Strichartz 評価の証明は本質的に、この「周波数ごとの位相回転」を時空間ノルムに翻訳する作業だ。

Schrödinger 方程式の解表示 u(t)=e^{it\Delta}u_0。Fourier 変換で書き下した一行だが、ここで e^{it\Delta} を「線形作用素として」見る視線が育つかどうかが、関数解析的視点への分岐点になる。

L^2 \to L^2 ユニタリ性。位相 e^{-it|\xi|^2} は絶対値が 1 なので、Plancherel から e^{it\Delta} は L^2 ノルムを保つ。これは先のエネルギー保存と同じ事実を、Fourier 側から見たものだ。

L^1 \to L^\infty 型の分散評価。一方で、初期データが L^1 に入っていれば、解は時間とともに L^\infty 的に薄まる:

\|e^{it\Delta} u_0\|_{L^\infty_x} \lesssim |t|^{-n/2}\, \|u_0\|_{L^1_x}.

これは局在した波束が時間発展で広がっていくことの定量表現で、Schrödinger 方程式の分散性そのものである。

補間・双対性・TT^\ast 論法。L^2\to L^2 のユニタリ性(エネルギー)と、L^1\to L^\infty の分散評価。この二つの両端を、Riesz–Thorin 補間や双対性、そして TT^\ast 論法によって組み合わせることで、その「あいだ」にあるさまざまな混合ノルムを制御できる。これがまさに Strichartz 評価の証明の心臓部だ。

Sobolev 空間。実際の非線形問題では L^2 だけでなく H^s レベルの評価が必要になり、Sobolev 埋め込みや fractional Leibniz 則とセットで Strichartz が使われる。

Duhamel 公式。非線形項を含む方程式

i\partial_t u = -\Delta u + F(u)

の解は積分方程式

u(t) = e^{it\Delta} u_0 - i\int_0^t e^{i(t-s)\Delta} F(u(s))\, ds

の形で書かれる。線形部分は Strichartz でじかに評価でき、積分部分は inhomogeneous Strichartz で評価される。

非線形 PDE での固定点定理への応用。Strichartz ノルムで Banach 空間を作り、Duhamel 写像がその上で縮小写像になることを示す。これで Banach の不動点定理から局所解の存在と一意性が出る。

並べてみると、これらは「微分方程式」の章末問題には絶対に書いていないラインナップだ。授業が難しく感じたのは、当然のことだった。

Strichartz 評価の証明の雰囲気

厳密な証明は他の文献に任せるとして、雰囲気だけ書いておく。標準的には次の五段階で進む。

  1. Fourier 変換で線形 Schrödinger 解を表す。 u(t)=e^{it\Delta}u_0 の Fourier 像が e^{-it|\xi|^2}\hat u_0(\xi) になる、というところから始める。
  2. L^2\to L^2 の保存。位相だけ回っているので L^2 ノルムは保存される。これは「左端」。
  3. L^1\to L^\infty の分散評価。プロパゲータの核を陽に計算すると |t|^{-n/2} で減衰することがわかる。これが「右端」。
  4. 両端を補間・双対性・TT^\ast で繋ぐ。T u_0 := e^{it\Delta}u_0 という作用素を時空間に乗る形で書き直し、TT^\ast を取ると、Hardy–Littlewood–Sobolev や Hölder で評価できる積分核が出てくる。ここで時空間混合ノルムが自然に登場する。
  5. 結論。\|e^{it\Delta} u_0\|_{L^q_t L^r_x} \le C \|u_0\|_{L^2_x} が、ある admissible な指数の組 (q,r) に対して成り立つ。

最初に読むときは、(2) と (3) という両端から (4) の補間で内部の評価が湧き出すこと、そして (4) で時間方向のノルム L^q_t が自然に出てくることだけ押さえれば十分だ。endpoint (q,r)=(2, \tfrac{2n}{n-2}) の処理(Keel–Tao)など、本当に難しいところは後回しでよい。

なぜ非線形 PDE に効くのか ── Duhamel と不動点

Strichartz 評価が単なる「線形理論の華麗な評価式」で終わらないのは、非線形 PDE の解の構成に直接効くからだ。

非線形 Schrödinger 方程式 i\partial_t u = -\Delta u + |u|^{p-1}u を考えると、Duhamel 公式

u(t)=e^{it\Delta}u_0 - i\int_0^t e^{i(t-s)\Delta} F(u(s))\, ds, \qquad F(u)=|u|^{p-1}u

の右辺を u に関する写像 \Phi(u) と見て、適切な Strichartz 空間 X = L^q_t L^r_x \cap C_t L^2_x の上で

\|\Phi(u)\|_X \le C\|u_0\|_{L^2} + C\,\big\| |u|^{p-1}u \big\|_{L^{\tilde q'}_t L^{\tilde r'}_x}

のような評価を出す。後者は Hölder で \|u\|_X^p に押し戻せる。すると小さなボールの中で \Phi は縮小写像になり、Banach の不動点定理で局所解の存在と一意性が従う。

Strichartz 評価はここで、「線形プロパゲータがどれだけ嬉しく時空間に乗るか」を保証することで、非線形項という邪魔者を吸収できるだけの余裕を作っている。エネルギー保存だけでは、この種の非線形不動点議論は回らない。各時刻ごとの L^2 では情報が薄すぎるのだ。

学び直しのロードマップ

Strichartz 評価で挫折しかけたとき、次の順番で建て直すと負担が分散する。

  1. L^p 空間と Hölder 不等式。指数の代数(双対指数、\tfrac{1}{p}+\tfrac{1}{p'}=1)が身体になじむまで。
  2. Fourier 変換。Plancherel、たたみ込みと積、Schwartz 空間。
  3. Sobolev 空間 H^s。Fourier 側での (1+|\xi|^2)^{s/2} 重み、埋め込み定理。
  4. 線形 Schrödinger 方程式・波動方程式の解表示。Fourier 変換で書く u(t)=e^{it\Delta}u_0、波動方程式の解表示。
  5. L^2 保存と L^1\to L^\infty 分散評価。エネルギー保存を Fourier 側から見直し、プロパゲータ核の |t|^{-n/2} 減衰を計算する。
  6. 混合ノルム L^q_t L^r_x の定義と Minkowski 不等式。
  7. Duhamel 公式。線形項と非線形項の分離。
  8. Strichartz 評価を「黒箱」として使う練習。証明は読まなくていい。まず admissible pair に対する不等式を認めて、非線形 Schrödinger の局所適切性を構成する演習をする。
  9. 余力があれば、補間・双対性・TT^\ast による証明。Keel–Tao の endpoint Strichartz 論文がゴール。

特に 8 番、「まず黒箱として使う」というステップを飛ばさないことが、心理的にもいちばん大事だ。証明を完全に理解してから使うのではなく、使いながら証明に近づいていくほうが、この分野では結局速い。

まとめ ── 名前の付け方が悪いだけ

Strichartz 評価とは、解が時間と空間にどれくらい散らばるかを測る、現代 PDE の基本道具である。Schrödinger 方程式や波動方程式といった分散型 PDE の解について、L^2 という単一時刻のノルムでは捉えきれない「時間発展による広がり」を、時空間混合ノルムで定量化する。

そして、これが「微分方程式」という名前の授業に出てきても、その中身は分散型 PDE のための調和解析である。フーリエ解析・関数解析・補間理論・振動積分の理論がそろって背後に立っていて、それらの上にようやく Strichartz 評価が建っている。だから、予備知識不足を感じるのはむしろ正しいセンサーが働いている証拠であって、能力の問題ではない。

授業の名前が「微分方程式」のままだったのが少し罪深い、というだけの話だ。あなたは、関数空間上の力学系としての現代解析 PDE の入口に立っている。地図さえあれば、ここから先は怖くない。
