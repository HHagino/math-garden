可解群はなぜ「可解」なのか ── 方程式が根号で解けることの群論的な核心

可解群はなぜ「可解」なのか ── 方程式が根号で解けることの群論的な核心

1. 導入:可解群という名前の不思議

群論を学んでいくと、どこかで「可解群(solvable group)」という名前に出会う。定義はこうだ。群 G が可解であるとは、正規部分群の列

G = G_0 \ \triangleright\ G_1 \ \triangleright\ \cdots \ \triangleright\ G_r = \{1\}

があって、各商群 G_i / G_{i+1} がすべてアーベル群になることをいう。

最初に見ると、これは群論の内部だけで完結した、技術的な専門用語に見える。「可解」という日本語(英語の solvable)も、何が「解ける」のかよく分からない。

しかし、この名前は文字どおり「方程式が解ける」ことと結びついている。Galois 理論の中心的な定理のひとつは、

方程式が根号で解ける \iff そのガロア群が可解群である

と述べる。「可解」という名前は、方程式論からの由来なのだ。

本記事は、この対応をたどる。とりわけ強調したいのは、なぜ商群がアーベルでなければならないのか、という一点である。

2. 根号で解くとは何をしているのか

「方程式を根号で解く」とは、具体的に何をすることなのか。

いちばん馴染み深いのは二次方程式の解の公式だ。

ax^2 + bx + c = 0 \quad \Longrightarrow \quad x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

係数 a, b, c から出発して、四則演算と平方根 \sqrt{\ } だけを使って根を書き下している。

三次・四次方程式にも(かなり複雑になるが)解の公式があり、四則演算と平方根・立方根を使って根が書ける。

一般化すると、「根号で解ける」とは次のようなことだ。方程式の係数が住んでいる体 K から出発して、

K \ \xrightarrow{\ \text{何かの } n \text{ 乗根を添加}\ } \ K_1 \ \xrightarrow{\ \text{何かの } n \text{ 乗根を添加}\ } \ K_2 \ \xrightarrow{\quad}\ \cdots \ \longrightarrow\ K_r

と体を少しずつ大きくしていき、最終的に方程式の根をすべて含む体 K_r にたどり着く。

各ステップは「何かの n 乗根をひとつ添加する」操作である。これを冪根添加(radical extension)と呼ぶ。

つまり、方程式が根号で解けるとは、根を含む体まで、冪根添加の有限列で到達できることである。

3. n 乗根の添加と巡回的な対称性

冪根添加 K_i \to K_{i+1} = K_i(\alpha)(\alpha は \alpha^n = a \in K_i を満たす)を一段、対称性の目で見てみよう。

話を単純にするため、K_i は 1 の原始 n 乗根 \zeta_n を十分に含んでいるとする。1

このとき、\alpha^n = a の解は

\alpha,\quad \zeta_n \alpha,\quad \zeta_n^2 \alpha,\quad \dots,\quad \zeta_n^{n-1}\alpha

の n 個である。拡大 K_i(\alpha)/K_i の自己同型 \sigma は、\alpha をこれらの解のどれかに移すしかない。つまり

\sigma(\alpha) = \zeta_n^{k}\, \alpha \qquad (\text{ある } k)

の形になる。ここで、二つの自己同型を合成するとどうなるかを見る。\sigma(\alpha) = \zeta_n^{j}\alpha、\tau(\alpha) = \zeta_n^{k}\alpha ならば、

(\sigma\tau)(\alpha) = \sigma(\zeta_n^{k}\alpha) = \zeta_n^{k}\,\sigma(\alpha) = \zeta_n^{j+k}\,\alpha

合成すると、指数 k が足し算されるだけだ。だからこの拡大の自己同型群は、\mathbb{Z}/n\mathbb{Z} の(部分)群 ── すなわち巡回群になる。そして巡回群はアーベル群である。

ここが要点だ。単位根を十分に含む状況での一回の n 乗根添加が生む対称性は、\alpha \mapsto \zeta_n^k \alpha という「単位根を掛ける」操作であり、巡回的・アーベル的である。

冪根添加で一度に処理できる対称性は、本質的にこの巡回的・アーベル的なものに限られる。これが、このあとの議論の核になる。

4. ガロア対応:正規部分群列と中間体の塔

ここで Galois 対応を思い出す。Galois 拡大 L/K について、中間体と \mathrm{Gal}(L/K) の部分群が対応し、その対応は包含の向きを逆転させる(体が大きいほど、対応する群は小さい)。

さらに、この対応のもとで「正規部分群」と「正規拡大」が対応する。部分群 H が正規部分群であることは、対応する中間体 M が K 上で正規(Galois)であることと同値で、このとき

\mathrm{Gal}(M/K) \ \cong\ \mathrm{Gal}(L/K)\,/\,H

が成り立つ。商群が、下半分の拡大の Galois 群として現れるのである。

さて、方程式が冪根で解けるとしよう。すると §2 のとおり、根を含む体まで冪根添加の塔がある。

K = K_0 \ \subset\ K_1 \ \subset\ \cdots\ \subset\ K_r \qquad (K_r \text{ は根をすべて含む})

この体の塔を、Galois 対応で群の列に翻訳する。2

G = G_0 \ \triangleright\ G_1 \ \triangleright\ \cdots\ \triangleright\ G_r = \{1\}

体が大きくなることが、群が小さくなることに対応する(包含の逆転)。そして、各段 K_i \subset K_{i+1} が冪根添加 ── §3 で見たアーベルな拡大 ── であることが、群の言葉では

G_i / G_{i+1} \ \text{ がアーベル群}

に翻訳される。

これはまさに、§1 で挙げた可解群の定義そのものである。だから、

方程式が根号で解ける \iff そのガロア群が可解群

という対応が成り立つ。

5. なぜ「商群」がアーベルなのか

ここが記事の核心である。なぜ、商群がアーベルでなければならないのか。

正規部分群列

G = G_0 \ \triangleright\ G_1 \ \triangleright\ \cdots\ \triangleright\ G_r = \{1\}

を、「対称性を段階的にほどいていく過程」として読んでみよう。

各段で、二つの登場人物がいる。

  • 正規部分群 G_{i+1} は、「この段ではまだ触らない、次に回す対称性」あるいは「すでに解決済みとして、いったん無視する対称性」だと見なせる。G_{i+1} が正規部分群であるからこそ、それで割る操作(剰余を取る操作)がきちんと群になる。
  • 商群 G_i / G_{i+1} は、「この段で新しく処理する対称性の差分」を表す。G_i が持っている対称性のうち、G_{i+1} ではまだ説明されていない、ちょうどその段ぶんの差。

「ガロア群を段階的に小さくする」(G_i \to G_{i+1})ことは、ガロア対応によって「中間体を段階的に大きくする」(K_i \to K_{i+1})ことに対応していた。

そして §3 で見たとおり、冪根添加で一度に処理できる差分 ── 一段の K_i \to K_{i+1} ── は、単位根を掛ける \alpha \mapsto \zeta_n^k\alpha という、巡回的・アーベル的なものに限られる。

したがって、その差分を表す商群 G_i / G_{i+1} は、アーベルでなければならない。

ここで強調したい区別がある。

ガロア群 G 全体がアーベルである必要はない。 要求されるのは、段階ごとの差分である商群 G_i/G_{i+1} がアーベルであることだ。

たとえ話を一つ(ただし、たとえ話は定理ではない)。G 全体が複雑に絡まった結び目だとしても、それを「一段ずつ」ほどいていけるなら、そして各段のほどき方が単純(アーベル)であるなら、それでよい。問題になるのは全体の複雑さではなく、一段ぶんの差分の単純さなのである。

6. S₃ の例:非可換でも根号で解ける

一般の三次方程式のガロア群は、3 文字の対称群 S_3(位数 6)である。S_3 は非可換である(たとえば互換の合成は順序によって結果が変わる)。

それでも、三次方程式は根号で解ける(カルダノの公式)。なぜか。

S_3 は、次の正規部分群列を持つ。

S_3 \ \triangleright\ A_3 \ \triangleright\ \{1\}

ここで A_3 は 3 次交代群(位数 3、巡回群 C_3 に同型)である。商群を計算すると、

S_3 / A_3 \ \cong\ C_2 \quad (\text{位数 }2,\ \text{アーベル}) A_3 / \{1\} \ \cong\ A_3 \ \cong\ C_3 \quad (\text{位数 }3,\ \text{アーベル})

各段の商群がアーベルである。よって S_3 は可解群だ。

意味を噛みしめよう。三次方程式の対称性 S_3 は、全体としては非可換である。しかし、その非可換性を C_2 と C_3 という二つの可換な段階に分解できる。 C_2 は平方根の段に、C_3 は立方根の段に対応する。だから三次方程式は、冪根添加を二段重ねることで解ける。

「非可換だが可解」── 全体としての非可換性が、アーベルな段差の積み重ねへとほどけていく。これが三次方程式の姿である。

7. S₅ と A₅:一般五次が解けない理由

一般の五次方程式のガロア群は、5 文字の対称群 S_5(位数 120)である。

S_5 を可解にしようと、正規部分群列を作ろうとすると、A_5(5 次交代群、位数 60)が現れる。S_5 \triangleright A_5 \triangleright \cdots と続けて、各商をアーベルにできるかどうか ── これが可解性の分かれ目になる。

S_5 / A_5 \cong C_2 までは問題ない。困るのは、A_5 から先である。

A_5 は、非可換単純群である。単純群とは、自明でない正規部分群を持たない群のこと ── つまり、\{1\} と自分自身 A_5 以外には、正規部分群がまったく存在しない。

これが致命的だ。A_5 を含む正規部分群列 A_5 \triangleright N \triangleright \cdots を作ろうとしても、N として選べるのは \{1\} か A_5 しかない。

  • N = A_5 なら、何も進まない。
  • N = \{1\} なら、商群 A_5/\{1\} \cong A_5 が現れる。これは非可換である。

つまり、A_5 の非可換性は、アーベルな商群の段階に分解できない。一段でほどこうとすると、その一段がまるごと非可換な A_5 になってしまう。

したがって S_5 は可解群ではない。ゆえに、一般の五次方程式は根号で解けない。これがアーベル–ルフィニの定理の、Galois による群論的な核心である。3

対比すると、こうなる。

方程式 ガロア群 非可換性の運命 根号で解けるか
一般三次 S_3 C_2 と C_3 にほどける 解ける
一般五次 S_5 A_5 という「ほどけない非可換の核」を含む 解けない

一般の五次方程式が解けないのは、根の公式の探し方が下手だからではない。S_5 の内部にある A_5 が、非可換性を可換な層へと分解させない ── そういう群論的な障害が存在するからである。

8. まとめ:根号で解けるとは、対称性をアーベルな層に分解できるということ

歩いてきた道を、対称性の言葉でまとめよう。

  • 方程式を根号で解くとは、係数体から冪根添加の塔を登り、根を含む体に到達することだった。
  • 一段の冪根添加が生む対称性は、単位根を掛ける \alpha \mapsto \zeta_n^k\alpha という、巡回的・アーベル的なものだった。
  • ガロア対応によって、体の塔は正規部分群列に翻訳され、各段の冪根添加は「商群 G_i/G_{i+1} がアーベル」に翻訳された。
  • だから、根号で解けるためには、ガロア群全体がアーベルである必要はない。要求されるのは、段階ごとの差分である商群がアーベルであることだった。
  • S_3 は非可換でも、C_2 と C_3 にほどけるから、解ける。
  • S_5 は A_5 という非可換単純群を含み、その非可換性をアーベルな層に分解できないから、解けない。

可解群の「可解」という名前は、こうして方程式論に帰っていく。

根号で解けるとは、方程式の根を直接見つける魔法ではなく、その背後にある対称性を、巡回的・アーベル的な層へと一段ずつほどいていける、ということなのである。

横断メモ(Galoisクラスタ). 本記事は群論の核(可解列=アーベル層への分解)。これを5次方程式の分類・判定まで具体化したのが別記事「ガロア理論の入門講義は、なぜ『おいしいところ』の手前で終わるのか」(S₅ の5つの推移的部分群、Dummit のリゾルベント判定、x^5-2=F_{20})── 兄弟記事だ。さらに「アーベル ⇄ 分解できる/非可換 ⇄ できない」は、「Galois 理論を線形代数として見る」の「アーベル ⇄ 同時対角化できる(1 次元固有空間に割れる)/非可換 ⇄ 2 次元以上の既約ブロックが残る」と、また「可換な作用素は同時対角化できる」(別記事「可換な対角化可能行列は同時対角化できる」)と、同じ一つの事実の別表現である。\alpha\mapsto\zeta_n^k\alpha という巡回的対称性は、それらの固有値そのものだ。可換性が分解を許し、非可換性(A_5 の単純性)が阻む ── この背骨が Galois・線形代数・量子の同時測定を貫いている。

査読・限界(解説モード)

  • 依拠する標準事実:可解群の定義(アーベル商の正規部分群列)、冪根添加が単位根を含む状況でアーベル(巡回)拡大を生むこと、ガロア対応(正規部分群 ⇄ 正規中間体・商群)、冪根可解 ⇄ ガロア群可解、S_3 可解、A_5 が非可換単純群で S_5 非可解。標準的なガロア理論。
  • 境界:議論は標数 0(または標数が関与する n を割らない)を前提、冪根の塔を含む Galois 拡大を取り直す技術的調整は脚注のとおり省略。「解ける」は「冪根で」の意(楕円関数等まで広げれば一般5次も解ける ── 別記事「ガロア…おいしいところ」「人は何を『解』と呼ぶのか」参照)。
  • 既知の理論の整理であり、新規主張を含まない。
