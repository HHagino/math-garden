場の理論の縮約密度行列は、量子情報の部分トレースと同じものなのか

公開

2026年6月2日

概要

量子情報の ρ_A = Tr_B ρ と、場の理論・多体系で相関関数や場の演算子から定義される縮約密度行列は、同じものか。Bell 状態の部分トレースを行列で手計算するところから始め、「何を縮約しているのか」を軸に、有限自由度では一致すること(Peschel の公式まで)、一粒子縮約密度行列は別物であること(Slater 行列式で確認)、連続QFTでは局所代数への状態の制限として見るべきこと(Type III・Bisognano–Wichmann・面積則)を、五枚の図と検算つきで追う。

結論を先に

短く言えば、有限自由度・格子化・モード分解では基本的に同じで、連続QFTと一粒子縮約密度行列では注意が要る。もう少し開くと:

  • サイトやモードがヒルベルト空間のテンソル因子になっている系(格子模型や、有限個のモードに分けた場の理論)では、量子情報の部分トレース \rho_A=\operatorname{Tr}_B\rho と、場の理論で「領域 A の縮約密度行列」と呼ぶものは、同じ対象の別表記だと思ってよい。
  • 「一粒子縮約密度行列」や「n 粒子縮約密度行列」は名前こそ似ているが、縮約している対象が空間領域ではなく粒子数自由度なので、目的が違う。
  • 連続的な相対論的QFTでは、空間を割っても素朴なテンソル分解が成り立たないことがある。そこでは \rho_A を「\mathcal H_A 上の密度行列」と読むより、全状態を領域 A の局所可観測量代数に制限したもの、と読むほうが正確になる。

軸は終始ひとつ、「何を縮約しているのか」だ。まず、その縮約を一度だけ手で触っておく。

0. まず手を動かす ── Bell 状態の部分トレース

抽象論より先に、計算を一つ通す。二量子ビット系 \mathcal H=\mathcal H_A\otimes\mathcal H_B(\mathcal H_A=\mathcal H_B=\mathbb C^2)の最大エンタングル状態

\lvert\Phi^+\rangle=\tfrac{1}{\sqrt2}\big(\lvert 0\rangle_A\lvert 0\rangle_B+\lvert 1\rangle_A\lvert 1\rangle_B\big)

をとる。全系は純粋状態 \rho=\lvert\Phi^+\rangle\langle\Phi^+\rvert で、行列で書けば \{00,01,10,11\} を基底とする 4\times4 行列の四隅だけに \tfrac12 が立つ。

部分トレース \operatorname{Tr}_B は、A の添字 a,a' を固定して B の対角だけ足す操作だ:(\rho_A)_{a a'}=\sum_b \rho_{(a,b),(a',b)}。これを四隅に適用すると、A の対角ブロックの対角成分(添字 00 と 11)だけが残り、A をまたぐコヒーレンス(00\leftrightarrow11、B の添字が 0 と 1 で食い違う)は和に拾われずに消える。結果は

\rho_A=\operatorname{Tr}_B\rho=\tfrac12\lvert 0\rangle\langle 0\rvert+\tfrac12\lvert 1\rangle\langle 1\rvert=\frac{I}{2}.

純粋だった全系から B を消したら、A は最大混合 I/2 になった。これがエンタングルメントの指紋だ。全体は完全に決まっているのに、片側だけ見ると何も分からない状態に潰れる。縮約とは見ない側を捨てる操作で、その代償が純粋性の喪失(混合化)である。

混合の度合いは、Bloch 球で見ると一目で分かる。純粋な一量子ビット状態は球面上の点に対応し、混合状態は内部に入る。最大混合 I/2 は球の中心、つまり「向きの情報がゼロ」の点だ。

念のため、\rho_A が A の測定を再現することも一例で確かめる。射影 O_A=\lvert 0\rangle\langle 0\rvert に対し \operatorname{Tr}(\rho_A O_A)=\tfrac12、一方 \langle\Phi^+\rvert(O_A\otimes I_B)\lvert\Phi^+\rangle=\tfrac12。両者は一致する。この再現性が、次節で \rho_A を定義に格上げする根拠になる。

1. 量子情報の縮約密度行列:部分系だけを見る

全系のヒルベルト空間が \mathcal H=\mathcal H_A\otimes\mathcal H_B と分かれ、全系の状態が密度行列 \rho(混合も含めた量子状態の記述)で与えられているとき、A の縮約密度行列は

\rho_A=\operatorname{Tr}_B\,\rho

で定義される。\operatorname{Tr}_B は B 側の自由度だけ和をとる部分トレースで、§0 で実演したとおり「B を見ないことにする」操作だ。

定義そのものより、次の性質が \rho_A の正体を言い当てている。A だけにはたらく任意の観測量 O_A について

\operatorname{Tr}_{\mathcal H_A}\!\big(\rho_A\, O_A\big)=\operatorname{Tr}_{\mathcal H_A\otimes\mathcal H_B}\!\big(\rho\,(O_A\otimes I_B)\big).

左辺は A だけの世界で測った期待値、右辺は全系で測った期待値である(§0 で O_A=\lvert0\rangle\langle0\rvert について両辺 \tfrac12 を確認した)。\rho_A とは、A 側のあらゆる測定の期待値を完全に再現する A だけの状態にほかならない。実際この再現性は部分トレースを一意に決める。つまり \operatorname{Tr}_B を「この等式を満たす唯一の線型写像」として公理的に定義してもよい。

縮約しているのは B 側の自由度。この「何を縮約したか」を毎回確かめると、以降の比較が一本の線に乗る(図3)。

2. 格子模型・有限自由度:同じもの、しかも実際に計算できる

格子模型や有限自由度の系で「領域 A の縮約密度行列」と言うとき、中身は §1 と変わらない。違うのは、それが相関関数の言葉で具体的に書き下せて、本当に計算できることだ。

自由フェルミオン格子を例にとる。領域 A のサイトの生成・消滅演算子 c_i^\dagger,c_j から相関行列 C_{ij}=\langle c_i^\dagger c_j\rangle(i,j\in A)を作る。自由フェルミオンはガウス状態(全相関が二点関数 C から Wick の定理で決まる状態)なので、領域 A の縮約密度行列はこの C だけで決まり、

\rho_A=\frac{1}{Z}\exp\!\Big(-\sum_{i,j\in A} h_{ij}\, c_i^\dagger c_j\Big)

という自由フェルミオン熱状態の形をとる。肩のエンタングルメント・ハミルトニアン h(モジュラー・ハミルトニアンとも呼ぶ)は、C から閉じた式で出る(Peschel):

h=\ln\frac{1-C}{C},\qquad\text{固有値では}\quad \varepsilon_k=\ln\frac{1-\zeta_k}{\zeta_k}\quad(\zeta_k=C|_A\ \text{の固有値}).

エンタングルメント・エントロピーも C|_A の固有値だけで書けて、S=\sum_k\big[-\zeta_k\ln\zeta_k-(1-\zeta_k)\ln(1-\zeta_k)\big]。無限次元に見えた場の縮約密度行列が、有限行列 C|_A の対角化に丸ごと帰着する。これが Peschel の方法で自由格子のエンタングルメントが実際に回る理由だ。

この対応は、どのモードがエンタングルメントを担うかも教えてくれる。\varepsilon(\zeta)=\ln\frac{1-\zeta}{\zeta} は \zeta=\tfrac12 で 0、\zeta\to0,1 で \mp\infty に発散する。\zeta が 0 や 1 に近いモードは「ほぼ空/ほぼ満杯」で凍りつき、\varepsilon の絶対値が大きく、ほとんど絡まない。逆に \zeta\approx\tfrac12 のモードがエンタングルメントの主役になる。

この \rho_A は外側 \bar A を部分トレースした \rho_A=\operatorname{Tr}_{\bar A}\rho を相関関数の言葉で書き直したもので、縮約しているのはやはり領域外の自由度だ。手続きと表記が違うだけで、対象は §0〜§1 と同じである。

3. まぎらわしい別物:一粒子・n 粒子縮約密度行列

「場の演算子で定義する縮約密度行列」には、もう一つ別の意味がある。多体系では

\rho^{(1)}(x,x')=\langle \psi^\dagger(x')\,\psi(x)\rangle

のような一粒子縮約密度行列(1-RDM)や、一般の n 粒子縮約密度行列を「縮約密度行列」と呼ぶ(\psi^\dagger,\psi は位置 x で粒子を作る/消す場の演算子)。これは §0〜§2 とは縮約の対象が違う。1-RDM が縮約しているのは粒子数自由度であって、空間領域ではない。N 粒子の状態から一粒子分の情報を抜き出す道具で、量子化学や密度汎関数論で使われる。

違いは、具体例で見ると消えない差として現れる。N 個の正規直交軌道 \varphi_1,\dots,\varphi_N を詰めた Slater 行列式(自由フェルミオンの基底状態)では

\rho^{(1)}(x,x')=\sum_{k=1}^N \varphi_k(x)\,\varphi_k^\ast(x')

となり、これはランク N の射影作用素だ(正規直交性から \int\rho^{(1)}(x,y)\rho^{(1)}(y,x')dy=\rho^{(1)}(x,x')、固有値は占有数 0,1)。これに対して空間領域の \rho_A は、§0 の I/2 が示すとおり一般に射影ではなく混合状態である。一方は冪等、もう一方は混合。同じ「縮約密度行列」でも、この一点で別の対象だと分かる。

記号 \rho^{(1)} と \rho_A を取り違えないこと。図4 の上二段が、その「縮約の対象の違い」だ。

4. テンソル分解が成り立つ世界 ── 対応が綺麗なのはなぜか

量子情報との対応が最も素直なのは、格子化された場の理論や、有限個のモードに分けた場の理論である。サイトやモードがそれぞれヒルベルト空間のテンソル因子になっていれば

\mathcal H=\bigotimes_i \mathcal H_i,\qquad \mathcal H_A=\bigotimes_{i\in A}\mathcal H_i

と書けて、部分トレース \rho_A=\operatorname{Tr}_{\bar A}\rho がそのまま意味をもつ。この設定でだけ、量子情報の部分トレース、場の理論の外部自由度の消去、領域 A の演算子で期待値を再現する状態、が文字どおり重なる。鍵はただ一点、ヒルベルト空間が領域ごとにテンソル分解すること。次節は、その前提が崩れる世界の話だ。

5. 連続QFT:テンソル分解が素朴には成り立たない

格子化していない連続的な相対論的QFTでは、空間を A と \bar A に割っても \mathcal H=\mathcal H_A\otimes\mathcal H_{\bar A} と素朴に書けるとは限らない。原因は、局所領域 A の可観測量代数 \mathcal A(A)(その領域で測れる演算子全体のなすフォン・ノイマン代数)が、しばしば Type III 代数(Rindler 楔のような場合は III_1 因子)になることだ。Type III の代数には、有限次元量子情報の最小射影もトレースもふつうの密度行列も、そのままの形では存在しない。だから「\mathcal H_A 上の密度行列 \rho_A」を文字どおり書くこと自体が、厳密には行き詰まる。

どれくらい物理的な話かというと、二つの有名な現象がここに直結している。

ひとつは面積則と紫外発散。真空はあらゆるスケールで絡んでいて、エンタングルメント・エントロピーは境界の面積に比例して発散する(S\sim c\,\text{Area}(\partial A)/\epsilon^{d-2}、\epsilon は切断)。有限の \rho_A から出るはずの有限のエントロピーが、素朴には存在しない。格子などの正則化が要るのはこのためだ。

もうひとつは Unruh 効果。Bisognano–Wichmann の定理により、Rindler 楔に対する真空のモジュラー・ハミルトニアンはちょうど 2\pi\times(ブースト生成子)になる。一様加速する観測者には真空が温度をもつ熱浴に見える、というあの効果の代数的な正体がこれで、\rho_A が素朴な密度行列でないからこそ立ち現れる。

そこで連続QFTでは、\rho_A を密度行列と読むより、全状態 \omega(代数上の状態、すなわち期待値汎関数)を局所代数 \mathcal A(A) に制限したもの

\omega\ \longmapsto\ \omega|_{\mathcal A(A)}

と読むのが正確だ。「A で測れる量に対する期待値の与え方」だけを取り出している。格子化でこの制限を密度行列に化けさせたものが、§4 までの \operatorname{Tr}_{\bar A}\rho だと捉えると、両者の関係が見える。

ここで庭の他の話と地続きになる。状態を「\mathcal H_A 上の点的な対象」でなく「代数 \mathcal A(A) 上の汎関数」として捉える発想は、位相空間を点でなく開集合の代数で捉える視点(別記事 点ではなく、開集合の代数で登る)と同じ呼吸だ ── 代数が一次、点は下流。さらに、全状態を局所代数へ制限する \omega\mapsto\omega|_{\mathcal A(A)} は、別記事 確率空間を Stone 的に読み替える が filtration 塔の各段の代数へ状態を制限し「観測の非可逆性」を論じたのと同じ型(どちらも背後に Type III・modular 理論)。そして「局所観測量の期待値だけで \rho_A が決まる」(§1)という特徴づけは、可換な観測量の同時測定 ── 別記事 生成子が見えると量子力学はわかる の CSCO ── と地続きだ。この「代数が一次」という母言語が、QFT のエンタングルメント・点なし位相・量子観測を貫いている。

最後に救いも書いておく。Type III でも、二領域のあいだに緩衝地帯を挟む条件(split property)の下では、あいだに Type I 因子が現れて近似的なテンソル分解と有限のエンタングルメントが回復する。連続QFTが常に手も足も出ないわけではない。

まとめ

縮約密度行列という一語の下に、対象の違う複数の操作が同居している。区別の鍵はいつも「何を縮約しているのか」だ。格子・有限自由度なら領域外の自由度を部分トレースしていて、量子情報の \rho_A と文字どおり同じ(自由フェルミオンなら相関行列 C|_A の対角化だけで \rho_A もエントロピーも出る)。1-RDM は粒子数を縮約していて別物(Slater 行列式では射影、空間 \rho_A は混合)。連続QFTでは領域に素朴な密度行列が立たず、局所代数への状態の制限として見るのが正確になる。

文脈 何を縮約するか 量子情報の部分トレースと同じか
格子模型の領域 A 領域外 \bar A のサイト・モード 同じ
有限個の場のモード 見ないモード 同じ
一粒子・n 粒子縮約密度行列 粒子数自由度 似ているが目的が違う(射影 vs 混合)
連続QFTの局所領域 局所代数への状態の制限 形式的には似るが、厳密には部分トレースとは限らない

同じか違うかを一語で決めるより、毎回「何を縮約しているのか」を確かめるほうが速い。有限自由度では文字どおり同じ、連続QFTでは代数の言葉で見る。自分がそのあいだのどこに立っているかが分かっていれば、混同は起きない。

事実関係について

  • 部分トレースと縮約密度行列:標準的定義。\rho_A=\operatorname{Tr}_B\rho は「局所観測量の期待値を再現する一意の状態」として特徴づけられる。Bell 状態で \rho_A=I/2 は教科書的事実(図1 は手計算の可視化)。
  • Peschel の方法:ガウス状態で \rho_A=\frac1Z e^{-\sum h_{ij}c_i^\dagger c_j}、h=\ln\frac{1-C}{C}、エントロピーは C|_A の固有値から。確立した結果(Peschel 2003、Peschel–Eisler レビュー)。
  • Slater 行列式の 1-RDM がランク N 射影になるのは標準事実。
  • Type III / Bisognano–Wichmann / 面積則 / split property:代数的QFT の確立した枠組み。楔の真空モジュラー流＝ブースト(Bisognano–Wichmann)、Rindler 楔代数が III_1 因子(Araki)、エンタングルメント・エントロピーの面積則的紫外発散。詳細は Witten のレビュー。
