Ihara の三項式は木の初到達母関数である ── グラフ上のランダムウォークを Green 核から見る

公開

2026年8月11日

1. 導入：一つの作用素、五つの窓

有限グラフ X の上で単純ランダムウォークを考える。推移行列 P、ラプラシアン \Delta = I - P。この一つの作用素のまわりに、見た目のまるで違う道具が並んでいる。Green 核、調和関数、Dirichlet エネルギー、熱核、そして Ihara ゼータ関数。

最初の四つが同じものの言い換えであることは、少し計算すればわかる。問題は五つめだ。ゼータ関数だけは、素数・オイラー積・リーマン予想という、明らかに別の言語からやってくる。

本記事の主張は一つである。

Ihara ゼータの心臓部にある三項式 1 - \lambda u + q u^2 は、そのグラフの普遍被覆である正則木の上で、ランダムウォークが親頂点に初めて到達するまでの母関数そのものである。

つまり五つめの窓も、やはり同じ作用素を見ている。ただしグラフの上ではなく、その普遍被覆の上で。

到達点を先に表で出す。q+1 を次数、A を隣接行列とする。

窓 対象 \Delta との関係 「壁」はどこか
Green 核 (I-uA)^{-1} レゾルベントそのもの 極 = 固有値の逆数
調和関数 \ker \Delta レゾルベントの極における留数 有限連結グラフでは定数のみ
Dirichlet エネルギー \mathcal{E}(f,f)=\langle \Delta f, f\rangle_\pi 二次形式としての \Delta 最小化元 = 調和
熱核 e^{-t\Delta} \int_0^\infty e^{-t\Delta}\,dt = \Delta^{-1} 減衰率 = スペクトルギャップ
Ihara ゼータ \det(I-uB)^{-1} 非後退歩道への持ち上げ \lvert u\rvert = 1/\sqrt q（新しい壁）

上の四つの窓が見ている壁は全部同じ場所にある。五つめだけが 1/\sqrt q という別の半径を持ち、それが Ramanujan グラフの定義と、Selberg ゼータのリーマン予想に、そのまま接続する。その接続を、K_4 という四頂点のグラフの上で手で計算して示す。

2. 最初の四つの窓は、本当に同じものである

先に、退屈だが省けない部分を片づける。X を有限連結グラフ、\pi を定常分布とする。

(a) Dirichlet エネルギーは \Delta の二次形式である。

\mathcal{E}(f,f) \;=\; \frac{1}{2|E|}\sum_{x\sim y} \bigl(f(x)-f(y)\bigr)^2 \;=\; \langle \Delta f,\, f\rangle_\pi .

K_4 上でランダムな f を三つ取って両辺を数値で突き合わせると、小数点以下 8 桁まで一致する。これは恒等式であって近似ではない。

(b) 調和関数は \Delta の核である。 Pf=f と \Delta f=0 は同じこと。(a) と合わせれば Dirichlet 原理が出る：\mathcal{E}(f,f)=0 \iff f は各辺で値が等しい \iff（連結なら）f は定数。有限連結グラフの調和関数が定数しかない、という Liouville 型の主張は、ここでは二行で終わる。

(c) Green 核は熱核の Laplace 変換である。

\Delta^{-1} \;=\; \int_0^\infty e^{-t\Delta}\,dt

（両辺とも定常成分を抜いた部分空間の上で）。K_4 で左辺をスペクトル分解から、右辺を行列指数関数の数値積分から出すと、最大差 2\times 10^{-6} で一致する。差は台形則の誤差である。

この三つを見比べると、四つの窓はどれも同じスペクトル測度の別の変換にすぎないとわかる。\Delta の固有値を \mu_i とすれば、Green 核は \sum 1/\mu_i、熱核は \sum e^{-t\mu_i}、Dirichlet エネルギーは \sum \mu_i |\hat f_i|^2。窓が違うだけで、外の景色は一つである。

だから、この四つのあいだを行き来しても新しい情報は出てこない。出てくるとすれば、五つめからだ。

3. Ihara ゼータは「非後退」で別の壁を作る

Ihara ゼータの定義は、リーマンゼータのオイラー積を露骨に真似ている。X の素サイクル \mathfrak{p}（非後退・尾なし・巡回同値を除いた閉路）に対し

Z_X(u) \;=\; \prod_{\mathfrak{p}} \bigl(1-u^{\ell(\mathfrak{p})}\bigr)^{-1}.

\ell(\mathfrak{p}) は長さ。非後退（backtracking しない：来た辺をすぐ引き返さない）が定義の中心にある。これが効く。

橋本の定理により、この無限積は有限行列式で閉じる。X の有向辺 2m 本の上の非後退辺行列（橋本行列）B を

B_{(i\to j),\,(k\to l)} \;=\; \begin{cases} 1 & j=k \ \text{かつ}\ l \neq i \\ 0 & \text{それ以外}\end{cases}

と定めると、

Z_X(u)^{-1} \;=\; \det(I - uB), \qquad \log Z_X(u) \;=\; \sum_{k\ge 1} \frac{\operatorname{tr}(B^k)}{k}\,u^k .

第二式は跡公式である。K_4 で k \le 10 まで係数を突き合わせると、k=3,4,6,7,8,9,10 で 8, 6, 16, 24, 21, 58.67, 120 が両辺一致する（k=1,2 が 0 なのは、長さ 1・2 の非後退閉路が存在しないから）。

ここで、なぜ「新しい情報」なのかが見える。\operatorname{tr}(A^k) は長さ k の閉歩道の数で、これは Green 核の展開係数そのもの、つまり §2 の四つの窓の中にいる。\operatorname{tr}(B^k) は違う。引き返しを禁じた瞬間、数えている対象がグラフのスペクトルから離れる。

離れたはずのものが、離れきらない。それが次節の Bass の公式である。

4. Bass の公式：2m \times 2m が n \times n に落ちる

\boxed{\ Z_X(u)^{-1} \;=\; (1-u^2)^{\,m-n}\,\det\!\bigl(I - Au + Qu^2\bigr),\qquad Q = D - I\ }

n=|V|、m=|E|、D は次数対角行列。左辺は 2m 次、右辺は n 次の行列式である。

この記事の主張の重みは、この公式が「なぜ」成り立つかではなく、「何が」右辺に残ったかにある。残ったのは u の二次式だ。一次ではない。\det(I-uA) ならただのレゾルベントで §2 に戻ってしまうが、\det(I-Au+Qu^2) は違う。

四つのグラフで実際に両辺を展開して確かめた（K_4、K_5、および非正則な bowtie（三角形二つが一頂点を共有）と theta グラフ）。四つとも一致する。非正則でも成り立つのは大事な点で、後で §7 に効く。

K_4 で具体的に書き下すと、n=4, m=6, q=2、\operatorname{spec}(A) = \{3, -1, -1, -1\} だから

Z_{K_4}(u)^{-1} \;=\; (1-u^2)^2\,(1-3u+2u^2)\,(1+u+2u^2)^3 \;=\; (1-u^2)^2(1-u)(1-2u)(1+u+2u^2)^3 .

正則グラフでは Q=qI なので右辺は固有値ごとに完全に分解する：

\det(I-Au+qu^2) \;=\; \prod_{\lambda \in \operatorname{spec}(A)} \bigl(1 - \lambda u + q u^2\bigr).

この三項式が主役である。その根は

q u^2 - \lambda u + 1 = 0 \iff u = \frac{\lambda \pm \sqrt{\lambda^2 - 4q}}{2q} \iff \lambda = \frac{1}{u} + qu .

最後の形に注目してほしい。\lambda と u を結ぶのは \Phi(w) = w^{-1} + qw という一つの有理写像である。これが何であるかを、次節で正体を明かす。

5. 核心：三項式は正則木の初到達母関数である

X が (q+1)-正則なら、その普遍被覆は (q+1)-正則木 T_{q+1} である。木の上でランダムウォークを走らせる。

頂点 v から、その親頂点に初めて到達するまでの歩道の母関数を H(u) = \sum_k h_k u^k とおく（h_k は長さ k の初到達歩道の本数、u は長さを数える形式変数）。木の自己相似性から、一歩目で場合分けするだけで再帰が閉じる。

  • 一歩目で親へ行く：寄与 u。
  • 一歩目で q 人の子のどれかへ行く：寄与 qu。そこから v へ戻るのに H、v から親へ行くのにもう一度 H。

\boxed{\ H \;=\; u + q\,u\,H^2\ } \qquad\Longrightarrow\qquad H(u) \;=\; \frac{1-\sqrt{1-4qu^2}}{2qu}.

図の要点は H が二回現れることにある。子へ降りた歩道は、v へ戻るのに一度、v から親へ抜けるのにもう一度、同じ母関数を消費する。この H^2 が二次式の出どころであり、§4 の三項式が二次である理由でもある。

q=2 で展開すると H = u + 2u^3 + 8u^5 + 40u^7 + \cdots。再帰を直接反復して係数を数えても 1, 0, 2, 0, 8, 0, 40 が出る（偶数次が 0 なのは、木では親までの距離のパリティが固定されるから）。

さて、quH^2 - H + u = 0 を uH で割る。

\frac{1}{u} \;=\; \frac{1}{H} + qH \;=\; \Phi(H).

\Phi が二度目に出た。§4 の三項式は \lambda = \Phi(u)、木の再帰は u^{-1} = \Phi(H)。同じ写像である。

対応を明示する。u_T を木の変数、u_I を Ihara 変数として、\lambda = 1/u_T と読めば u_I = H(u_T)。実際に代入すると

H\!\left(\frac{1}{\lambda}\right) \;=\; \frac{\lambda - \sqrt{\lambda^2-4q}}{2q}

で、これは三項式 qu^2-\lambda u+1=0 の根に一致する（右辺の閉じた形は \lambda>0 のとき。H は奇関数なので \lambda<0 では根号の前の符号が反転し、やはり絶対値の小さいほうの根になる）。

三項式 1-\lambda u + qu^2 の二つの根は、スペクトル値 \lambda における正則木の初到達母関数の、二つの分枝である。

⚠️ 分枝の取り方には向きがある。\lambda が実で |\lambda| > 2\sqrt q のとき、H は単位円板の内側にある方の根（|u| < 1/\sqrt q）を選ぶ。\lambda の符号が負でもこれは変わらない。ところが |\lambda| < 2\sqrt q になると二根は複素共役対になり、両方とも |u| = 1/\sqrt q ちょうどに乗る。大小の区別が消え、「どちらが H か」という問いが意味を失う。数値で確かめると、q=2, \lambda=2.53 で両根の絶対値がともに 0.7071 = 1/\sqrt 2、\lambda = 3.13 で 1.116 と 0.448 に割れる。

この「割れる／割れない」の境目が、次節のすべてである。

6. 分岐点が Ramanujan 境界である

\Phi(w) = w^{-1} + qw は二対一の写像で、臨界点は \Phi'(w) = -w^{-2}+q = 0 より

w = \pm \frac{1}{\sqrt q}, \qquad \Phi\!\left(\pm\frac{1}{\sqrt q}\right) = \pm 2\sqrt q .

つまり \Phi の分岐点は \lambda = \pm 2\sqrt q、分岐切断は区間 [-2\sqrt q,\, 2\sqrt q] である。H(u) の根号 \sqrt{1-4qu^2} が分岐するのも、同じ場所を裏から見たものだ。

そして [-2\sqrt q,\, 2\sqrt q] は、正則木 T_{q+1} の上の隣接作用素の \ell^2 スペクトルそのものである。だから：

グラフ X が Ramanujan \iff 非自明固有値がすべて |\lambda| \le 2\sqrt q \iff X のスペクトルが、その普遍被覆のスペクトルの中に収まっている \iff 対応する三項式の根がすべて |u| = 1/\sqrt q に乗る \iff Ihara ゼータのリーマン予想。

四つの言い換えが一列に並ぶ。真ん中の「普遍被覆のスペクトルに収まっている」が、この記事の視点から見た Ramanujan 性の意味である。有限グラフでありながら、スペクトルの上では無限木と見分けがつかない、ということだ。

K_4 で確かめる。q=2、2\sqrt q = 2.828。非自明固有値は -1 で、|-1| \le 2.828 だから K_4 は Ramanujan。実際、§4 の因数分解で非自明部分は (1+u+2u^2)^3、その根は u = (-1 \pm i\sqrt7)/4 で絶対値は \sqrt{8}/4 = 1/\sqrt 2 = 1/\sqrt q。ちょうど臨界円上にある。自明固有値 3 に対応する因子だけが (1-u)(1-2u) と実根に割れ、u=1/2 = 1/q が Z の極を与える。

図の読み方は一つだけである。切断の内側の固有値は円周へ、外側の固有値は実軸へ持ち上がる。Ramanujan 性とは「自明固有値以外は全部内側」という条件にほかならない。

Z の極の位置は歩道の増大率を支配する。K_4 の \operatorname{tr}(B^k) を 2^k で割ると、k=10,14,18,22 で 1.172, 0.984, 0.989, 1.000 と 1 に寄る。B の最大固有値はちょうど 2 = q である。素サイクルの個数が q^k/k で増える、という素測地線定理の類似が、ここから出る。

6.5. Z の極は、被覆の上での初回帰確率である

§5 の定理を自明固有値 \lambda=q+1 に当てると、すぐに一つの系が出る。三項式の根は

H\!\left(\frac{1}{q+1}\right)=\frac{(q+1)-\sqrt{(q+1)^2-4q}}{2q}=\frac{(q+1)-(q-1)}{2q}=\frac{1}{q}

で、これは (1-u)(1-qu) の小さいほうの根、すなわち Z_X の極である。一方、左辺は T_{q+1} 上の単純ランダムウォークの初回帰確率 F=(q+1)\cdot\frac{1}{q+1}\cdot H にほかならない。

Z_X の極 u=1/q は、普遍被覆の上でランダムウォークが原点に戻る確率である。

期待訪問回数も同時に落ちる：G(1)=1/(1-F)=q/(q-1)。木の上で距離のマルコフ連鎖を回して \sum_k p_k(o,o) を出すと、q=2,3,5 に対し 2.000000,\ 1.500000,\ 1.250000 で厳密値と一致する。q=2 の三正則木では、原点に平均ちょうど 2 回しか居ない。

ここから、同値の鎖が閉じる。

\underbrace{F=\tfrac1q<1}_{\text{有限回しか戻らない}} \iff q\ge2 \iff \underbrace{2\sqrt q< q+1}_{\text{分岐点}\,<\,\text{自明固有値}} \iff \underbrace{\tfrac1q<\tfrac{1}{\sqrt q}}_{\text{極が分岐円の内側}}

§6 の図が、そのまま非再帰性の図になっている。自明固有値だけが分岐切断の外にいる、という絵は、「ウォークが無限へ逃げる」と同じことを言っていた。

崩れる側も見える。q=1、つまり普遍被覆が \mathbb{Z} のとき、F=1（再帰的）となり 2\sqrt q=q+1=2 で分岐点と自明固有値が衝突する。実際 C_n のゼータを計算すると Z^{-1}=(1-u^n)^2 で、全部の根が単位円上に乗る。極も分岐円も自明因子も u=1 の一点に潰れる。

Selberg 側も同じ形をしている。\mathbb{H}^2 上のブラウン運動が非再帰的であることと、L^2 スペクトルの底が 1/4>0 であることは同じ事実の裏表で、(0,1/4) という隙間が (2\sqrt q,\,q+1) に対応する。リーマン予想が空虚でないためには隙間が要り、隙間があることが非再帰性である。再帰的な被覆（\mathbb{Z}、\mathbb{Z}^2）では隙間が閉じ、「Ramanujan」も「臨界線」も内容を失う。

⚠️ ただしゼータ性そのものは非再帰性を要求しない。C_n にもオイラー積はあり（素サイクルは 2 本）、関数等式もある。非再帰性が効いているのは極の位置とリーマン予想が内容を持つかどうかであって、「ゼータであること」ではない。この区別は次の記事 ゼータは記憶から生まれる の主題になる。

7. どこで崩れるか

主張のスコープを閉じておく。

(a) 木ではゼータが何も見ない。 X が木なら閉路が無いので B は冪零、Z_X \equiv 1。Bass の公式では m - n = -1 となり、指数が負になる。P_2（辺一本）、P_4、星 K_{1,3} の三つで両辺を計算すると、確かに \det(I-uB)=1 と (1-u^2)^{-1}\det(I-Au+Qu^2)=1 が一致する。「(1-u^2)^{m-n} は自明因子」という説明は、m \ge n のときにしか通らない。

(b) 非正則グラフでは三項式が固有値ごとに割れない。 Bass の公式自体は非正則でも成り立つ（bowtie と theta で確認済み）。しかし Q = D-I がスカラーでないと \det(I-Au+Qu^2) が \prod_\lambda(1-\lambda u+qu^2) に分解せず、A と Q が同時対角化できない。§5 の対応も崩れる：普遍被覆が正則木でないから、そもそも「木の初到達母関数」が一つに定まらない。Ramanujan 性という概念が非正則グラフで扱いにくいのは、この一点が原因である。

(c) ゼータはグラフを決めない。 正則グラフでは Bass より Z は \operatorname{spec}(A) だけの関数だから、同スペクトルな非同型正則グラフの対は、同じ Ihara ゼータを持つ。Shrikhande グラフと 4\times4 ルークグラフ（ともに 16 頂点 6 正則）で確認した。スペクトルはどちらも \{6,\, 2^{6},\, (-2)^{9}\} で完全一致、三角形数も \operatorname{tr}(A^4) も一致するが、非同型である（一頂点の近傍が誘導する部分グラフが、Shrikhande では 6-サイクルで連結、ルークでは三角形二つで非連結）。ゼータは被覆から見える情報しか持っていない。

(d) 「u は複素数」ではあるが「u は確率」ではない。 §5 の H(u) は歩道を長さで数える形式的母関数であって、推移確率で重みづけた量ではない。確率版が欲しければ u \to u/(q+1) の置き換えが要る。比喩として「初到達確率」と呼びたくなるが、文字どおり確率なのは変数を置き換えた後だけである。

8. Selberg 側との対応表

同じ形が双曲面の上でも起きる。\Gamma \backslash \mathbb{H} をコンパクト双曲面とすると、Selberg ゼータは閉測地線を渡るオイラー積で定義され、その非自明零点は s(1-s) = \lambda（\lambda はラプラシアンの固有値）で与えられる。

グラフ（Ihara） 双曲面（Selberg）
対象 有限 (q+1)-正則グラフ X コンパクト双曲面 \Gamma\backslash\mathbb{H}
普遍被覆 正則木 T_{q+1} 双曲平面 \mathbb{H}
「素数」 素サイクル（非後退・尾なし） 原始閉測地線
スペクトル変数の持ち上げ \lambda = u^{-1} + qu \lambda = s(1-s)
分岐点 \lambda = \pm 2\sqrt q \lambda = 1/4（s=1/2）
分岐切断 = 被覆のスペクトル [-2\sqrt q, 2\sqrt q]（T_{q+1} の \ell^2 スペクトル） [1/4,\infty)（\mathbb{H} の L^2 スペクトル）
リーマン予想 極が \lvert u\rvert = 1/\sqrt q 上 \iff Ramanujan 零点が \operatorname{Re} s = 1/2 上 \iff 小さい固有値なし
跡公式 \log Z = \sum_k \operatorname{tr}(B^k)u^k/k Selberg 跡公式

両側で「リーマン予想」が意味しているのは同じ一文である。すなわち「有限（余コンパクト）な対象のスペクトルが、その普遍被覆のスペクトルの外へはみ出さない」。1/2 という数も \sqrt q という数も、どちらも被覆のスペクトルの端 = 持ち上げ写像の分岐点として決まっている。天下りの定数ではない。

ここで注意しておく。この対応表は構造の類比であって、一方から他方が導かれるわけではない。\Phi(w)=w^{-1}+qw は有理写像、s \mapsto s(1-s) は多項式で、二対一の分岐被覆という点だけが共通している。q \to 連続極限で Selberg が出る、という主張は本記事はしていない（p 進群と実群を同じ枠に載せる仕事はあるが、それは別の話である）。

9. 何がこの視点で見えるようになるか

\Delta の四つの窓（Green 核・調和関数・Dirichlet エネルギー・熱核）は、スペクトル測度の変換にすぎない。Ihara ゼータが新しいのは、非後退という条件を通じてグラフを離れ、普遍被覆へ登るからである。そして登った先で、\Delta のスペクトル変数は二枚のシートに分かれ、その分岐点が Ramanujan 境界になる。

この構図は「不変量が解像度を決める」という庭の背骨に、そのまま乗る。隣接作用素のスペクトルは、グラフを被覆の言葉で見たときの位置しか覚えていない。だから同スペクトル非同型対（§7c）を区別できない。逆に言えば、区別できないという事実そのものが、この不変量が何を見ているかの定義になっている。

横断先を二つ挙げる。ラプラス–ベルトラミ作用素は大域的な装置である は、同じ \Delta を多様体側から見た記事で、§8 の右列がその舞台である。伊藤補正は幾何ではない ── Fisher 弧長で単体を歩き、Dirichlet 重みで境界を読む は、Dirichlet 形式が座標表示に依るのか構造なのかを問うた記事で、§2(a) の「エネルギーは二次形式である」がそこの言葉では「座標に依らない側」に落ちる。

10. 査読・限界

確立した事実（外部文献に依拠）

  • Ihara ゼータの起源は Y. Ihara, On discrete subgroups of the two by two projective linear group over \mathfrak{p}-adic fields, J. Math. Soc. Japan 18 (1966), 219–235。もともとは p 進群の離散部分群の話で、グラフとしての解釈は Serre の Trees を経て定着した。
  • 行列式表示 Z^{-1}=\det(I-uB) は K. Hashimoto, Zeta functions of finite graphs and representations of p-adic groups（Adv. Stud. Pure Math., 1989）。
  • 三項式への還元は H. Bass, The Ihara–Selberg zeta function of a tree lattice, Internat. J. Math. 3 (1992)。組合せ論的な別証明が D. Foata, D. Zeilberger, Trans. Amer. Math. Soc. (1999) にある。有限グラフに限った整理は M. Kotani, T. Sunada, Zeta functions of finite graphs, J. Math. Sci. Univ. Tokyo 7 (2000)。
  • Ramanujan グラフ・Alon–Boppana 境界・T_{q+1} のスペクトルが [-2\sqrt q, 2\sqrt q] であることは、Lubotzky Discrete Groups, Expanding Graphs and Invariant Measures（1994）およびその周辺の標準的事実。
  • Shrikhande グラフと 4\times4 ルークグラフが同パラメータ (16,6,2,2) の非同型な強正則グラフであることは古典的（Shrikhande 1959）。

自分で計算して確かめたこと（本記事の数値・式はすべて機械検算済み）

  • Bass の公式を K_4・K_5・bowtie・theta の四つで、\det(I-uB) を直に展開して照合（うち二つは非正則）。
  • 橋本の等式（オイラー積 =\det(I-uB)^{-1}）を K_4 で 6 次まで。素サイクルを実際に列挙すると長さ 3 が 8 本、4 が 6 本、6 が 12 本（長さ 6 の素朴な数え上げ 20 本のうち 8 本は三角形の二重回りで、原始的でない）。両辺とも 1+8u^3+6u^4+48u^6 になる。
  • K_4 の完全な因数分解、跡公式の係数を k\le10 まで、\operatorname{tr}(B^k)/q^k \to 1 を k=22 まで。
  • 木の再帰 H = u+quH^2 とその閉じた形、係数 1,0,2,0,8,0,40、恒等式 1/u = 1/H + qH、および H(1/\lambda) が三項式の根に一致すること。分枝の符号の挙動（§5 の警告）も数値で確認した。
  • Dirichlet エネルギー =\langle\Delta f,f\rangle_\pi、Green 核 = 熱核の時間積分（K_4、最大差 2\times10^{-6}）。
  • 木で Z\equiv1 かつ Bass の指数が -1 になること（P_2, P_4, K_{1,3}）。
  • Shrikhande と 4\times4 ルークが同スペクトル・非同型・同ゼータであること。

私見・見立て（事実ではない）

  • 「三項式は木の初到達母関数である」という言い方は本記事の整理であって、標準的な用語ではない。同じ内容は通常「Bass の公式」「\lambda と u の対応」として、母関数を経由せずに述べられる。数学的内容に新しいものは何もない。視点の置き方だけが本記事の寄与である。
  • §8 の対応表を「Ihara は Selberg の p 進版である」と読むのは行き過ぎだと考える。共通しているのは二対一の分岐被覆という構造で、そこから先は別々の理論である。

未解決・本記事が扱っていないこと

  • 非正則グラフの Ramanujan 性の正しい定式化（普遍被覆のスペクトル半径を使う定義があるが、本記事は触れていない）。
  • 無限グラフ・無限体積の場合。\ell^2 ベッチ数や von Neumann 次元が必要になり、行列式が Fuglede–Kadison 行列式に置き換わる。
  • グラフの同型類をゼータがどこまで決めるか（§7c は否定的な例を一つ与えただけで、何を足せば決まるかは述べていない）。
  • 重み付き・有向グラフへの拡張。
