ガロア理論の入門講義は、なぜ「おいしいところ」の手前で終わるのか ── 5次方程式の可解性分類

公開

2026年5月20日

ガロア理論の入門講義は、なぜ「おいしいところ」の手前で終わるのか

1. 導入：ガロア理論入門へのモヤモヤ

ガロア理論の入門を受けたあとに、妙な物足りなさが残ったことはないだろうか。

典型的な講義や入門書の流れはこうだ。まず2次方程式の解の公式を確認する。次に3次方程式のカルダノの公式、4次方程式のフェラーリの方法を見せる。そして「では5次は？」と問いを立て、最後にアーベル＝ルフィニの定理 ―― 一般の5次方程式には冪根による解の公式が存在しない ―― を証明して幕を閉じる。

筋は通っている。歴史的にも自然だ。だが、正直に言えば、この流れで説明されるのは、ガロアがいなくてもおおよそ見えていた部分が大半なのである。2次・3次・4次に公式があることは、ガロアより前から知られていた。5次が「一般には」解けないという感触も、アーベルとルフィニがガロア理論の完成形を待たずに到達した結論だ。

すると、肝心のガロアは何をしたのか。「一般5次は解けない」を証明した人、という説明だけだと、ガロア理論はまるごと一個の不可能性定理に縮んでしまう。本当に知りたいのは、その先である。冪根で解ける5次方程式とは具体的にどんなものか。目の前のひとつの5次方程式について、それが解けるか解けないかを、どうやって判定するのか。 この問いに答えないまま終わる入門は、いちばんおいしいところの手前で皿を下げているように思える。

この記事は、その不満を出発点にして、ガロア理論が本来どこを向いた理論なのかを整理してみたい。

2. アーベル＝ルフィニで終わると何が見えないのか

アーベル＝ルフィニの定理は、もちろん偉大な結果である。「一般の5次方程式」、すなわち係数を不定元と見たときの5次方程式は、四則と冪根だけでは根を表せない。これは深い。

しかし、この定理だけを到達点にすると、ひとつ重大な誤読が生まれる。「5次方程式は解けない」という、雑な一文に丸められてしまうのだ。

これは正しくない。「一般の」5次方程式が解けないことと、「あらゆる」5次方程式が解けないことは、まったく別のことである。後で具体的に見るように、x⁵ − 2 = 0 はれっきとした5次方程式だが、その根は冪根できれいに書ける。「5次は解けない」と覚えていると、この例の前で立ち往生する。

アーベル＝ルフィニ型の入門が落とすのは、要するに個別性である。方程式を一個ずつ見たときに、解けるものと解けないものがあって、その境目に構造がある ―― この一番面白い部分が、不可能性の証明だけでは視界に入らない。ガロア理論の本体は、まさにその境目を扱う理論なのだ。

3. ガロア理論の本体は「不可能性」ではなく「分類」である

ガロア理論の発想を一行で言えば、こうなる。多項式の根たちの間にある対称性を「群」として取り出し、その群の構造から方程式の性質を読む。

多項式 f(x) の根を α₁, …, αₙ とする。これらの根は、係数体（ここでは有理数体 Q とする）から見ると互いに区別がつかない部分を持っている。たとえば √2 と −√2 は、有理数の世界からはどちらが「正しい √2」とも言えない。この「入れ替えても有理数の世界からは矛盾が見えない」操作の全体が、根の置換群 ―― ガロア群 ―― である。

ガロア理論の基本定理は、この群の部分群と、根が生成する体（分解体）の中間体とが、きれいに対応することを述べる。そしてその対応の上で、決定的な定理がひとつ立つ：

方程式 f(x) = 0 が冪根で解けることと、そのガロア群が可解群であることは同値である。

ここがガロア理論の心臓部だ。「解けるか」という解析的・計算的に見える問いが、「群が可解か」という純粋に群論的な問いに翻訳される。可解群とは、ざっくり言えば「アーベル群を積み上げて作れる群」、より正確には組成列の各因子がすべて巡回群（あるいはアーベル群）になるような群のことだ。

この視点に立つと、ガロア理論は不可能性の定理ではなく、分類の理論だと分かる。方程式を、そのガロア群によって仕分ける。可解群がついた方程式は解ける側、非可解群がついた方程式は解けない側。アーベル＝ルフィニはこの分類のうち「非可解な群が実際に現れる」という一事例にすぎない。

なぜ2次・3次・4次だけでは、このありがたみが見えにくいのか。理由は単純で、低次では群が小さすぎるからである。2次のガロア群はたかだか位数2、3次は S₃（位数6）、4次は S₄（位数24）。これらはすべて可解群だ。つまり低次では「可解かどうかの判定」が常に YES で、判定そのものが仕事をしていない。群論のフィルターを通しても、何も濾し取られない。フィルターの威力は、初めて「解ける」と「解けない」が両方現れる5次で見えてくる。

4. 既約5次多項式と S₅ の推移的部分群

そこで5次に絞る。係数体は Q、対象は既約な5次多項式 f(x) ∈ Q[x] とする（既約でないと、より低次の因子の問題に分かれてしまい、5次らしさが失われる）。

f が既約であることは、ガロア群に強い制約を与える。f の5つの根に群が作用するとき、既約性はこの作用が推移的であることと同値になる。推移的とは、どの根もどの根へも群の元で移せる、ということだ。もし作用が推移的でなければ、根の集合が群で保たれる小さな塊に分かれ、それに対応して f が因数分解できてしまう。

したがって、

既約な5次多項式のガロア群は、S₅ の推移的部分群として現れる。

これは強い。S₅ は位数120の大きな群だが、その部分群のうち推移的なものは、共役を除けばごくわずかしかない。具体的には、次の5種類で尽きる：

  • C₅ … 位数5の巡回群
  • D₅ … 位数10の二面体群（正五角形の対称性）
  • F₂₀ … 位数20のフロベニウス群（後述）
  • A₅ … 位数60の交代群
  • S₅ … 位数120の対称群

5次方程式のガロア群を考えるとは、結局この5つのどれが現れているかを見極めることに等しい。そして可解か否かの線は、この5つの中をきれいに走っている。

5. 冪根で解ける5次：C₅、D₅、F₂₀

まず可解な側の3つを見る。これらがついた既約5次方程式は、冪根で解ける。

C₅（位数5）。 巡回群だから、当然可解。5つの根が「ぐるぐる回る」一巡の対称性しか持たない、いちばん素直な場合だ。後で見るように、円分体（1の冪根が生む体）の中から自然に現れる。

D₅（位数10）。 正五角形の対称性の群。回転（C₅）に裏返しを加えたもので、C₅ を正規部分群に持ち、商が C₂ になる。アーベル群（C₅, C₂）の積み上げなので可解。

F₂₀（位数20）。 フロベニウス群とも、AGL(1,5)（5元体の上のアフィン変換群）とも呼ばれる。構造は C₅ ⋊ C₄、すなわち正規部分群 C₅ に、その自己同型群 Aut(C₅) = C₄ がまるごと作用してできる半直積だ。これも C₅ の上に C₄ が乗っているだけなので可解。S₅ の中では、シロー5部分群の正規化群として現れる ―― これが「推移的部分群のうち5を法とする構造を最大限に許す可解群」である。

整理すると、可解な3つはいずれも「位数5の巡回群 C₅ を正規部分群として土台に持ち、その上にアーベルな層（C₁, C₂, C₄）が乗っている」という共通の骨格を持つ。5次方程式が解けるとは、根の対称性がこの形に収まっている、ということなのだ。

6. 冪根で解けない5次：A₅、S₅

残りの2つは、可解でない。

A₅（位数60）。 5次の交代群。これは非可解群の最小例として有名で、しかも非可換な単純群である ―― 自明でない正規部分群を一切持たない。可解群は組成列をアーベルな因子まで分解できる群のことだったが、A₅ はそもそも分解の手がかりになる正規部分群がない。だから可解になりようがない。正二十面体（icosahedron）の回転対称群と同型で、その意味で「icosahedral な対称性」とも言われる。

S₅（位数120）。 5次の対称群。A₅ を指数2の正規部分群として含むので、A₅ が非可解である以上、S₅ も非可解だ。そして「無作為に取ってきた5次方程式」のガロア群は、ふつうこの S₅ になる ―― これが「一般の5次方程式」の正体である。アーベル＝ルフィニの定理は、突き詰めれば「S₅（および A₅）が非可解である」という群論的事実の言い換えにほかならない。

ここまでを一枚の表にまとめておく。

ガロア群 位数 可解性 冪根で解けるか 典型的なイメージ
C₅ 5 可解 解ける 巡回5次。円分体的な例
D₅ 10 可解 解ける 正五角形の対称性をもつ例
F₂₀ 20 可解 解ける x⁵ − a 型。Kummer 的な例
A₅ 60 非可解（単純群） 一般に解けない 正二十面体的な対称性
S₅ 120 非可解 一般に解けない 「一般の」5次方程式

可解と非可解の境目は、C₅・D₅・F₂₀ と A₅・S₅ のあいだに、はっきり一本入っている。ガロア理論とは、目の前の5次方程式がこの線のどちら側にいるかを、根の対称性として見抜く理論なのだ。

7. 具体例1：x⁵ − 2 は5次だが冪根で解ける

抽象論が続いたので、具体例に降りる。最初の例は x⁵ − 2 = 0 だ。

この多項式は、アイゼンシュタインの判定法（素数2について、定数項が2で割れて4で割れず、最高次以外の係数も2で割れる）により、Q 上既約である。れっきとした既約5次多項式だ。

それでいて、根は完全に書ける。5乗して2になる数を一つ取り、それを実5乗根 2^{1/5} とし、1の原始5乗根を ζ₅ とすれば、5つの根は

2^{1/5}, ζ₅·2^{1/5}, ζ₅²·2^{1/5}, ζ₅³·2^{1/5}, ζ₅⁴·2^{1/5}

である。冪根（2の5乗根と、1の5乗根）だけで、何の苦もなく表示できてしまう。

分解体は Q(2^{1/5}, ζ₅) だ。次数を数えると、[Q(2^{1/5}) : Q] = 5、[Q(ζ₅) : Q] = 4 で、5と4は互いに素だから、合わせて [Q(2^{1/5}, ζ₅) : Q] = 20。ガロア群の位数は20である。

この群の構造もはっきりしている。ζ₅ をどの原始5乗根に送るか（C₄ ぶんの自由度）と、2^{1/5} をどの根に送るか（C₅ ぶんの自由度）が組み合わさり、C₄ は C₅ の自己同型としてフルに効く。したがってガロア群は C₅ ⋊ C₄、すなわち F₂₀ 型だ。表の3行目、可解な側にぴたりと収まる。

x⁵ − 2 は、「5次方程式は解けない」という雑な言い方が誤解であることを示す、いちばん分かりやすい反例である。5次でも、群が可解なら解ける。

8. 具体例2：円分体から来る巡回5次

次に、ガロア群が C₅ になる例 ―― いちばん対称性の素直な5次を見たい。

f(x) = x⁵ + x⁴ − 4x³ − 3x² + 3x + 1

を考える。一見すると無愛想な多項式だが、これは

2cos(2π/11) = ζ₁₁ + ζ₁₁⁻¹

の最小多項式である。実際、11次円分多項式 Φ₁₁(x) = x¹⁰ + x⁹ + ⋯ + 1 を x⁵ で割り、y = x + x⁻¹ で書き直すと、x^k + x^{−k} がチェビシェフ的に y の多項式になり（x⁵+x⁻⁵ = y⁵−5y³+5y、x⁴+x⁻⁴ = y⁴−4y²+2、x³+x⁻³ = y³−3y、…）、整理するとちょうど上の f(y) が出てくる。

この多項式の5つの根は、2cos(2π/11), 2cos(4π/11), …, 2cos(10π/11) で、すべて11次円分体の実部分体 Q(ζ₁₁ + ζ₁₁⁻¹) の中にある。円分体 Q(ζ₁₁) のガロア群は C₁₀ で、複素共役による C₂ で割った実部分体のガロア群は、ちょうど C₅ になる。

この例の良さは、ガロア群が「根の置換」として目に見えることだ。C₅ の生成元は、5つの根を一定の規則でひとつずらしに巡回させる。根が文字どおりぐるぐる回る。「ガロア群とは根の置換群である」という定義が、抽象的な言い回しでなく、円分体の幾何の中で具体的に触れられる ―― C₅ の例は、その意味で教育的にとても良い。そして C₅ は巡回群、もちろん可解なので、この5次も冪根で解ける。

9. 具体例3：リゾルベントによる可解5次の判定

x⁵ − 2 や円分体の例は、可解だと「見れば分かる」種類のものだった。だが本当に知りたかったのは、もっと無愛想な5次 ―― 一見しただけでは可解性が分からない方程式を、どう判定するかだった。

ここに、ガロア理論が分類の理論であることの実用的な果実がある。デイヴィッド・ダミットの論文 “Solving Solvable Quintics”（1991年）は、まさにこの判定アルゴリズムを与えている。

考え方の骨子はこうだ。可解な5次のガロア群は F₂₀ かその部分群（D₅, C₅）に収まる。そこで、S₅ の中で F₂₀ がどう座っているかを利用する。S₅ における F₂₀ の指数は 120 / 20 = 6 だから、F₂₀ の共役類は6個。これに対応して、もとの5次方程式の根から組み立てられる6次のリゾルベント（分解方程式）を作ることができる。

すると判定はこうなる：この6次リゾルベントが有理根を持てば、もとの既約5次は可解（ガロア群が F₂₀ 以下）であり、持たなければ非可解（A₅ または S₅）。しかも有理根が見つかれば、そこから根の冪根表示を実際に組み立てる手続きまで付いてくる。たとえば x⁵ + 15x + 12 のような、係数だけ見ても可解か分からない例が、このリゾルベント計算によって「解ける側」と判定される、というのがダミットの扱う典型例である。

計算の細部には立ち入らない。大事なのはひとつ ―― 「目の前のこの5次は解けるのか」という個別の問いに、ガロア理論は実際に答えを出すアルゴリズムを持っているということだ。これは不可能性定理からは絶対に出てこない、分類の理論ならではの成果である。

10. 結論：「5次は解けない」ではなく「どの5次が解けるか」

最初のモヤモヤに戻ろう。アーベル＝ルフィニで終わる入門講義は、何を見せ損ねているのか。

見せ損ねているのは、ガロア理論が分類と判定の理論だという、その正体である。アーベル＝ルフィニは「一般5次という、ガロア群が S₅ になる場合は解けない」と言っているにすぎない。それで話を閉じると、5次方程式という広い世界のうち、非可解な一隅だけを見て全体を語ったことになる。残りの ―― C₅, D₅, F₂₀ がついた、解ける側の ―― 豊かな世界が、まるごと視界の外に落ちる。

ガロア理論の真価は、不可能性の証明そのものではない。可能な場合と不可能な場合を、根の対称性という一つの原理で仕分けてみせることにある。x⁵ − 2 は解け、無作為な5次は解けず、その境界には可解群か非可解群かという明確な構造が走っている。そして個別の方程式については、リゾルベントによって実際に判定できる。

だから、最後にこう言い直したい。

「5次方程式は解けない」のではない。 正しくは ―― 一般の5次方程式は冪根では解けない。しかし、ガロア群が可解である5次方程式は冪根で解ける。そしてガロア理論とは、その違いを根の対称性として見抜く理論である。

入門講義が本当に届けるべきだったのは、アーベル＝ルフィニの「終止符」ではなく、この「仕分けの目」だったのだと思う。

11. 否定形 ──「解ける」は「冪根で」に相対的だ

最後に境界を一つ。本記事の「解ける/解けない」は、終始「冪根で」という限定つきだった。許す操作を変えれば、話は変わる。x^5-x-1 はガロア群が S_5 で冪根では解けないが、Hermite(1858)は一般5次方程式を楕円モジュラー関数(テータ関数)を使って解いてみせた。つまり「5次は解けない」は「四則と冪根という道具立てでは解けない」の意味であって、道具を楕円関数まで広げれば解ける。

横断メモ. これは別記事「人は何を『解』と呼ぶのか」と地続きだ ── 何を「解いた」と呼ぶかは、受け入れる操作・翻訳に依存する。冪根を解と呼べば S_5 は不可能、楕円関数を解と呼べば可能。また、可解性=ガロア群がアーベル因子に分解できること、という本記事の核心は、「Galois 理論を線形代数として見る」で見た「アーベル(可換)Galois 群 ⇄ 同時対角化できる/1 次元固有空間に割れる、非可換 ⇄ 割れない」と同じ事実の別表現だ(C_5 の円分例は、あちらの円分・Kummer の固有値そのもの)。可換性が分解を許し、非可換性(A_5 の単純性)がそれを阻む ── この一点が、同時対角化・量子の同時測定・5次の可解性を貫いている。

査読・限界(解説モード)

  • 依拠する標準事実:既約 ⇄ ガロア群が推移的、S_5 の推移的部分群は C_5,D_5,F_{20},A_5,S_5 の5種、冪根可解 ⇄ ガロア群が可解、A_5 が(非可換)単純群で非可解、x^5-2 のガロア群 =F_{20}、2\cos(2\pi/11) の最小多項式のガロア群 =C_5、Dummit の6次リゾルベントによる可解性判定、Hermite の楕円関数による一般5次の解法。標準的なガロア理論。
  • 境界(否定形):「解ける」は「冪根で」に相対的(§11、Hermite)。本記事は冪根可解性に話を限った。
