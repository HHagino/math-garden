多様体から軌道体へ ── 現代幾何はなぜ “点のまわりの対称性” まで記録するのか

1. 導入:多様体だけでは足りない場面がある

最近の幾何学では、多様体だけでなく 軌道体(orbifold) や スタック(stack) を扱うことが増えているらしい、と聞いたことがあるかもしれない。

普通の多様体では、各点の近くはユークリッド空間 \mathbb{R}^n の開集合のように見える ── これが多様体の定義であり、教科書の最初に習う基本だ。しかし、軌道体では、局所モデルが単なる \mathbb{R}^n ではなく、有限群 \Gamma の作用で割った商空間

\mathbb{R}^n / \Gamma

のようなものになる。

「単なる多様体じゃ何が足りないんだ?」「特異点を許せばいいだけでは?」── 自然な疑問だ。本記事は、軌道体が単なる「特異点付き多様体」ではなく、点の背後に残る対称性まで含めた幾何構造 であることを丁寧に説明する。

2. 多様体の局所モデル:\mathbb{R}^n

復習。多様体 M とは、各点 x \in M に対して、近傍 U \ni x が

\varphi : U \;\xrightarrow{\sim}\; V \subset \mathbb{R}^n

という同相(あるいは滑らかな同型)を持つ空間である。座標 \varphi を「チャート」と呼び、複数のチャートの重なりが整合的に貼り合うことを要請する。

ポイントは:多様体の各点は、近傍を取ればすべて区別がつかない。それはみな「\mathbb{R}^n の開集合」に同型で、点の「個性」はそこにはない。

3. 軌道体の局所モデル:\mathbb{R}^n / \Gamma

軌道体 \mathcal{X} では、各点 x の近傍は単純な \mathbb{R}^n ではなく、

(\widetilde{U}, G_x)

という組から作られる。\widetilde{U} は \mathbb{R}^n の(連結)開集合、G_x は有限群、そして G_x が \widetilde{U} に作用していて、点 x の近傍は商

\widetilde{U} / G_x

として表される。G_x を点 x の 局所群(local group) または イソトロピー群(isotropy group) と呼ぶ。

つまり、軌道体は「単にユークリッド空間で覆う」のではなく、「ユークリッド空間を有限群の対称性で割った塊で覆う」幾何構造である。

普通の点(つまり G_x が自明な点)では、局所モデルは \widetilde U / \{e\} = \widetilde U と多様体と変わらない。しかし、特別な点(固定点)では G_x が非自明になり、そこに「対称性のひだ」が残っている。

4. 軌道体は単なる特異空間ではない

ここが重要な区別。

商空間 \widetilde U / G_x を 集合や位相空間として だけ見ると、たとえば \mathbb{C} / (\mathbb{Z}/n)(回転群で割った円盤)は、中心が 円錐特異点 を持つ平面空間に見える。素朴には「特異点付き多様体」と呼びたくなる。

しかし、同じ位相空間が、複数の異なる軌道体構造を持ちうる。たとえば、円盤の中心の固定点に対して \mathbb{Z}/2 が作用するのか \mathbb{Z}/3 が作用するのかで、軌道体としては別物 ── でも商空間としての位相は同じだったりする。

つまり、軌道体は「点の集合 + 位相空間」だけでは復元できない。各点の背後に残る対称性(G_x という有限群)まで含めた構造 が軌道体である。

軌道体とは、点の集合ではなく、各点の背後に残る対称性まで含めた幾何構造である。

5. 固定点・安定化群・局所群の意味

具体例:円盤 D^2 = \{z \in \mathbb{C} \mid |z| \leq 1\} に、回転群 \Gamma = \mathbb{Z}/n を z \mapsto e^{2\pi i/n} z で作用させる。

  • 中心 0 は唯一の 固定点:\Gamma \cdot 0 = \{0\}。
  • それ以外の点 z \neq 0 では、\Gamma は自由に作用する(\gamma z = z なら \gamma = e)。

商空間 D^2 / \Gamma は、中心に 円錐角 2\pi/n を持つ「円錐」になる。中心は局所群 \mathbb{Z}/n を背負った特別な点、それ以外の点は局所群自明の普通の点。

軌道体としては、この円錐点の「ひだ(\mathbb{Z}/n の作用)」まで含めた構造が記録される。これを忘れて単なる位相空間として見ると、n = 2, 3, 4, \ldots の違いが消えてしまう。

つまり、軌道体は固定点に残る対称性を、幾何のデータとして忘れない。

6. モジュライ空間で軌道体が自然に出る理由

軌道体が「面白い特殊例」だけなら、わざわざ多様体と区別する必要はない。重要なのは:対象を分類しようとすると、モジュライ空間が普通の多様体ではなく軌道体やスタックになりやすい こと。

分類問題の基本構造:

対象を分類する ⟶ 同型関係で割る ⟶ 自己同型が残る ⟶ 多様体ではなく軌道体 / スタックが自然に出る。

詳しく見よう。ある種の数学的対象(リーマン面、ベクトル束、代数曲線、…)の集合を考え、それらを「同型」で類別する。各同型類の代表元の周りでパラメータを動かすと、滑らかに変形できるので、局所的にはユークリッド空間のように見える。

ところが、ある対象に非自明な自己同型(\sigma : X \to X で \sigma \neq \mathrm{id} なもの)があると、その点の局所モデルは、変形空間 \widetilde U を自己同型群 \mathrm{Aut}(X) で割ったものになる。

つまり、自己同型を持つ対象の周りでは、モジュライ空間は 「変形空間 ÷ 自己同型群」 という商空間として現れる。これは、ちょうど第 3 節の \widetilde U / G_x の構造そのもの。だから、モジュライ空間は自然に軌道体構造を持つ。

7. リーマン面のモジュライ空間の例

具体例として、コンパクト・リーマン面の moduli 空間 \mathcal{M}_g(g は種数)を挙げる。

種数 g \geq 2 のリーマン面を分類する標準的な手段は:

\mathcal{M}_g \;=\; \mathcal{T}_g \;/\; \mathrm{Mod}_g

ここで、\mathcal{T}_g は タイヒミュラー空間(滑らかな複素多様体、種数 g で次元 3g - 3)、\mathrm{Mod}_g は 写像類群 で、\mathcal{T}_g に正則に作用する。

ところが、\mathrm{Mod}_g の作用は一般に自由ではない ── 自己同型を持つリーマン面(例えばハイパー楕円曲面など)の点では、写像類群の固定群が非自明になる。

その結果、\mathcal{M}_g は単純な複素多様体ではなく、複素軌道体 の構造を自然に持つ。各点 [X] \in \mathcal{M}_g の局所群はちょうど \mathrm{Aut}(X)。

ここで軌道体は「分類空間に残った自己同型の記録装置」として機能している。

8. シンプレクティック幾何・Gromov–Witten 理論・stringy topology への広がり

軌道体は、現代幾何のあちこちに自然に現れる。

  • シンプレクティック幾何: ハミルトン群作用の運動量写像による商(シンプレクティック・リダクション)は、しばしば軌道体として現れる。固定点では局所群が非自明になる。
  • Gromov–Witten 理論: 安定写像のモジュライ空間 \overline{\mathcal{M}}_{g,n}(X, \beta) は、軌道体(あるいはより一般にスタック)として扱われる。自己同型を持つ安定写像が、軌道体構造を作る。
  • Chen–Ruan コホモロジー / stringy topology: 軌道体上のコホモロジー理論として、Chen–Ruan コホモロジー が定義される。これは普通のコホモロジー H^\bullet(|\mathcal{X}|)(位相空間としての軌道体の特異コホモロジー)に、twisted sector と呼ばれる「対称性の “ひだ” に対応する追加成分」を足したものだ。
  • オービフォールド弦理論: 弦理論では、軌道体の特異点の背後にある群作用が、追加の物理的状態(twisted sector の弦)を生む。特異点を単に “欠陥” として除去するのではなく、そこから新しい幾何的・物理的情報が湧き出す。

これらに共通するメッセージは:

対称性で割った空間の特異性を、単なる欠陥として消すのではなく、そこに残る群作用そのものを幾何的・物理的情報として扱う。

軌道体は、そのための言語である。

9. グロタンディーク的視点:点ではなく、点の背後の自己同型まで見る

ここで、グロタンディーク的な発想に触れたい。

普通の多様体では、「点の近くは \mathbb{R}^n」というだけで済む。点の個性はなく、局所構造もすべて同じ。

軌道体では、「点の近くは \mathbb{R}^n / G_x で、G_x がどのように作用しているか」までが構造だ。点に 個性(局所群) がある。

これを スタック の発想にまで進めると、空間を「点の集合」ではなく、「点とその間の同型射(対称性)を含む圏」として見る。多様体は、点の集合に局所構造を入れたものだったが、スタックは、点 と その自己同型まで含めた幾何対象だ。

軌道体は、スタックの最も初等的な例 ── 局所群が有限群の場合 ── として位置付けられる。スタックへの入口である。

これは、グロタンディークが代数幾何において提唱した「空間を、その上の関数や層、点への近づき方を含めて理解する」という発想とも響き合う。空間を点集合として見るのではなく、点へのアクセスの仕方(自己同型、被覆、対称性)まで含めて見る 視点が、軌道体・スタックの背後にある。

10. 結論:現代幾何は「場所」だけでなく「対称性を背負った場所」を扱う

最後に、誤解されやすい点を明示しておく。

「現代幾何は多様体を捨てた」と言うのは正確ではない。多様体は依然として基本例であり、研究の主役の一つである。軌道体やスタックは、多様体を 基本例として含む 拡張であって、置き換えではない。

ただし、モジュライ問題や群作用を扱うと、多様体の枠だけでは情報を落としすぎる場面がある。そこで、自己同型・特異性・対称性を自然に扱える軌道体やスタックが必要になる。

多様体が「局所的にユークリッド空間である場所」の幾何だとすれば、軌道体は「局所的にユークリッド空間を有限対称性で割った場所」の幾何である。

しかし本質は、特異点を許すこと そのもの ではない。本質は、点の背後に残る対称性を忘れず、それを空間の構造として扱うこと にある。

現代幾何が軌道体やスタックに向かうのは、空間をより複雑にしたいからではない。分類・対称性・自己同型を正直に扱うと、そこに自然に到達してしまうから である。

軌道体は、「点の集まり」を超えて、「対称性を背負った場所の集まり」として空間を見るための、ひとつの誠実な語彙である。
