イロ式レーティングと確率的勾配法

イロ式レーティングの更新式をロジスティック模型の確率的勾配法として読み、刻み幅 K が決める速さと揺れの引き換えを R の実験で確かめる。
公開

2026年10月28日

1. 導入：1500 対 1700 を手で計算する

レーティング 1500 の A と 1700 の B が指す。イロ式では、A が「得点」で期待できる量を

E_A=\frac{1}{1+10^{(R_B-R_A)/400}}=\frac{1}{1+10^{200/400}}\approx 0.240

と置く。勝ちを 1、引き分けを 0.5、負けを 0 と数えた得点 S が期待 E より大きければ点が上がり、小さければ下がる。K=32 とすると、

  • A が勝てば、A は 32\times(1-0.240)=+24.3 点、B は -24.3 点
  • 引き分けなら、A は 32\times(0.5-0.240)=+8.3 点、B は -8.3 点
  • A が負ければ、A は 32\times(0-0.240)=-7.7 点

これが更新式 R\leftarrow R+K(S-E) のすべてである。この記事で問うのは、この単純な式が統計の言葉で何をしているのか、だ。結論を先に並べる。

イロ式の言葉 統計の言葉
差 400 で勝ちやすさが 10 倍 ロジスティック模型(Bradley–Terry 模型)の尺度の選び方
期待得点 E 模型が予言する S の平均
R\leftarrow R+K(S-E) 1 局ぶんの対数尤度の勾配を 1 回登る確率的勾配法(刻み幅は一定)
K 刻み幅。大きいと速く動くが、いつまでも揺れる
「毎回はじめから数え直す」 対局の列に対する決定的な関数。ただし順番を入れ替えると値が変わる

後半では R で対局を作り、これらを数字で確かめる。確かめて分かったのは、K=32 のとき表示される点には、ふだんから ±40〜50 点ほどの揺れが乗っているということだ。

2. 勝つ確率のモデル

差 d=R_A-R_B に対し E=1/(1+10^{-d/400}) と置くと、定数 c=\ln 10/400 を使って

E=\frac{1}{1+e^{-cd}}

というロジスティック関数になる。勝つ見込み(オッズ)は E/(1-E)=10^{d/400} なので、差が 400 開くごとにオッズが 10 倍になる。差 100 で E=0.640、200 で 0.760、400 で 0.909(10 対 1)。

各人に正の数 \pi_i=10^{R_i/400} を割り当て、i が j に勝つ確率を \pi_i/(\pi_i+\pi_j) とする模型が、Bradley と Terry の paired comparison 模型である(書誌は査読節)。\pi_i/(\pi_i+\pi_j) に \pi=10^{R/400} を入れれば上の E に一致する。どちらも同じ模型の書き方の違いにすぎない。

この模型で意味を持つのは差だけで、全員に同じ数を足しても確率は変わらない。「1500 から始める」は計算の都合の約束であって、強さの絶対的な目盛りではない。400 という数も、底を 10 にして見やすい数にそろえるための選択だ。

3. 更新式は何をしているか

一局ぶんの対数尤度を、得点 S\in\{0,\tfrac12,1\} について

\ell=S\ln E+(1-S)\ln(1-E)

と書く(S が 0 か 1 なら普通の Bernoulli の対数尤度)。E=\sigma(cd) のとき \sigma'=\sigma(1-\sigma) だから

\frac{\partial \ell}{\partial d}=c\,(S-E).

ここで S\ln E の微分は S\,cE(1-E)/E=cS(1-E)、(1-S)\ln(1-E) の微分は -c(1-S)E で、足すと c(S-E) になる。数値微分でも S=0,\tfrac12,1 の三通りで一致した(差 -200 で -0.001383,\ 0.001495,\ 0.004373)。

R_A は d に +1、R_B は -1 で入るので、R_A を勾配の向きに刻み幅 \eta で動かすと \Delta R_A=\eta c(S-E)。これが K(S-E) に等しいとおけば

\boxed{\ \eta=\frac{K}{c}=\frac{400}{\ln 10}K\ \ (\approx 173.7K)\ }

となる。K=32 なら \eta\approx5559 で、この数に意味はないが、K は勾配法の刻み幅を点の単位に直したものだと分かる。つまり更新式は「1 局ぶんの対数尤度に対し、片方の点を上げ片方を下げる、一定幅の 1 歩」だ。2 人の点の和が保存されるのは、d にしか尤度が依存しないことの反映である。

全対局を並べた対数尤度 L=\sum_{\text{局}}\ell の最大化を考えると、i の点について

\frac{\partial L}{\partial R_i}=c\sum_{i\text{ が指した局}}(S-E)=0

つまり「各人の実際の得点の合計＝模型が予言する得点の合計」が最尤の条件になる(引き分けを 0.5 と数えれば、これは正しい確率模型の尤度ではなく準尤度だが、条件の形は同じ)。イロ式は、この方程式の左辺の 1 項ずつを拾って歩いているとも読める。

この式は、S の平均だけを使っている点に注意したい。E[S]=E が成り立っていれば、S が 0/1 の Bernoulli でなくても更新は平均として正しい方向に動く。引き分けが入っても方程式の形が保たれる理由はここにある(7 節の実験D)。

1 局の損失 -\ell は、S を確率 E の予言と比べる交差エントロピーで、S\in\{0,1\} の場合は KL 情報量 \mathrm{KL}(S\,\|\,E) そのものである。この見方は、距離と発散を並べた Frank Nielsen の距離・発散の地図を読む の、KL が局所で Fisher 計量になる話へ続く。点が真の値へ戻る速さは、この曲率 c^2E(1-E) に刻み幅 \eta を掛けたもので決まる(次節)。

読みの境界. 「イロ式は確率的勾配法である」は、式の形が一致するという意味での読みだ。Elo 自身がそう導いたとは言っていない(Elo の本は未確認、査読節)。

4. Kの引き換え：速さと揺れ

一定の刻み幅の確率的勾配法は、最適点に収束しない。最適点の周りで揺れ続ける。この揺れは、最も簡単な場合に閉じた形で書ける。

2 人だけ、真の差が 0、勝敗が五分の場合。R_A=x,\ R_B=-x とすると d=2x で、x の更新は x\leftarrow x+K(S-E(2x))。x=0 の周りで E(2x)\approx\tfrac12+\tfrac{c}{2}x、また \mathrm{Var}(S)=\tfrac14 なので、S-E(2x)=\xi-\tfrac c2x(\xi は平均 0・分散 \tfrac14)と書けて

x_{t+1}=\Big(1-\frac{Kc}{2}\Big)x_t+K\xi_t.

これは AR(1) 過程で、定常分散は \dfrac{K^2/4}{1-(1-Kc/2)^2}。整理すると

\mathrm{Var}(x)=\frac{K}{4c}\cdot\frac{1}{1-Kc/4}\ \approx\ \frac{K}{4c}\quad(Kc\ll1).

分散は K に比例して増え、一方で真の値へ戻る速さ(1-Kc/2 の幅)も K に比例する。速く動く刻み幅は、同じ割合で揺れる。これが引き換えの正体だ。標準偏差で書けば \sqrt{K/(4c)}\approx6.6\sqrt K 点。

K 理論(上の式) 実測(R、40万局)
4 13.2 13.2
16 26.7 27.0
32 38.2 39.1
64 55.3 57.7

K が大きいほど誤差が開くのは、E を直線で近似した一次の見積もりを使ったためだろう(確かめてはいない)。K\le32 では 3% 以内で合う。

もう一つ、読み方がある。2 人の差 d=2x を n 局の最尤で推定したときの標準偏差は 2/(c\sqrt n)。これを K=32 の定常の標準偏差 2\times38.2=76.4 と等置すると n\approx21。分散だけを合わせた目安にすぎないが、K=32 のイロ式は、およそ直近 20 局ぶんの情報で推定していることに相当する。

FIDE の規定でも K は固定ではなく、新しく登録された人は 30 局を終えるまで K=40、その後 2400 未満なら 20、一度 2400 に達したら(その後下回っても)10 と段階を踏んで小さくなる。ただし 18 歳の年の終わりまでは、2300 未満である限り 40 のままという例外がある(英語版の規定 8.3.3。査読節)。データが貯まるほど刻み幅を絞る、確率的勾配法の常套手段と形が似ている。意図までは確かめていないので、似ている、までにとどめる。

5. 道場の実装：毎回はじめから数え直す

筆者は友人どうしで指す対局ページ(将棋・チェス・囲碁・オセロ)を作り、勝敗からレーティングを出している。その計算部分は次のとおり(抜粋・整形。元は JavaScript)。

var K = 32, START = 1500;
function ratings(games){
  var done = games.filter(g => g.status==="done" && g.rated && g.result && g.finishedAt
                               && g.seats.first && g.seats.second && g.seats.first!==g.seats.second)
                  .sort((a,b) => a.finishedAt<b.finishedAt ? -1 : a.finishedAt>b.finishedAt ? 1 : (a.id<b.id?-1:a.id>b.id?1:0));
  var table = {};
  function get(k){ return table[k] || (table[k] = {r:START, n:0, w:0, l:0, d:0}); }
  done.forEach(function(g){
    var a = get(g.seats.first), b = get(g.seats.second);
    var ea = 1 / (1 + Math.pow(10, (b.r - a.r) / 400));
    var sa = g.result.winner==="first" ? 1 : g.result.winner==="second" ? 0 : 0.5;
    var da = K * (sa - ea);  a.r += da;  b.r -= da;  ...
  });
  return table;
}

各人が自分の点を書き込まず、終わった平手の対局を終了時刻の順に並べて毎回最初から 1500 で数える。二人が同時に結果を書いても点が二重に加わらず、記録だけが正本になる。ハンデ戦は強さの差を前提にした勝負で、2節の模型(同じ条件で指す)から外れるので数えない。

ここで気づく点がある。この関数は、対局の集合ではなく列の関数だ。同じ対局の集合でも、順番を入れ替えると値が変わる。実験Bで、同じ対局を 200 通りに並べ替え、各人の最終の点がどれだけ動くかを測った(次節)。決定的なので「毎回同じ表が出る」ことは保証されるが、それは「正しい強さが出る」こととは別だ。

6. Rで確かめる

道具は次の 4 つ。E、対局の生成、イロ式、そして比べるための Bradley–Terry の最尤(MM 法。全員に「強さ 0 の仮想の相手と 1 局引き分けた」記録を足し、全勝・全敗の人で発散するのを防いである)。

E  <- function(d) 1 / (1 + 10^(-d / 400))
mkgames <- function(n, theta) {                # theta = 真の強さ。ペアは一様に選ぶ
  N <- length(theta)
  a <- sample(N, n, TRUE); b <- sample(N - 1, n, TRUE); b <- ifelse(b >= a, b + 1, b)
  data.frame(a = a, b = b, S = as.numeric(runif(n) < E(theta[a] - theta[b])))
}
elo <- function(g, N, K, R0 = 0) {
  R <- rep(R0, N)
  for (i in seq_len(nrow(g))) {
    a <- g$a[i]; b <- g$b[i]
    d <- K * (g$S[i] - E(R[a] - R[b])); R[a] <- R[a] + d; R[b] <- R[b] - d
  }
  R
}
btfit <- function(g, N, iters = 500) {         # 最尤(MM法)・仮想相手つき
  cc <- log(10) / 400
  W <- matrix(0, N, N)
  for (k in seq_len(nrow(g))) { a <- g$a[k]; b <- g$b[k]
    W[a, b] <- W[a, b] + g$S[k]; W[b, a] <- W[b, a] + 1 - g$S[k] }
  n <- W + t(W); w <- rowSums(W) + 0.5; v <- rep(1, N)
  for (it in seq_len(iters)) {
    den <- sapply(seq_len(N), function(i) sum(n[i, -i] / (v[i] + v[-i])) + 1 / (v[i] + 1))
    v <- w / den; v <- v / exp(mean(log(v)))
  }
  log(v) / cc
}
N <- 8; theta <- seq(-280, 280, length.out = N)   # 8 人、真の強さを 80 点刻み
ctr  <- function(x) x - mean(x)
rmse <- function(R) sqrt(mean((ctr(R) - ctr(theta))^2))

実験A(一人あたりの対局数 m と K)。8 人(真の強さの標準偏差は 183 点)、ペアは一様、一人あたり m 局ぶんの対局を作り、全員 0(=1500)から始めて、真の強さとの RMSE を 300 回の平均で測った。

m K=4 K=16 K=32 K=64 最尤
10 174.7 152.8 131.3 106.1 116.0
30 159.2 111.2 79.9 70.6 68.5
100 118.6 51.4 47.9 71.2 37.8
300 59.8 33.5 48.6 71.5 21.5
1000 17.8 34.4 50.1 73.6 11.6

読み取れること。

  1. 序盤は大きい K が勝つ。m=10 で、K=4 の誤差(174.7)は真の強さの散らばり(183)と変わらず、ほとんど何も学べていない。
  2. 終盤は小さい K が勝つ。m=1000 で K=4 は 17.8、K=64 は 73.6 のまま。底は 4 節の定常の揺れで決まり、プール全体では 2 人の場合より少し大きい(8 人の係数は確かめていない)。
  3. どの定数 K も最尤に追いつかない。m=1000 の最尤は 11.6。K=16 の底は 34、K=32 は 50 で、数が増えても減らない。
  4. m=10 では最尤(116)が K=64(106)に負ける。局数が少ないと、仮想の相手 1 局ぶんしか縮めていない最尤は散らばりすぎ、0 から動き始めるイロ式のほうが結果として強く縮めた推定になっているからだ。最尤の優位がはっきり出るのは m\ge100 からである。

実験B(順番依存)。同じ対局(一人 100 局)を 200 通りに並べ替え、各人の最終の点の標準偏差を平均した(30 組の対局で)。

K 4 16 32 64
順番だけで動く標準偏差(点) 2.2 16.5 34.2 61.5

最尤は集合の関数だから、この数は 0 である。K=32 では、まったく同じ勝敗の集合から、順番次第で ±34 点の別の表ができる。実験A(m=100, K=32)の誤差 47.9 のうち、これは小さくない部分を占める。道場が「終了時刻の順」を使うのは、順番の候補のうち、誰にも文句の出ない一つを選ぶ規約であって、値を正しくする操作ではない。

7. 崩れるところ

D. 引き分け。引き分け確率を \delta=f\cdot2\min(E,1-E)、勝つ確率を E-\delta/2 にすると、E[S]=E のまま引き分けだけ増やせる(f=0,0.5,1 で実際の引き分け率は 0, 0.23, 0.46)。一人 100 局の RMSE:

f 引き分け率 K=16 K=32 最尤
0 0 51.6 47.7 37.5
0.5 0.23 47.5 38.4 29.2
1 0.46 45.5 29.2 20.8

誤差は減る。引き分けは S-E の分散を下げる(0.163 から 0.048)からだ。3 節の読みどおり、E[S] が合っていれば引き分けがあっても更新は同じ点へ向かう。ただし「引き分けが多い対戦は力が近い」という情報は使えていない。それを使うなら引き分けを明示した別の模型が要るが、ここでは扱わない。また、この実験の引き分けは E[S]=E が成り立つように作ったもので、実際の将棋やチェスの引き分けがそうなっている保証はない。

E. 強さが動く。1 局ごとに全員の真の強さが標準偏差 \sigma のランダムウォークをする場合に、最後の時点の真の強さと比べた RMSE(一人 400 局):

\sigma(1 局あたり) 全期間での動き K=4 K=16 K=32 最尤(全履歴)
0 0 44.6 33.1 48.3 19.3
1.5 約 60 57.7 37.3 49.6 37.8
4 約 160 100.7 57.8 59.3 89.6

強さが固定なら最尤が圧勝するが、動くと全履歴を等しく使う最尤は、一定の K のイロ式に並ばれ、最後には負ける(\sigma=4 で 89.6 対 57.8)。K が一定とは「古い局を指数的に忘れる」ことで、動く標的には、忘れる性質が武器になる。このとき K の最適は動きの速さで変わる(試した三つの K の中では K=16 が最良だったが、他の \sigma や人数では別の値になりうる)。

F. 三すくみ。1 が 2 に、2 が 3 に、3 が 1 に 0.75 の確率で勝つ。強弱が一列に並ばないから、どんな点の割り当てもこの結果を再現できない。最尤は 3 人をほぼ同点(幅 11)に置き、当てはめ後の 1 局あたり平均対数尤度は -0.693=\ln\tfrac12 で、真の値 -0.562 より悪い。イロ式の点(K=16)の後半の揺れは標準偏差 29.7・三者の幅 63.9 で、3 人が互角のとき(30.1、64.6)と見分けがつかない。点は「相手に依らない強さ」を前提にしており、相性は点の差としては現れない。

その他、実験していない崩れ。先手と後手の有利(チェスの白など)は、点の外に出る別の要因で、実験に入れていない。対局相手の偏り(いつも同じ 2 人が指す)で点が全体につながらなくなる場合、最尤は存在しない(全勝の人は点が無限大へ飛ぶ。上の btfit が仮想の相手を足しているのはこのため)。この最尤の存在が条件つきという形は、最尤推定と軌道閉包 で扱う別の模型のそれと同じだが、中身は別の話であり、同じ定理とは言っていない。

8. 締め：表示された点に、誤差の棒を付けるなら

道場の画面に「1532」と出るとき、この数字はおよそ「直近 20 局ぶんの情報から出した推定」で、K=32 の揺れは ±40 点ほどある。差が 50 点なら、強さの差ではなく運の差かもしれない。点そのものより、どれだけ揺れる量を見せられているかが、見る人に伝わる設計は可能だろうか。たとえば局数 n に応じて K を小さくした点と、K が決める揺れの幅を並べて示す。それをやると、点は「強さ」ではなく「ある K で追跡した推定量」として扱われる。その代わり、友人どうしの遊びの熱は少し冷めるかもしれない。どちらが良いかは、ここでは決めない。

9. 査読・限界

この記事のモードは三つにまたがる(外部事実・純粋数学・数値実験)。

外部事実 - Bradley, R. A. & Terry, M. E. (1952), “Rank Analysis of Incomplete Block Designs: The Method of Paired Comparisons”, Biometrika 39(3–4), 324–345。出版社(Oxford Academic)のページで書誌のみ確認した。本文は購読が要り開いていない。したがって「\pi_i/(\pi_i+\pi_j) の形」はこの論文を読んだ上での記述ではなく、一般に Bradley–Terry 模型として知られている形を書いたものである。 - FIDE の規定(FIDE Rating Regulations, Handbook B.02, 2024 年 3 月施行版のページ。2025 年 10 月 1 日施行の改定を含む)。確認できたのは英語版のみで、日本語版は見つからなかった(探した範囲は handbook.fide.com の B.02 の頁。日本語への切り替えは無い)。原文の本文に語を当てて次を確認した(通読はしていない):K=40(新規で 30 局まで)・20(2400 未満)・10(一度 2400 に達した後は、下回っても)・18 歳の年の終わりまでは 2300 未満なら 40・一つの期間で K\times n(n は局数)が 700 を超えないよう K を下げる上限(以上 8.3.3)。400 点を超える差は 400 とみなす規則(2025 年 10 月 1 日施行。2650 以上は対象外。8.3.1)。期待得点は式でなく換算表 8.1.2 で与えられ、1 局ぶんの量が「得点 − P_D」、それを大会または期間で合計してから K を掛ける(8.3.2)。つまり FIDE の更新は 1 局ごとではなく、期間ごとにまとめてである。表 8.1.2 の値を式 E と照らすと、差 198〜206 で表 0.76・式 0.760、差 65 で表 0.59・式 0.593 は合うが、差 392〜411 で表 0.92・式 0.909、差 422 で表 0.93・式 0.919 と、差が大きい所で表のほうが開く。「差 400 で 10 倍」の尺度は FIDE の表と同じではない(表の由来は頁に書かれていない)。 - Elo, A. E. (1978), The Rating of Chessplayers, Past and Present は開いていない。更新式や 400 の起源についての記述は、この記事では引いていない。

純粋数学(導出) - 3 節の勾配と、4 節の AR(1) による定常分散は、本文中の仮定(2 人・真の差 0・五分・x=0 の周りの一次近似)の下での計算。一次近似なので K が大きいと理論は実測より小さく出る(上の表)。「K=32 は約 20 局ぶんの推定」は分散を等置しただけの目安で、重みの形が違う(指数と等重)ため同等という主張ではない。 - 「確率的勾配法」という読みは、式の形の一致であって、イロ式の由来の説明ではない。

数値実験 - 設定は 8 人(真の強さは 80 点刻みの等間隔)・ペア一様・乱数の種を固定。別の人数・別の強さの散らばり・偏ったペア選択では数字は変わる。傾向(序盤は大きい K、終盤は小さい K、順番依存は K に比例して増える)は確かめたが、具体的な点数を一般の値として読まないでほしい。 - 最尤は「仮想の相手と 1 局引き分け」で縮めてあり、純粋な最尤ではない。少ない局数の比較(特に m=10)はこの正則化に左右される。 - 実験D の引き分けは E[S]=E となるように作った。実際の引き分けの機構ではない。 - 実験の結果の再現には、記事中のコードに加え、各実験の反復回数(A=300, B=30×200, C=40万局, D=300, E=100, F=100。F は 3 人で 3000 局を指させ、後半 1500 局の揺れを測った)と乱数の種(set.seed)が要る。すべてを載せたスクリプトは手元にあるが、この記事には載せていない。

言えないこと。この記事は「イロ式の点はふつうの推定量として何者か」を示したのであって、「イロ式がレーティングとして最良か」は論じていない。最良かは何を目的にするか(動く強さの追跡か、固定された強さの推定か、対戦相手の見つけやすさか)で変わる。
