Chapter 7第7章　超対称量子力学

この章では、\(Q^2=0\) と \(H=\{Q,Q^{\dagger}\}\) という二本の式だけから、正のエネルギーの準位がボソンとフェルミオンの対になること、零エネルギー状態の数が \(\ker Q/\operatorname{im}Q\) で決まること、Witten 指数が \(\beta\) によらないことを、有限次元で完全に証明する。次に直線上の模型 \(Q=\psi^{\dagger}(\partial_x+W')\) で \(H\) を書き下し、零エネルギー状態を一階の常微分方程式から求めて、超対称性が破れるかどうかの判定表を作る。最後に \(W=tf\) と置いて、これが Morse–Witten の教科書（以下 MW）の 1 次元の \(\Delta_t\) そのものであり、\(H_\hbar=\hbar^2\Delta_{1/\hbar}\) となることを計算で示す。

第2部は \(\hbar=1\) で書く。状態は \(\Psi,\Phi\)、小文字の \(\psi,\psi^{\dagger}\) はフェルミオンの演算子である（第1部の波動関数 \(\psi\) とは別。記法の表 §1）。超対称量子力学の規格化は MW と同じで、第1部の \(\frac12P^2\) の規格化との換算は §7.5 と §7.6 で確かめる。

到達目標 1. 超対称代数（\(Q^2=0\)、\(H=\{Q,Q^{\dagger}\}\)）の一般論として、正のエネルギーがボソンとフェルミオンの対になること、\(\ker H\cong\ker Q/\operatorname{im}Q\)、Witten 指数が \(\beta\) によらないことを証明する（有限次元で完全に、無限次元は条件を明示して）。 2. 直線上の Witten 模型 \(Q=\psi^{\dagger}(\partial_x+W')\) から \(H=-\partial_x^2+W'^2+W''[\psi^{\dagger},\psi]\) を導き、零エネルギー状態 \(e^{-W}\vert0\rangle\)・\(e^{W}\vert1\rangle\) の規格化可能性から、超対称性が破れるかと Witten 指数を判定できる。 3. \(W=tf\) と置くと、これが MW の 1 次元の \(\Delta_t\)（MW §5.4）そのものであり、\(H_\hbar=\hbar^2\Delta_{1/\hbar}\) であることを計算で示す。

前提：定理 3.4（振動子のスペクトル）、命題 6.6（フェルミオンの Fock 空間）、定義 6.18（超跡）。 この章で増やす記号：\(D=\partial_x+W'(x)\)、\(D^{\dagger}=-\partial_x+W'(x)\)（\(W\) は実数値。直線上の一階の作用素）。\(H_0,H_1\) は \(H\) の \(F=0\) と \(F=1\) の部分。\(N_{\mathrm B}=a^{\dagger}a\)（ボソンの個数）、\(N_{\mathrm F}=\psi^{\dagger}\psi\)（フェルミオンの個数）。格子の演算子は添字 \(h\) を付ける。

7.1 超対称代数

この節では、超対称代数を定義し、\(H\ge0\) と \(\ker H=\ker Q\cap\ker Q^{\dagger}\) を証明し、MW の定義 2.1 の形（\(Q_1,Q_2\)）との同値を確かめる。

定義 7.1（超対称代数） \(\mathbb Z_2\) 次数つき Hilbert 空間 \(\HH=\HH_{\mathrm B}\oplus\HH_{\mathrm F}\) と、次数を測る自己共役な \((-1)^F\)（\(\HH_{\mathrm B}\) で \(+1\)、\(\HH_{\mathrm F}\) で \(-1\)）を取る。超電荷は、\((-1)^F\) と反交換する（奇の）作用素 \(Q\) で \[Q^2=0,\qquad H=\{Q,Q^{\dagger}\}=QQ^{\dagger}+Q^{\dagger}Q\] を満たすもの。\(H\) を Hamiltonian と呼ぶ。\(Q^{\dagger}\) も奇で \((Q^{\dagger})^2=0\)。以下 §7.1〜7.2 では \(\HH\) が有限次元、または \(Q\) が有界であるとする（§7.3 の定理 7.4・7.5 は、無限次元で使う仮定をそれぞれの主張に書く）。

命題 7.1〔証明〕 (a) \(\langle\Psi,H\Psi\rangle=\Vert Q\Psi\Vert^2+\Vert Q^{\dagger}\Psi\Vert^2\ge0\)。 (b) \(\ker H=\ker Q\cap\ker Q^{\dagger}\)。 (c) \(H\) は \(Q,Q^{\dagger},(-1)^F\) と可換。

証明. (a) 定義から直ちに。(b) \(\supset\) は明らか。\(H\Psi=0\) なら (a) の左辺が 0 で、右辺の二項がどちらも 0。(c) \(QH=QQ^{\dagger}Q\)（\(Q^2=0\) を使った）\(=HQ\)。\(Q^{\dagger}\) も同様。\(H\) は偶（奇の作用素二つの積の和）だから \((-1)^F\) と可換。\(\square\)

MW との同値. MW の定義 2.1 は自己共役な \(Q_1,Q_2\) と \(\{Q_a,Q_b\}=2\delta_{ab}H\) を置く。\(Q=\frac12(Q_1+iQ_2)\) と置くと \(Q^{\dagger}=\frac12(Q_1-iQ_2)\) で、逆に \(Q_1=Q+Q^{\dagger}\)、\(Q_2=-i(Q-Q^{\dagger})\) である。

命題 7.2（MW の形との同値）〔証明〕 定義 7.1 の \(Q\) に対し \(Q_1=Q+Q^{\dagger}\)、\(Q_2=-i(Q-Q^{\dagger})\) は自己共役で奇、\(Q_1^2=Q_2^2=H\)、\(\{Q_1,Q_2\}=0\)。逆に MW の形が与えられれば \(Q=\frac12(Q_1+iQ_2)\) が定義 7.1 を満たす。

証明. \(Q_1^2=Q^2+QQ^{\dagger}+Q^{\dagger}Q+(Q^{\dagger})^2=H\)。\(Q_2^2=-(Q-Q^{\dagger})^2=-(-QQ^{\dagger}-Q^{\dagger}Q)=H\)。\(\{Q_1,Q_2\}=-i\bigl[(Q+Q^{\dagger})(Q-Q^{\dagger})+(Q-Q^{\dagger})(Q+Q^{\dagger})\bigr]=-i\,(2Q^2-2(Q^{\dagger})^2)=0\)。逆向き：\(\{Q_1,Q_1\}=2H\) から \(Q_1^2=H\) などを使って \(Q^2=\frac14(Q_1^2-Q_2^2+i\{Q_1,Q_2\})=0\)、\(\{Q,Q^{\dagger}\}=\frac14(\{Q_1,Q_1\}+\{Q_2,Q_2\})=H\)。\(\square\)

この同値で \(Q_1\) が自己共役な奇の作用素で \(Q_1^2=H\) となるので、\(Q_1\) は \(H\) の「平方根」である。§7.3 の指数の証明はこの \(Q_1\) を使う。

注意 7.1（無限次元の定義域）〔主張〕 \(\HH\) が無限次元で \(Q\) が非有界のとき、\(H=QQ^{\dagger}+Q^{\dagger}Q\) をどの定義域で自己共役な作用素と見るかは別の問題である。\(Q\) が閉で稠密に定義されていれば、二次形式 \(\Vert Q\Psi\Vert^2+\Vert Q^{\dagger}\Psi\Vert^2\)（定義域 \(\operatorname{dom}Q\cap\operatorname{dom}Q^{\dagger}\)）は閉形式になり、形式の表現定理により自己共役な作用素 \(H\) が一つ決まる（Kato『線形作用素の摂動論』、書誌のみ・本文未確認）。この \(H\) で命題 7.1(a)(b) は \(\operatorname{dom}Q\cap\operatorname{dom}Q^{\dagger}\) の元に対して成り立つ。この章の §7.4 以降はこの意味で \(H\) を使い、定義域の細部は追わない。

7.2 対構造と抽象的な Hodge 分解

この節では、有限次元の超対称代数について、空間が三つの直交する部分空間に分かれること、零エネルギー状態が \(\ker Q/\operatorname{im}Q\) と同型なこと、正のエネルギーの準位が対をなすことを証明する。

命題 7.3（対構造と抽象的な Hodge 分解）〔証明〕 \(\HH\) は有限次元とする。 (a) \(\HH=\ker H\oplus\operatorname{im}Q\oplus\operatorname{im}Q^{\dagger}\)（直交直和）。 (b) \(\ker Q=\ker H\oplus\operatorname{im}Q\)。とくに自然な写像 \(\ker H\to\ker Q/\operatorname{im}Q\) は同型。 (c) \(E\gt0\) の固有空間を \(V_E\) とすると、\(Q\colon V_E\cap\ker Q^{\dagger}\to V_E\cap\ker Q\) は同型で、逆は \(\frac1EQ^{\dagger}\)。 (d) \(V_E=(V_E\cap\ker Q)\oplus(V_E\cap\ker Q^{\dagger})\)。 (e) 命題 7.2 の \(Q_1\) は \(V_E\cap\HH_{\mathrm B}\) から \(V_E\cap\HH_{\mathrm F}\) への同型を与える。よって \(\dim(V_E\cap\HH_{\mathrm B})=\dim(V_E\cap\HH_{\mathrm F})\)。

証明. (a) \(\langle Q\Phi,Q^{\dagger}\Xi\rangle=\langle Q^2\Phi,\Xi\rangle=0\) なので \(\operatorname{im}Q\perp\operatorname{im}Q^{\dagger}\)。随伴の一般則 \((\operatorname{im}Q)^{\perp}=\ker Q^{\dagger}\)、\((\operatorname{im}Q^{\dagger})^{\perp}=\ker Q\) を使うと、\((\operatorname{im}Q\oplus\operatorname{im}Q^{\dagger})^{\perp}=\ker Q^{\dagger}\cap\ker Q=\ker H\)（命題 7.1(b)）。有限次元では直交補空間の補空間がもとに戻るので (a)。 (b) \(\ker Q=(\operatorname{im}Q^{\dagger})^{\perp}\) であり、(a) から \((\operatorname{im}Q^{\dagger})^{\perp}=\ker H\oplus\operatorname{im}Q\)。\(\operatorname{im}Q\subset\ker Q\)（\(Q^2=0\)）だから商は \(\ker H\) に同型。 (c) \(V_E\) は \(Q,Q^{\dagger}\) で不変（命題 7.1(c)）。\(v\in V_E\cap\ker Q^{\dagger}\) なら \(Ev=Hv=Q^{\dagger}Qv\)、\(v\in V_E\cap\ker Q\) なら \(Ev=QQ^{\dagger}v\)。したがって \(Q^{\dagger}Q=E\) が \(V_E\cap\ker Q^{\dagger}\) の上、\(QQ^{\dagger}=E\) が \(V_E\cap\ker Q\) の上にある。\(Q\) は \(V_E\cap\ker Q^{\dagger}\) を \(V_E\cap\ker Q\) に写す（\(Q(Qv)=Q^2v=0\) で \(Qv\in\ker Q\)、\(H\) と可換なので \(Qv\in V_E\)、\(v\in\ker Q^{\dagger}\) なら \(Q^{\dagger}Qv=Ev\ne0\) から \(Qv\ne0\)）。逆に \(Q^{\dagger}\) は \(V_E\cap\ker Q\) を \(V_E\cap\ker Q^{\dagger}\) に写し、\(\frac1EQ^{\dagger}Q=1\)、\(\frac1EQQ^{\dagger}=1\) が各々の上で成り立つので、\(Q\) と \(\frac1EQ^{\dagger}\) は互いの逆。 (d) \(v\in V_E\) に対し \(v=\frac1EQQ^{\dagger}v+\frac1EQ^{\dagger}Qv\) で、第1項は \(\operatorname{im}Q\subset\ker Q\)、第2項は \(\ker Q^{\dagger}\) に入る。直和であること：二つの部分空間は \(\operatorname{im}Q\perp\operatorname{im}Q^{\dagger}\) から直交。 (e) \(Q_1\) は自己共役で奇、\(Q_1^2=H\) なので \(H\) と可換。\(V_E\) を不変にし、その上で \(Q_1^2=E\ne0\) だから可逆。奇だから \(\HH_{\mathrm B}\cap V_E\to\HH_{\mathrm F}\cap V_E\) と逆向きが互いの定数倍の逆。\(\square\)

例 7.1（一番小さい対） \(\HH=\mathbb C^2=\operatorname{span}\{\vert0\rangle,\vert1\rangle\}\)（\(\HH_{\mathrm B}=\mathbb C\vert0\rangle\)、\(\HH_{\mathrm F}=\mathbb C\vert1\rangle\)）、\(Q=z\,\psi^{\dagger}\)（\(z\in\mathbb C\)）。\(Q^2=z^2\psi^{\dagger2}=0\)。\(H=\vert z\vert^2\{\psi^{\dagger},\psi\}=\vert z\vert^2\)。\(z\ne0\) ならすべての状態が \(E=\vert z\vert^2\) の対（\(Q\vert0\rangle=z\vert1\rangle\)）で、\(\ker H=0\)。\(z=0\) なら \(H=0\)、\(\ker H=\HH\) の二つとも孤立した零モード。

対構造が言うのは「対を持てない状態は零エネルギーに限る」ことである（MW 命題 2.2 の「零エネルギー状態だけが対をもたずに孤立しうる」と同じ）。零エネルギー状態が実際に存在するか、存在すればボソンかフェルミオンか、は次の節の指数と §7.4 の判定表で決まる。

7.3 Witten 指数

この節では、\(\Str e^{-\beta H}\) が零エネルギー状態の数の差に等しく、\(\beta\) によらないことを示し、\(H\) を連続に変えても変わらない条件を述べ、その条件が壊れる例を見る。

定理 7.4（Witten 指数）〔証明〕 \(H=Q_1^2\)（命題 7.2）が自己共役で、ある \(\beta_0\gt0\) について \(e^{-\beta_0H}\) がトレース族とする（有限次元なら自動）。このとき \(\beta\ge\beta_0\) で \(\Str e^{-\beta H}=\Tr\bigl((-1)^Fe^{-\beta H}\bigr)\) は存在し、 \[\Str e^{-\beta H}=\dim\bigl(\ker H\cap\HH_{\mathrm B}\bigr)-\dim\bigl(\ker H\cap\HH_{\mathrm F}\bigr)=:\ind(H)\] となって \(\beta\) によらない。

証明. \(e^{-\beta_0H}\) がトレース族なら \(H\) のスペクトルは固有値だけで、各固有空間 \(V_E\) は有限次元、\(\sum_Ee^{-\beta_0E}\dim V_E\lt\infty\)。\(\beta\ge\beta_0\) でも同じ和が収束し、\(V_E\) ごとに \(\Str\) を取って和をまとめられる（絶対収束）。\(E\gt0\) の \(V_E\) では命題 7.3(e) により \(\dim V_E^{\mathrm B}=\dim V_E^{\mathrm F}\) で、\((-1)^F\) の寄与が打ち消す。\(E=0\) の寄与は \(e^{0}\bigl(\dim\ker H^{\mathrm B}-\dim\ker H^{\mathrm F}\bigr)\)。\(\square\)（命題 7.3(e) は有限次元の証明だが、\(V_E\) が有限次元なら同じ。）

別証（超跡の言葉）. 有限次元で \(\frac{d}{d\beta}\Str e^{-\beta H}=-\Str(He^{-\beta H})=-\Str\bigl(\{Q,Q^{\dagger}e^{-\beta H}\}\bigr)\)。\(Q^{\dagger}e^{-\beta H}\) は奇だから \(\{Q,Q^{\dagger}e^{-\beta H}\}\) は次数つき交換子で、その超跡は 0（命題 6.20）。\(\beta\to\infty\) では \(e^{-\beta H}\to\) (\(\ker H\) への射影) なので、極限値が \(\ind(H)\)。\(\square\)

定理 7.5（変形での不変性） (a)〔証明〕\(s\in[0,1]\) で \(H_s\) が定理 7.4 の条件を満たし、ある \(\beta\gt0\) について \(s\mapsto e^{-\beta H_s}\) がトレースノルムで連続ならば、\(\ind(H_s)\) は \(s\) によらない。 (b)〔主張〕零エネルギー状態が \(s\) とともに無限遠から入ったり無限遠へ逃げたりしない、という形の十分条件が各模型で成り立つ（そのときは (a) の仮定が満たされる）。これを一般に確かめる手続きはこの本では書かない。

(a) の証明. トレースノルムで連続なら \(s\mapsto\Tr\bigl((-1)^Fe^{-\beta H_s}\bigr)\) は連続（\(\vert\Tr(AB)\vert\le\Vert A\Vert\,\Vert B\Vert_1\)）。定理 7.4 によりこれは整数 \(\ind(H_s)\) に等しいので、連続な整数値関数は定数。\(\square\)

例 7.2（指数が跳ぶ例） 後の §7.4 の記号で \(W=\frac s2x^2\)（\(s\ne0\)）を取る。\(F=0\) の部分は \(-\partial_x^2+s^2x^2-s\)、\(F=1\) の部分は \(-\partial_x^2+s^2x^2+s\) で、これは 定理 3.4（\(\hbar=m=1\)、角振動数 \(\vert s\vert\)）から次のスペクトルを持つ。 - \(s\gt0\)：\(F=0\) が \(\{2sn:n\ge0\}\)、\(F=1\) が \(\{2s(n+1):n\ge0\}\)。零モードは \(F=0\) に一つ（\(e^{-sx^2/2}\)）。\(\Str e^{-\beta H}=\sum_{n\ge0}e^{-2\beta sn}-\sum_{n\ge0}e^{-2\beta s(n+1)}=1\)。 - \(s\lt0\)：\(F=0\) が \(\{2\vert s\vert(n+1)\}\)、\(F=1\) が \(\{2\vert s\vert n\}\)。零モードは \(F=1\) に一つ（\(e^{sx^2/2}\)）。\(\Str e^{-\beta H}=-1\)。 - \(s=0\)：両方とも \(-\partial_x^2\) で、スペクトルは \([0,\infty)\) の連続スペクトル。\(e^{-\beta H}\) はトレース族でない（核の対角が \((4\pi\beta)^{-1/2}\) の定数で、\(\Tr=\infty\)）。\(\Str\) は定義できない。

\(s\) が \(0\) を通ると指数は \(+1\) から \(-1\) に跳ぶ。定理 7.5 (a) の仮定が壊れている。零モードの幅は \(\vert s\vert^{-1/2}\) で、\(s\to0\) で無限遠へ逃げる。これは (b) が警告している状況である。数値は検算 7.2 に置いた。

7.4 直線上の Witten 模型

この節では、\(\HH=L^2(\mathbb R)\otimes\mathbb C^2\) の上の超電荷 \(Q=\psi^{\dagger}(\partial_x+W')\) から Hamiltonian を計算し、零エネルギー状態を求めて、超対称性が破れるかの判定表を作る。

\(W\colon\mathbb R\to\mathbb R\) を滑らかな実数値関数（超ポテンシャル）とする。フェルミオンは記法の表のとおり \(\mathbb C^2\) に取る：\(\vert0\rangle=(1,0)^{\top}\)、\(\vert1\rangle=(0,1)^{\top}\)、\(\psi^{\dagger}\vert0\rangle=\vert1\rangle\)、\(\psi^{\dagger}=\begin{pmatrix}0&0\\1&0\end{pmatrix}\)、\(\psi=\begin{pmatrix}0&1\\0&0\end{pmatrix}\)。状態を \(\Psi=(a(x),b(x))^{\top}\) と書き、\(a\) が \(F=0\)（空）、\(b\) が \(F=1\)（占有）の成分である。\(D=\partial_x+W'\)、\(D^{\dagger}=-\partial_x+W'\) とおく。

例 7.3（\(H\) の導出：手で） \(Q=\psi^{\dagger}D\)、\(Q^{\dagger}=\psi D^{\dagger}\)（\(\psi\) と \(D^{\dagger}\) は可換）。\(Q^2=\psi^{\dagger2}D^2=0\)。\(H=QQ^{\dagger}+Q^{\dagger}Q=\psi^{\dagger}\psi\,DD^{\dagger}+\psi\psi^{\dagger}\,D^{\dagger}D\)。成分で書くと \(\psi^{\dagger}\psi=\operatorname{diag}(0,1)\)、\(\psi\psi^{\dagger}=\operatorname{diag}(1,0)\) だから \[H=\begin{pmatrix}D^{\dagger}D&0\\0&DD^{\dagger}\end{pmatrix}.\] 作用素の積を関数 \(a\) に作用させて計算する。 \[D^{\dagger}Da=-(a'+W'a)'+W'(a'+W'a)=-a''-W''a+W'^2a,\] \[DD^{\dagger}b=(-b'+W'b)'+W'(-b'+W'b)=-b''+W''b+W'^2b.\] \([\psi^{\dagger},\psi]=\psi^{\dagger}\psi-\psi\psi^{\dagger}=\operatorname{diag}(-1,+1)\) なので、まとめて \[H=-\partial_x^2+W'(x)^2+W''(x)\,[\psi^{\dagger},\psi].\] \(F=0\) の部分 \(H_0=D^{\dagger}D=-\partial_x^2+W'^2-W''\)、\(F=1\) の部分 \(H_1=DD^{\dagger}=-\partial_x^2+W'^2+W''\)。これは記法の表 §1の式と一致する。

零エネルギー状態とは、命題 7.1(a) により \(\Psi\in\operatorname{dom}Q\cap\operatorname{dom}Q^{\dagger}\) で \(Q\Psi=0\) かつ \(Q^{\dagger}\Psi=0\) を満たすものである（注意 7.1 の意味）。

命題 7.6（直線上の零モードと判定表）〔証明〕 \(W\) が滑らかな実数値関数とする。零エネルギー状態は、\(e^{-W}\in L^2(\mathbb R)\) なら \(e^{-W}\vert0\rangle\)（\(F=0\)、定数倍）、\(e^{W}\in L^2(\mathbb R)\) なら \(e^{W}\vert1\rangle\)（\(F=1\)、定数倍）の、高々この二つで張られる。両方が \(L^2\) に入ることはない。 とくに、\(W(x)\to+\infty\)（\(x\to\pm\infty\) の両方）で \(\int e^{-2W}\lt\infty\) なら、零エネルギー状態は \(e^{-W}\vert0\rangle\) のみ（超対称性は破れない、指数 \(+1\)）。\(W\to-\infty\)（両端）で \(\int e^{2W}\lt\infty\) なら \(e^{W}\vert1\rangle\) のみ（破れない、指数 \(-1\)）。\(x\to+\infty\) と \(x\to-\infty\) で \(W\) の符号が逆向きに発散する（たとえば \(W\) が奇数次の多項式）なら零エネルギー状態は無い（超対称性が破れる、指数 \(0\)）。

証明. \(Q\Psi=\psi^{\dagger}(Da)\vert0\rangle\to(Da)\vert1\rangle\) なので \(Q\Psi=0\iff Da=0\iff a'=-W'a\)。これは一階の線形常微分方程式で、解は \(a=ce^{-W}\)（\(ce^{-W}\) の \(x\) による微分は \(-W'a\)。一意性は \((e^{W}a)'=0\) から）。同様に \(Q^{\dagger}\Psi=0\iff D^{\dagger}b=0\iff b'=W'b\iff b=c'e^{W}\)。成分ごとに独立で、\(L^2\) に入るのは積分が有限のときだけ。\(e^{-W}\) と \(e^{W}\) の自乗積分が共に有限になることはない（\(e^{-2W}\) と \(e^{2W}\) の積が 1 だから、もし両方が可積分なら \(\int 1\,dx\le\bigl(\int e^{-2W}\bigr)^{1/2}\bigl(\int e^{2W}\bigr)^{1/2}\lt\infty\) となり（Cauchy–Schwarz）、\(\int_{\mathbb R}1\,dx=\infty\) に矛盾する）。判定表：\(W\to+\infty\) が両端で起これば \(e^{W}\) は発散し \(L^2\) でない。\(e^{-W}\) の可積分性は仮定。逆符号の場合も同様。両端で逆向きなら、\(e^{-W}\) は \(W\to-\infty\) の端で、\(e^{W}\) は \(W\to+\infty\) の端で発散するので、どちらも \(L^2\) でない。指数は定理 7.4 の右辺。ただし \(e^{-\beta H}\) がトレース族でないときは、指数の定義を零エネルギー状態の個数の差に置き換える。\(\square\)

注意 7.2（スペクトルが離散になる条件）〔主張〕 \(W\) が \(m\ge2\) 次の多項式なら \(W'^2\pm W''\to+\infty\) で、\(H_0,H_1\) は固有値だけのスペクトルを持つ（無限遠で発散するポテンシャルをもつ Schrödinger 作用素のスペクトルは離散。Reed–Simon 第 IV 巻、書誌のみ・本文未確認）。このとき \(e^{-\beta H}\) のトレース族性も成り立つと思われるが、この本は確かめていない。この仮定のもとでは、命題 7.3 と定理 7.4 の有限次元の議論が \(V_E\)（有限次元）ごとに適用できる。

7.5 例：振動子と反射のないポテンシャル

この節では、\(W\) が二次のとき（超対称な振動子）に \(H\) が \(2\omega(N_{\mathrm B}+N_{\mathrm F})\) に書けること、\(W=\log\cosh x\) のとき超対称性の絡み合いが反射のなさを保証することを証明する。

命題 7.7（超対称な振動子）〔証明〕 \(W=\frac\omega2x^2\)（\(\omega\gt0\)）とする。\(a=\sqrt{\omega/2}\,(x+\omega^{-1}\partial_x)\)、\(N_{\mathrm B}=a^{\dagger}a\)（第3章で \(\hbar=m=1\) に取った \(a\)）、\(N_{\mathrm F}=\psi^{\dagger}\psi\) とおくと、 \[D=\sqrt{2\omega}\,a,\qquad D^{\dagger}=\sqrt{2\omega}\,a^{\dagger},\qquad H=2\omega\,(N_{\mathrm B}+N_{\mathrm F}).\] したがって \(H_0=2\omega N_{\mathrm B}\)（固有値 \(2\omega n\)、\(n\ge0\)）、\(H_1=2\omega(N_{\mathrm B}+1)\)（固有値 \(2\omega(n+1)\)）。固有値 \(0\) は \(F=0\) の \(h_0\propto e^{-\omega x^2/2}\) だけ。\(E=2\omega m\)（\(m\ge1\)）の固有空間は二次元で、\(\{h_m\otimes\vert0\rangle,\ h_{m-1}\otimes\vert1\rangle\}\) が張り、\(Q\) が前者を後者に写す。\(\omega\lt0\) ならば同じ計算で \(F=0\) と \(F=1\) の役割が入れ替わる（零モードは \(e^{W}\vert1\rangle\)、指数 \(-1\)）。

証明. \(\sqrt{2\omega}\,a=\sqrt{2\omega}\sqrt{\omega/2}\,(x+\omega^{-1}\partial_x)=\omega x+\partial_x=D\)（\(W'=\omega x\)）。\(D^{\dagger}=-\partial_x+\omega x=\sqrt{2\omega}\,a^{\dagger}\)。\([a,a^{\dagger}]=1\)（第3章、定理 3.4）から \(D^{\dagger}D=2\omega a^{\dagger}a\)、\(DD^{\dagger}=2\omega aa^{\dagger}=2\omega(N_{\mathrm B}+1)\)。例 7.3 の \(H=\operatorname{diag}(D^{\dagger}D,\,DD^{\dagger})\) に代入し、\(N_{\mathrm F}=\operatorname{diag}(0,1)\) に注意して \(H=2\omega(N_{\mathrm B}+N_{\mathrm F})\)。固有値は第3章の \(h_n\)（\(\hbar=m=1\)、角振動数 \(\omega\)）に対する \(N_{\mathrm B}h_n=nh_n\) から。対：\(Q(h_m\otimes\vert0\rangle)=\sqrt{2\omega}\,ah_m\otimes\psi^{\dagger}\vert0\rangle=\sqrt{2\omega m}\,h_{m-1}\otimes\vert1\rangle\)。\(\omega\lt0\) のときは、\(H_0=-\partial^2+\omega^2x^2-\omega\) が \(\omega=-\vert\omega\vert\) で \(-\partial^2+\vert\omega\vert^2x^2+\vert\omega\vert\)、\(H_1=-\partial^2+\vert\omega\vert^2x^2-\vert\omega\vert\) となり、\(\vert\omega\vert\) の振動子について上の計算を \(H_0\leftrightarrow H_1\) で入れ替えたものだから、\(H_0=2\vert\omega\vert(N_{\mathrm B}+1)\)、\(H_1=2\vert\omega\vert N_{\mathrm B}\)。\(\square\)

零点エネルギーの打ち消し. \(H=2\omega N_{\mathrm B}+2\omega N_{\mathrm F}\) には \(\frac12\) の定数がない。第1部の規格化の \(H_{\mathrm I}=\frac12P^2+\frac12W'^2\)（\(\hbar=m=1\)）では零点エネルギーが \(\frac\omega2\) で、\(H=2H_{\mathrm I}+W''[\psi^{\dagger},\psi]\) だから、ボソンの零点 \(2\cdot\frac\omega2=\omega\) とフェルミオンの零点 \(\omega\cdot(-1)=-\omega\) が打ち消す。記法の表 §3 の換算「\(F=0\) の部分が \(2H_{\mathrm I}-W''\)」を数値で確かめた：\(\omega=1\) で \(H_{\mathrm I}\) の最低固有値（差分、\(x\in[-10,10]\)、4000 点）が \(0.4999992\)、\(2H_{\mathrm I}-W''=-1.6\times10^{-6}\approx0\)（刻み誤差）。

7.6 半古典の読み替え：\(t=1/\hbar\)

この節では、\(\hbar\) を戻した Hamiltonian \(H_\hbar\) が MW の \(\Delta_t\) の \(\hbar^2\) 倍であることを計算で示し、MW §5.4 の 1 次元の局所模型をこの章の記号に写す。

\(f\colon\mathbb R\to\mathbb R\) を滑らかな実数値関数とする（MW では Morse 関数）。MW の定義 5.1 は \(\d_t=e^{-tf}\,\d\,e^{tf}=\d+t\,\d f\wedge\)、\(\d_t^{*}=\d^{*}+t\,\iota_{\nabla f}\)、\(\Delta_t=\d_t\d_t^{*}+\d_t^{*}\d_t\) である（確かめた：MW §5.1・§5.3）。\(\mathbb R\) 上では、\(0\) 形式（関数 \(a(x)\)）を \(a\,\vert0\rangle\)、\(1\) 形式 \(b(x)\,\d x\) を \(b\,\vert1\rangle\) とすると \(\d=\psi^{\dagger}\partial_x\)、\(\d^{*}=-\psi\partial_x\)（MW §5.1 の \(\d f\wedge=\sum_i(\partial_if)\psi^{i\dagger}\)、\(\iota_{\nabla f}=\sum_i(\partial_if)\psi_i\) に合わせた対応。\(\mathbb R\) の平坦な計量。\(\d,\d^{*}\) 自体の \(\psi\) による表示は MW 付録 A.2 にあるが、ここではその本文を開いていない）。

命題 7.9（\(H_\hbar=\hbar^2\Delta_{1/\hbar}\)）〔証明〕 \(W=tf\)（\(t\gt0\)）とおくと、第7章の \(Q\) は \(Q=\psi^{\dagger}(\partial_x+tf')=\d_t\) で、\(H=\{Q,Q^{\dagger}\}=\Delta_t\)。すなわち \[\Delta_t=-\partial_x^2+t^2f'(x)^2+t\,f''(x)\,[\psi^{\dagger},\psi].\] \(\hbar\gt0\) を戻した Hamiltonian を \[H_\hbar=-\hbar^2\partial_x^2+f'(x)^2+\hbar\,f''(x)\,[\psi^{\dagger},\psi]\] と定義すると、\(H_\hbar=\hbar^2\Delta_t\big\vert_{t=1/\hbar}\)。さらに \(H_\hbar=\{Q_\hbar,Q_\hbar^{\dagger}\}\)、\(Q_\hbar=\psi^{\dagger}(\hbar\partial_x+f')=\hbar\,\d_{1/\hbar}\)。

証明. \(\partial_x(e^{tf}a)=e^{tf}(a'+tf'a)\) から \(e^{-tf}\partial_xe^{tf}=\partial_x+tf'\) なので \(\psi^{\dagger}(\partial_x+tf')=e^{-tf}(\psi^{\dagger}\partial_x)e^{tf}=e^{-tf}\d\,e^{tf}=\d_t\)。例 7.3 で \(W=tf\) とすれば \(W'=tf'\)、\(W''=tf''\)、\(H=-\partial_x^2+t^2f'^2+tf''[\psi^{\dagger},\psi]\)。\(t=1/\hbar\) のとき \(\hbar^2\Delta_t=-\hbar^2\partial_x^2+f'^2+\hbar f''[\psi^{\dagger},\psi]=H_\hbar\)。\(Q_\hbar=\hbar\psi^{\dagger}(\partial_x+tf')=\hbar\,\d_t\) から \(\{Q_\hbar,Q_\hbar^{\dagger}\}=\hbar^2\Delta_t\)。\(\square\)

例 7.4（MW §5.4 との対応表） MW §5.4 は \(f=\frac12\lambda x^2\)（\(\lambda\ne0\)）で \(\Delta_t=-\frac{d^2}{dx^2}+t^2\lambda^2x^2+t\lambda\sigma\)、\(\sigma=-1\)（\(0\) 形式）、\(+1\)（\(1\) 形式）と書く（確かめた：MW §5.4）。

二重井戸で何が見えるか. 検算 7.1 の \(f=\frac{x^4}{4}-\frac{x^2}{2}\) は \(x=\pm1\) に極小（指数 0、\(f''=2\)）、\(x=0\) に極大（指数 1、\(f''=-1\)）を持つ。系 7.10 の各臨界点の局所模型を一つずつ足し合わせると、低い固有値は \(F=0\) に二つ（二つの極小）、\(F=1\) に一つ（極大）あるはずで、検算 7.1 の \(H_{0,h}\) の最低 2 個 \(\{0,\mu\}\)、\(H_{1,h}\) の最低 1 個 \(\{\mu\}\) と合う。0 にとどまるのは超対称性が保つ一つだけで、もう一つは \(\mu\) に持ち上がって対をなす。これは第8章の調和近似と第9章のインスタントンの予告であって、この章で証明するのは \(x\to\pm\infty\) で \(W\to+\infty\) のときの零モードが \(e^{-tf}\) という形で一つに決まること（命題 7.6）だけである。

7.7 この章のまとめとつながる先

この章で証明したのは、\(H\ge0\) と \(\ker H=\ker Q\cap\ker Q^{\dagger}\)（命題 7.1）、MW の形との同値（命題 7.2）、有限次元の対構造と \(\ker H\cong\ker Q/\operatorname{im}Q\)（命題 7.3）、トレース族の条件での Witten 指数（定理 7.4）とその連続性の条件（定理 7.5 (a)）、直線上の零モードと判定表（命題 7.6）、振動子の対（命題 7.7）、\(\log\cosh\) の反射のなさ（命題 7.8）、\(H_\hbar=\hbar^2\Delta_{1/\hbar}\)（命題 7.9、系 7.10）である。無限次元の定義域（注意 7.1）、離散スペクトルとトレース族性（注意 7.2）、定理 7.5 (b) は主張にとどめた。

つながる先。 - 第8章：\(\mathbb R^n\) へ。\(Q=\sum_i\psi^{i\dagger}(\partial_i+t\partial_if)\) と調和近似。この章の命題 7.7 は第8章 §8.3 の \(n\) 方向の積になる。 - 第9章：持ち上がった対の大きさ \(\mu(t)\) のトンネル効果による見積もり（検算 7.5 の見立ての行き先）。 - 第13章 §13.5：\(\Str e^{-\beta H}=1\) を、ボソンの行列式（\(\det^{-1/2}\)）とフェルミオンの行列式の打ち消しとして（命題 7.7 の \(H=2\omega(N_{\mathrm B}+N_{\mathrm F})\) の分配関数が \(\frac{1-e^{-2\beta\omega}}{1-e^{-2\beta\omega}}=1\) に潰れる）。 - 振動子のつながり：第3章の 定理 3.4 を命題 7.7 で超対称な相棒にした。第8章 §8.3 でさらに Witten 変形の局所模型になる。 - MW：第2章（超対称代数・対構造・Witten 指数。この章と重なるので MW 第2章は流し読みでよい。確かめた：§2.1〜2.3）・§5.4（確かめた）。 - 庭：ラプラス＝ベルトラミ作用素は計算を楽にする道具ではない（laplace-beltrami-hodge-global-device）＝§7.2 の抽象的 Hodge 分解の幾何の側（記事の §4 は Hodge ラプラシアン \(d\delta+\delta d\) を、§7 は微分形式の空間が完全な部分・余完全な部分・調和な部分の三つの直交直和に分かれることを述べていて、§7.2 の三つの直交部分空間への分解の幾何の実例になっている。記事の本文を開いて確かめた）。

7.8 演習の答えの筋

演習 7.1（手で） \(\HH=\mathbb C^2\otimes\mathbb C^2\)（フェルミオン二つ、\(\psi_1,\psi_2\)）、\(Q=z_1\psi_1^{\dagger}+z_2\psi_2^{\dagger}\) に対し \(Q^2=0\) を示し、\(H\) と \(\ker H\) を求めよ。

演習 7.2（手で） 命題 7.7 の \(\omega\lt0\) の場合に、\(H_0,H_1\) の固有値と零モードを書け。

演習 7.3（手で） \(W=\log\cosh x\) の代わりに \(W=\log\cosh(\kappa x)\)（\(\kappa\gt0\)）としたとき、\(H_0,H_1\) を書き、\(H_0\) の束縛状態のエネルギーを求めよ。

演習 7.4（手で） \(W=\frac14x^4\) について、命題 7.6 で零モードを判定せよ。\(W=\frac13x^3\) ではどうか。

答えの筋。 - 演習 7.1：\(Q^2=\sum z_iz_j\psi_i^{\dagger}\psi_j^{\dagger}=0\)（反交換）。\(H=\{Q,Q^{\dagger}\}=(\vert z_1\vert^2+\vert z_2\vert^2)\cdot1\)（\(\{\psi_i^{\dagger},\psi_j\}=\delta_{ij}\)）。\(z\ne0\) なら \(\ker H=0\) で全部が対。 - 演習 7.2：\(H_0=2\vert\omega\vert(N+1)\)、\(H_1=2\vert\omega\vert N\)。零モードは \(F=1\) の \(e^{W}\vert1\rangle=e^{-\vert\omega\vert x^2/2}\vert1\rangle\)。 - 演習 7.3：\(W'=\kappa\tanh\kappa x\)、\(W''=\kappa^2\operatorname{sech}^2\kappa x\)。\(H_0=-\partial^2+\kappa^2-2\kappa^2\operatorname{sech}^2\kappa x\)、\(H_1=-\partial^2+\kappa^2\)。零モード \(\operatorname{sech}(\kappa x)\)、\(H_0-\kappa^2\) の束縛状態は \(-\kappa^2\) ただ一つ（\(x\) を \(\kappa x\) に取り直す）。 - 演習 7.4：\(W=\frac14x^4\) は両端で \(+\infty\)、\(\int e^{-x^4/2}\lt\infty\) なので零モード \(e^{-x^4/4}\vert0\rangle\)、指数 \(+1\)。\(W=\frac13x^3\) は \(x\to-\infty\) で \(-\infty\)、\(x\to+\infty\) で \(+\infty\) なので零モード無し（破れる）。検算 7.1 の読み方の節に数値がある。
