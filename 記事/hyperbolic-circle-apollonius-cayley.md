# ポアンカレ計量の同心円に、アポロニウスの円の記憶を見る
## i 中心の双曲円は、実軸を根軸とする円束だった

## 1. 導入:双曲幾何のはずなのに

双曲幾何は、しばしば「ユークリッド幾何とは別世界」として紹介される。平行線がいくらでも引け、三角形の内角の和は $\pi$ より小さい。距離の測り方がそもそも違う。

しかし、上半平面モデルで「ある一点を中心とする双曲円」を描いてみると、奇妙なことが起こる。それは ── ユークリッド幾何の目で見ても ── ちゃんと円なのである。しかも、その円たちは、初等幾何でおなじみの**アポロニウスの円**であり、**実軸を根軸とする同軸円束**として整然と並ぶ。

本記事は、その事実を丁寧にたどる。双曲幾何の話のはずなのに、読み進めるうちに、メビウス変換・アポロニウスの円・円束・根軸といった、どこか懐かしい初等幾何の言葉が次々によみがえってくる ── そういう記事にしたい。

---

## 2. 上半平面とポアンカレ計量

舞台は上半平面である。

$$\mathbb{H} = \{\, z = x + iy \mid y > 0 \,\}$$

ここに、ユークリッド的な距離ではなく、**ポアンカレ計量**を入れる。

$$ds^2 = \frac{dx^2 + dy^2}{y^2}$$

これは「同じ見かけの長さでも、実軸 $y=0$ に近いほど引き伸ばされて長く感じられる」計量である。実軸は無限の彼方であり、上半平面はそれ自身で完結したひとつの世界をなす。

この計量のもとで二点 $z, w \in \mathbb{H}$ の双曲距離 $d_{\mathbb{H}}(z,w)$ は、次の美しい公式で与えられる。

$$\cosh d_{\mathbb{H}}(z,w) = 1 + \frac{|z-w|^2}{2\,\operatorname{Im}z\,\operatorname{Im}w}$$

右辺はユークリッド的な量(差の絶対値の二乗、虚部)だけで書かれていることに注意したい。**双曲距離は、ユークリッド的なデータから完全に計算できる。** この一点が、これから先のすべての種である。

---

## 3. i を中心とする双曲円の方程式

中心を $i$($x=0,\ y=1$ の点)に取ろう。$\operatorname{Im} i = 1$、$|z-i|^2 = x^2 + (y-1)^2$ だから、距離公式は

$$\cosh d_{\mathbb{H}}(z,i) = 1 + \frac{x^2 + (y-1)^2}{2y}$$

となる。

いま、双曲半径 $r$ の円、すなわち「$i$ からの双曲距離がちょうど $r$ である点の集合」を考える。$d_{\mathbb{H}}(z,i) = r$ と置くと、$\cosh d_{\mathbb{H}}(z,i) = \cosh r$ だから、

$$1 + \frac{x^2 + (y-1)^2}{2y} = \cosh r$$

両辺から $1$ を引いて $2y$ を掛ける。

$$x^2 + (y-1)^2 = 2y(\cosh r - 1)$$

左辺を展開すると $x^2 + y^2 - 2y + 1$。右辺は $2y\cosh r - 2y$。両辺の $-2y$ が打ち消し合って、

$$x^2 + y^2 - 2y\cosh r + 1 = 0$$

という、すっきりした式が残る。これを $y$ について平方完成する。

$$x^2 + (y - \cosh r)^2 = \cosh^2 r - 1 = \sinh^2 r$$

最後に $\cosh^2 r - 1 = \sinh^2 r$ を使った。結論はこうだ。

> 上半平面における、$i$ 中心・双曲半径 $r$ の円は、**ユークリッド幾何の目で見ると**
> $$\text{中心 } (0,\ \cosh r), \qquad \text{半径 } \sinh r$$
> のふつうの円である。

双曲的な円は、ユークリッド的にも円だった。ただし、その**中心はずれている**。双曲的中心 $i = (0,1)$ に対し、ユークリッド的中心は $(0,\cosh r)$ で、$\cosh r > 1$ だけ上にある。半径が大きいほど、ユークリッド中心は上へ逃げていく。

---

## 4. 円束と根軸:双曲的同心円の正体

半径 $r$ を動かすと、円の族が得られる。$c = \cosh r$ と置けば、

$$x^2 + y^2 - 2cy + 1 = 0 \qquad (c = \cosh r \geq 1)$$

これは $c$ をパラメータとする円の族である。双曲幾何の側では、これらはすべて $i$ を中心とする**同心円**だ。ではユークリッド幾何の側では、この族はどう見えるのか。

二つの円を取る。

$$x^2 + y^2 - 2c_1 y + 1 = 0$$
$$x^2 + y^2 - 2c_2 y + 1 = 0$$

この二式の差を取ると、二次の項 $x^2 + y^2$ と定数項 $1$ がきれいに消えて、

$$-2(c_1 - c_2)\, y = 0$$

が残る。$c_1 \neq c_2$ なら、

$$y = 0$$

すなわち**実軸**が出てくる。

二つの円の方程式の差が表す直線は、その二円の**根軸**(radical axis)と呼ばれる。いま得られたのは、この円族のどの二円を取っても根軸が同じ ── 実軸 ── になる、ということだ。共通の根軸を持つ円の族を**同軸円束**(coaxial system)という。

> 双曲幾何における「$i$ を中心とする同心円」は、ユークリッド幾何では「**実軸を共通の根軸とする同軸円束**」として見えている。

双曲的な「中心」という一点が、ユークリッド的には「根軸」という一本の直線に化けている。これが最初の翻訳である。

---

## 5. 円の上端と下端:e^{−r} と e^{r}

この円が虚軸($x=0$)と交わる点を見よう。$x = 0$ を

$$x^2 + (y-\cosh r)^2 = \sinh^2 r$$

に代入すると $(y-\cosh r)^2 = \sinh^2 r$、すなわち $y = \cosh r \pm \sinh r$。指数関数を思い出せば、

$$y = \cosh r - \sinh r = e^{-r}, \qquad y = \cosh r + \sinh r = e^{r}$$

円の下端は $ie^{-r}$、上端は $ie^{r}$ である。

これが双曲半径 $r$ と整合することを、直接確かめておきたい。虚軸に沿って動くとき $x$ は一定なので、ポアンカレ計量は

$$ds = \frac{dy}{y}$$

となる。$i$(つまり $y=1$)から $ie^{r}$(つまり $y=e^{r}$)までの双曲的な道のりは、

$$\int_{1}^{e^{r}} \frac{dy}{y} = \bigl[\log y\bigr]_{1}^{e^{r}} = r$$

ちょうど $r$ である。下方向も同様に、$i$ から $ie^{-r}$ まで距離 $r$。だから、双曲半径 $r$ の円は虚軸上では $ie^{-r}$ から $ie^{r}$ までを端から端とする。

そして、ユークリッド的な中心と半径は、この二つの端点の中点と半分の幅としてごく自然に出てくる。

$$\text{中心の高さ} = \frac{e^{r} + e^{-r}}{2} = \cosh r, \qquad \text{半径} = \frac{e^{r} - e^{-r}}{2} = \sinh r$$

$\cosh$ と $\sinh$ が、双曲円の幾何そのものから ── 名前の由来どおりに ── 立ち現れている。

---

## 6. ケイリー変換:単位円盤モデルへ

ここでもう一つのモデル、単位円盤を呼び込む。**ケイリー変換**

$$w = \frac{z - i}{z + i}$$

は、上半平面 $\mathbb{H}$ を単位円盤

$$\mathbb{D} = \{\, w \mid |w| < 1 \,\}$$

へ写すメビウス変換である。とりわけ、

$$z = i \quad \longmapsto \quad w = \frac{i-i}{i+i} = 0$$

を満たす。双曲的中心 $i$ が、円盤の中心 $0$ へぴたりと移る。

そしてケイリー変換は、ポアンカレ計量に関する**等長写像**である(双曲距離を保つ)。したがって:

> 上半平面での「$i$ 中心・双曲半径 $r$ の円」は、単位円盤モデルでは「**$0$ 中心・双曲半径 $r$ の円**」に移る。

円盤モデルの利点は、原点中心の双曲円が、ユークリッド円としても**原点中心**になることだ(中心がずれない)。実際、円盤モデルでの原点からの双曲距離は

$$d_{\mathbb{D}}(0,w) = 2\operatorname{artanh}|w|$$

で与えられる。これを $d_{\mathbb{D}}(0,w) = r$ と置けば、

$$|w| = \tanh\frac{r}{2}$$

円盤モデルでは、双曲半径 $r$ の円は、ユークリッド半径 $\tanh(r/2)$ の、原点中心のまんまるい円である。双曲幾何の「同心円」が、ここでは文字どおりの同心円になる。

---

## 7. ケイリー変換から、上半平面の円の式を取り戻す

逆に、円盤モデルの素朴な円から出発して、上半平面の円の式を導き直してみよう。これが本記事のいちばんの見どころである。

円盤モデルでの原点中心円 $|w| = \rho$ を、ケイリー変換で上半平面へ引き戻す。$w = (z-i)/(z+i)$ だったから、

$$\left|\frac{z-i}{z+i}\right| = \rho$$

すなわち

$$|z - i| = \rho\,|z + i|$$

この式をじっと見てほしい。これは、**二点 $i$ と $-i$ からの距離の比が一定値 $\rho$ である点 $z$ の軌跡**である。距離の比が一定 ── これこそ、古代ギリシャ以来の**アポロニウスの円**の定義そのものだ。

円盤モデルの素朴な同心円が、上半平面に引き戻されると、$i$ と $-i$ という二つの焦点をめぐるアポロニウスの円の族になる。

式で確かめよう。$z = x + iy$ として、$|z-i|^2 = \rho^2 |z+i|^2$ を展開する。

$$x^2 + (y-1)^2 = \rho^2\bigl\{\, x^2 + (y+1)^2 \,\bigr\}$$

左辺は $x^2 + y^2 - 2y + 1$、右辺は $\rho^2(x^2 + y^2 + 2y + 1)$。整理すると、

$$(1-\rho^2)(x^2+y^2) - 2(1+\rho^2)\,y + (1-\rho^2) = 0$$

両辺を $1-\rho^2$($\rho < 1$ なので正)で割って、

$$x^2 + y^2 - 2\,\frac{1+\rho^2}{1-\rho^2}\,y + 1 = 0$$

ここで $\rho = \tanh(r/2)$ と置く。双曲半角公式によって、

$$\frac{1+\rho^2}{1-\rho^2} = \frac{1+\tanh^2(r/2)}{1-\tanh^2(r/2)} = \cosh r$$

が成り立つ。したがって、

$$x^2 + y^2 - 2y\cosh r + 1 = 0$$

── これは §3 で双曲距離公式から導いた円の式と、**完全に一致する**。

二つの道、すなわち「ポアンカレ計量の距離公式から直接計算する道」と「円盤モデルの素朴な円をケイリー変換で引き戻す道」が、同じ一本の式に合流した。双曲円・アポロニウス円・原点中心円が、同じものの三つの顔だったことが、ここで確かめられた。

---

## 8. 実軸が根軸になる理由 ── アポロニウスの側から

§4 では、円族の方程式の差を取って「実軸が根軸」という結論を得た。同じことを、いまやアポロニウスの円の側から見直すことができる。

アポロニウスの円は、$i$ と $-i$ からの距離の比 $|z-i| : |z+i|$ が一定の点の軌跡だった。では、その比がちょうど $1$ になるのはどこか。実軸上の点 $z = x$(実数)では、

$$|x - i| = \sqrt{x^2+1} = |x + i|$$

つまり実軸は、二点 $i$ と $-i$ から**等距離**にある点の集合 ── **垂直二等分線**である。

ケイリー変換の逆像として現れるアポロニウス円の族において、実軸は「比が $1$ の極限ケース」という特別な位置を占める。$i$ と $-i$ を焦点とするアポロニウス円束の構造のなかで、垂直二等分線は族全体を貫く基準線になる。

この特別な直線が、円束の言葉に翻訳されると ── 「**実軸が共通の根軸である**」という、§4 で見た事実になる。アポロニウスの「垂直二等分線」と、円束の「根軸」は、同じ直線の二つの呼び名だったのだ。

---

## 9. まとめ:双曲幾何が初等幾何の言葉で語られるとき

歩いてきた翻訳を、一枚の図にまとめよう。

$$
\boxed{
\begin{array}{ccc}
\text{上半平面の } i \text{ 中心双曲円}
&=&
\text{ユークリッドのアポロニウス円} \\[6pt]
&=&
\text{実軸を根軸にもつ同軸円束} \\[6pt]
&\xrightarrow{\ \text{Cayley}\ }&
\text{単位円盤の原点中心円}
\end{array}
}
$$

ポアンカレ計量という、一見ユークリッド幾何とは無縁の対象から出発した。ところが、その「同心円」を描いてみれば、現れたのはアポロニウスの円であり、実軸を根軸とする円束であり、ケイリー変換という一つのメビウス変換を通せば、円盤の上のまんまるい同心円だった。

双曲幾何は、別世界の幾何ではなかった ── 少なくともこの場面では。それは、メビウス変換・アポロニウスの円・円束・根軸という、初等幾何が古くから持っていた言葉へと、驚くほどなめらかに翻訳される。

ポアンカレ計量の同心円をたどっていくと、いつのまにか、定規とコンパスの時代の幾何学に出会っている。双曲幾何の話だったはずなのに、読み終えてみれば、前世の初等幾何の記憶がよみがえっている ── そういう種類の美しさが、ここにはある。
